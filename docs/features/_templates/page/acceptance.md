# 页面验收

## UI Mock

- [ ] 主任务可完成
- [ ] 所有入口和返回路径正确
- [ ] 路由参数非法时安全失败
- [ ] 加载、成功、空、错误、离线、无权限状态可验证
- [ ] 表单校验和防重复提交正确
- [ ] 文本缩放、读屏、对比度和触控区域符合要求
- [ ] Android/iOS 目标真机显示和交互通过
- [ ] Widget/Mock flow 测试场景已列出并通过
- [ ] 页面未连接真实超级接口、WebSocket 或生产 SDK

## 真实接入（仅 UI Flow Approved 后）

- [ ] Fake adapter 已由批准的真实 adapter 替换
- [ ] 加载、错误、弱网、权限和会话变化与 UI Mock 语义一致
- [ ] 集成测试与双端真机验证通过

# 首页交互

## 刷新与滚动

- 首次进入加载一次；切回保活分支不自动请求，只有失效策略命中时由 application 层刷新。
- 下拉刷新使用 SingleFlight；失败保留最后成功快照。
- 重按首页 Tab 滚动到顶，不自动刷新。
- 复刻阶段允许两列运营海报纵向滚动；Fake 场景使用有限列表，不接分页接口。

## 入口、Banner 与海报

- “一起玩 / 组局玩 / 扫码”三个核心入口均设置稳定 actionId 和 300ms 导航去重。
- 三联入口复刻旧版交互：斜向流光在完整 3/6/9 秒周期内持续横穿对应卡片，不使用短促闪光；按下时整卡降至 70% 透明度，松开或取消即恢复。
- 系统开启减少动态效果时，流光固定为不可见且不再循环；按压反馈和导航仍可用。
- 不可用入口仍保持位置，显示受控原因和可访问性状态，不静默消失。
- Banner 默认 4 秒轮播；开启“减少动态效果”后停止自动播放。
- Banner/海报点击前验证客户端 action 枚举与资源引用格式；复刻旧版“图片展开 + 内容面板”Fake 详情，关闭或系统返回后恢复原轮播页和滚动位置，未知动作失败关闭。
- 旧版内容卡完整保留三类 Mock：`mode=0` 图文卡、`mode=1` 纯海报、`mode=2` 视频卡；参考图首屏固定使用纯海报。
- 页面不拼 location，不把完整对象或显示文案传给目标页。

## 底栏

- App Shell 保持类型化导航，固定五个目的地为首页、消息与通讯录、内容、私人储物柜、我的，并把视觉复刻为旧版悬浮胶囊。
- 中央爱心是内容 Tab，不打开扫码；扫码只由首页三联入口进入。
- 不恢复服务端 `tabData` 动态路由，不把旧首页大 Swiper 迁入 Flutter。
- 内容 Tab 已选中时再次点击只回到内容根/滚动到顶；D2 作品发布暂缓，因此不复刻旧版二次点击发布。

## 无障碍

- 卡片语义顺序与视觉顺序一致；每个入口朗读任务、可用性和结果。
- 行程状态不能只靠颜色，必须有文字和图标语义。
- 自动轮播支持暂停；开启“减少动态效果”时不自动切换。
- 图片失败时保留标题和动作，不以图片作为唯一信息。

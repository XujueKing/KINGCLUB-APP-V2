# 首页滚动紧凑头部核查

## 核查范围

- 对照用户提供的旧版滚动前、滚动后截图。
- 在连接的 Android 真机上从首页顶部向上滑动一次，并保存滚动前后画面。
- 检查 Flutter 首页滚动结构是否包含会员头部的吸顶、压缩或替换逻辑。

## 步骤与结果

1. 首页顶部：会员 Logo、等级资产、顶部 Banner、三联入口和运营海报均正常显示。
2. 向上滑动浏览运营海报：会员头部与顶部 Banner一起滚出屏幕，顶部直接露出轮播 Banner；未出现旧版的紧凑会员栏。

## 结论

当前版本没有实现旧版“向下浏览广告时，将会员 Logo、等级资产和进度压缩后吸附在顶部”的滚动联动效果。首页目前只是一个普通 `CustomScrollView` 列表，`_MemberHeader` 是列表首项，没有吸顶、压缩或基于滚动偏移切换紧凑态的逻辑。

## 证据

- `01-top.png`：真机首页顶部状态。
- `02-scrolled.png`：真机上滑后状态，会员头部完全离开屏幕。

## 建议

- 按旧版补充两态头部：展开态保持现状；滚动超过顶部 Banner 后切换为紧凑吸顶态。
- 紧凑态保留 Logo、昵称/等级、金币、钻石和进度条；顶部 Banner滚出，三联入口和运营海报继续在其下方滚动。
- 切换过程使用连续尺寸与位置插值，避免突然跳变，并在“减少动态效果”模式下改为无动画状态切换。

## 实施复验

- 已将会员头部改为两态吸顶结构：`08-final-top.png` 为展开态，`12-final-compact-matched.png` 为顶部 Banner 滚出后的紧凑态。
- 紧凑态持续保留旧版 Logo、昵称/等级、金币、钻石与进度条，三联入口和运营广告从其下方继续滚动。
- 回到顶部后恢复展开尺寸；页面仍保留原有 Banner、入口与海报交互。
- 首页 Widget 测试 13/13 通过，静态分析无问题。

## 第二轮实施复验：完整顶部组合

- 用户补充确认旧版吸顶对象不是只有会员栏，而是“紧凑会员栏 + 一起玩/组局玩/扫码”完整组合。
- 已将三联入口纳入同一可折叠头部：Banner 滚出后，会员栏压缩，三个入口保持在其下方并共同固定。
- 三联入口底部增加黑色柔和阴影，运营广告从阴影后方滚动，保留旧版层次感。
- `15-sticky-group-shadow-top.png`：展开态顺序与比例。
- `16-sticky-group-shadow-compact.png`：组合吸顶、阴影和广告滚动态。
- 首页 Widget 测试 13/13 通过，静态分析无问题。

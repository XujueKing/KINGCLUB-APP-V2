# 组件：旧版底部导航

- 文档状态：`Approved for Development`
- 组件 ID：`HOME-C05`
- 归属：App Shell；本文件记录首页截图中的内容复刻要求
- 旧版来源：`tabData`、`click_tabbar`、`click_newVideo`

## 固定目的地

| 索引 | 目的地 | 视觉语义 | 备注 |
|---:|---|---|---|
| 0 | 首页 | 房屋图标，选中时香槟色圆形底 | 当前首页默认选中 |
| 1 | 消息与通讯录 | 对话气泡图标 | 可显示红色未读数字 |
| 2 | 内容 | 白色圆角方块内粉色爱心 | 不是扫码 |
| 3 | 私人储物柜 | 公文包/储物图标 | 旧版该分支使用特殊深棕背景 |
| 4 | 我的 | 人像图标 | 进入个人中心 |

底栏只显示图标，不新增文字标签。目的地顺序由客户端固定，不恢复服务端动态路由。

## 视觉规则

- 胶囊旧尺寸 `660×110rpx`，圆角 `50rpx`，背景 `#1A1611EE`。
- 外层固定底部，高 `190rpx`，带向上透明的黑色遮罩；Flutter 需叠加真实 SafeArea。
- 普通图标旧约 `50×35rpx`，内容爱心约 `70×49rpx`。
- 选中态有移动的深色/香槟色圆形底，截图视觉优先。
- 未读徽标红色，只有 `dot=true && num>0` 时显示；数字过大使用 `99+`。

## 点击规则

- 点击未选中项：切换到对应 Flutter 分支根。
- 重按首页：滚动到顶，不触发真实刷新。
- 重按其他项：回分支根/滚动到顶。
- 旧版重按已选中内容 Tab 会打开作品发布；本期作品发布已暂缓，所以不复刻该副作用，除非先完成独立页面文档并变更范围。

## 验收

- [ ] 五项顺序和旧图标正确，中心爱心不被替换为扫码。
- [ ] 首页选中态与参考图的圆形底一致。
- [ ] 未读徽标不会遮挡图标，读屏可朗读数量。
- [ ] 底栏覆盖内容时，最后一张卡仍可滚动到可点击区域。

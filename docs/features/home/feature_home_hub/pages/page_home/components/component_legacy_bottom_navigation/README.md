# 组件：旧版底部导航

## 2026-09-12 宽90%与深色渐变遮罩（最新）

用户反馈底部太亮：底栏收窄至屏宽90%（675rpx），五图标及动画圆底中心同步缩放；恢复外层透明→#DD000000→黑色渐变，stops为0/0.5/0.86，压暗底部内容。保留无白边茶色磨砂、高度和安全间距。该遮罩按用户要求优先保证暗底观感，玻璃透色会相应减弱。

## 2026-09-12 茶色磨砂与无亮边（最新）

按用户反馈，将半透明底色调为茶棕渐变（#80503A25 / #702D2015 / #80433222，ARGB），删除白色描边。背景模糊24逻辑像素、宽690rpx、现有高度和安全间距保持不变。

## 2026-09-12 加宽与玻璃效果（最新）

宽度660→690rpx（屏宽92%），五按钮与圆底共享按比例展开的中心；图标大小、栏高、底部安全间距保留。玻璃使用裁剪范围内24逻辑像素BackdropFilter模糊，半透明暖深色渐变、0.7逻辑像素淡白边缘高光。原近乎不透明底色与外层黑渐变会遮住模糊背景，现一起减弱，使滚动内容颜色能透入栏内。

参考 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的通透材质方向；这是Flutter跨平台磨砂玻璃，不实现或宣称苹果原生Liquid Glass动态折射。仅在底栏使用一个裁剪模糊层，实际低端设备帧率、苹果真机效果仍需验收。

## 2026-09-12 用户指定尺寸对齐与滑动动画

以当前旧版 index.wxss/index.wxml 为依据：660×110rpx、50rpx圆角、#1A1611EE背景和20px模糊；普通50×35rpx、中央70×49rpx使用原PNG，资产哈希与旧版一致。外层190rpx内容高度加30rpx顶部padding，下方80rpx空隙容纳系统安全区，不重复叠加；超出部分额外留空。rpx按实际可用宽度/750换算。

## 固定目的地

| 索引 | 目的地 | 视觉语义 | 备注 |
|---:|---|---|---|
| 0 | 首页 | 房屋图标，选中时香槟色圆形底 | 当前首页默认选中 |
| 1 | 消息与通讯录 | 对话气泡图标 | 可显示红色未读数字 |
| 2 | 内容 | 白色圆角方块内粉色爱心 | 不是扫码 |
| 3 | 私人储物柜 | 公文包/储物图标 | 旧版该分支使用特殊深棕背景 |
| 4 | 我的 | 人像图标 | 进入个人中心 |

底栏只显示图标，不新增文字标签。目的地顺序由客户端固定，不恢复服务端动态路由。

## 视觉规则

- 胶囊旧尺寸 `660×110rpx`，圆角 `50rpx`，背景 `#1A1611EE`。
- 外层固定底部，高 `190rpx`，带向上透明的黑色遮罩；Flutter 需叠加真实 SafeArea。
- 普通图标旧约 `50×35rpx`，内容爱心约 `70×49rpx`。
- 选中态有移动的深色/香槟色圆形底，截图视觉优先。
- 未读徽标红色，只有 `dot=true && num>0` 时显示；数字过大使用 `99+`。

## 点击规则

- 点击未选中项：切换到对应 Flutter 分支根。
- 重按首页：滚动到顶，不触发真实刷新。
- 重按其他项：回分支根/滚动到顶。
- 旧版重按已选中内容 Tab 会打开作品发布；本期作品发布已暂缓，所以不复刻该副作用，除非先完成独立页面文档并变更范围。

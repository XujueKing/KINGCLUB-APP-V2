# 组件：运营内容瀑布流

- 文档状态：`Approved for Development`
- 组件 ID：`HOME-C04`
- 旧版来源：`nat_list` Masonry、`nat_bindtap`

## 内容模式

| 旧 `mode` | 类型 | 首页卡片内容 | 点击结果 |
|---:|---|---|---|
| 0 | 图文卡 | 图片 + 标题 + 作者头像/昵称 + 浏览量/眼睛图标 | 展开图片与内容面板 |
| 1 | 纯海报 | 一张 `332×460rpx` 海报，文案全部在图片内 | 展开图片与内容面板 |
| 2 | 视频卡 | 视频 + 声音/播放控制 | 本期只做受控 Fake 视频状态，不连网络流 |

首屏参考图使用两列 `mode=1` 纯海报，不在图片下重复输出标题或作者信息。

## 布局

- 两列 Masonry；旧横/纵轴间距 `6rpx`，外边距左右 `35rpx`。
- 卡片宽 `332rpx`；`mode=0` 图片高 `410rpx` 并带底部信息，`mode=1` 高 `460rpx` 且四角圆角 `10rpx`。
- 纵向无限滚动在 UI 阶段用有限 Fake 列表模拟；不请求真实分页。

## 点击详情

旧版会把当前卡片图片放大到屏幕宽度，并解析 URL 编码后的 JSON `content` 拉起内容面板；关闭时缩回原卡片位置。

V2 仅接受类型化 `contentBlocks`，禁止解析任意 HTML、脚本或动态路由。系统返回和关闭按钮都回到原瀑布流位置。

## 状态

- `posterReady`、`articleReady`、`videoPaused`、`videoPlayingMuted`。
- `singleImageError`：保持原卡高度，显示占位和可访问文本。
- `empty`：保留头部/Banner/快捷入口，内容区显示受控空态。
- `loadingMore` / `loadMoreError`：只影响底部，不清空已有卡片。

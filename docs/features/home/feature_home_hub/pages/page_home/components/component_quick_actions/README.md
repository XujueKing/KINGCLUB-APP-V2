# 组件：三联快捷入口

- 文档状态：`Approved for Development`
- 组件 ID：`HOME-C03`
- 旧版来源：`index.wxml` 的 `order/order_top`、`index_bindtap`
- 补充视觉基准：用户于 2026-08-26 提供的三联入口原图裁片

## 原图内容逐字抄录

```text
┌──────────────────────┐  ┌──────────────────────┐  ┌─────────────┐
│  [符号底纹]  一起玩  │  │  [多人底纹]  组局玩  │  │ [二维码底纹]│
│         TOGETHER PLAY│  │       EXCLUSIVE SEATS│  │   [扫码框]  │
└──────────────────────┘  └──────────────────────┘  │   SCAN QR   │
                                                    └─────────────┘
```

必须逐字使用以下内容：

- 第一项中文：`一起玩`
- 第一项英文：`TOGETHER PLAY`
- 第二项中文：`组局玩`
- 第二项英文：`EXCLUSIVE SEATS`
- 第三项：深棕色扫码框图标
- 第三项英文：`SCAN QR`
- 第三项没有中文标题，不得添加“扫码”二字。

## 固定内容与顺序

| 位置 | 中文/图标 | 英文 | 旧素材 | 旧点击结果 | V2 Mock 意图 |
|---|---|---|---|---|---|
| 左 | `一起玩` | `TOGETHER PLAY` | `H01.png` | `/pages/Choose/Choose` | `openAaReservations` |
| 中 | `组局玩` | `EXCLUSIVE SEATS` | `H02.png` | `/pages/Choose2/Choose2` | `openVipParty` |
| 右 | 二维码图标 | `SCAN QR` | `qrcode2.png` + `qrcode3.png` | `scanQrCode()` | `openSafeScanner(origin=home)` |

## 视觉规则

- 单行三列，不改成 2×2，也不增加第四个入口。
- 左、中旧尺寸 `246×140rpx`；右侧旧宽 `160rpx`。
- 背景径向渐变 `#B8A289 → #7E6951`，圆角 `15rpx`。
- 第一、第二项的低透明度装饰图形固定在左侧并允许被卡片边界裁切；中文标题位于右侧偏上，英文位于右侧下方。
- 第一项使用旧 `H01.png` 的符号底纹；第二项使用旧 `H02.png` 的多人底纹；不能换成普通线性图标。
- 第三项比前两项窄：`qrcode2.png` 作为铺满卡片的低透明度二维码底纹，`qrcode3.png` 作为居中的深棕扫描框，`SCAN QR` 位于图标下方。
- 中文标题约 `38rpx`、600 字重；英文约 `20rpx`、正常字重；全部文字为深棕 `rgb(66,46,25)`。
- 三张卡使用同一米棕色体系，但不得抹掉原图中从左上到右下的轻微明暗变化。
- H01/H02/二维码背景纹样都保持低透明度；前景文字和扫码框必须清晰。
- 卡片间保留黑色窄缝，三项整体左右对齐首页 Banner 和瀑布流内容边界。
- 点击保留轻量按压反馈，不改变内容、文案或图标。
- 旧版滚动超过阈值时显示顶部粘性副本 `order_top`；V2 是否复刻粘性副本以截图滚动 QA 为准，但内容必须完全一致。

## 交互边界

- 300ms 内重复点击只产生一个 RouteIntent。
- 一起玩和组局玩只进入已批准的 Fake 页面，不创建真实预约或订单。
- 扫码只进入安全扫码 Mock，不启动相机、不识别真实二维码。
- 不可用时位置不消失，显示稳定不可用原因。

## 验收

- [ ] 三项顺序、中文、英文大小写完全一致。
- [ ] 第一、第二项装饰图形在左侧，文字在右侧，位置与原图一致。
- [ ] 右侧不显示“扫码”中文文字，只显示二维码图标和 `SCAN QR`。
- [ ] 第三项同时具备浅色二维码底纹和深棕扫描框，不能只保留其中一个。
- [ ] 未使用 Emoji、字体字符、临时占位或新图标替代旧 PNG。
- [ ] 三项分别进入正确的 Fake 流程并能返回首页原位置。
- [ ] 窄屏不换成两行，必要时等比缩放整组三联入口。

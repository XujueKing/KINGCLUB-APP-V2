# 2026-10-02 聊天、账单与首页布局调整

## 用户要求与实现

1. 系统会话移除“全部已读”，保留进入前台可见会话后按已加载游标自动已读的逻辑。
2. 系统卡片打开的真实会员订单详情采用与系统会话相同的 #101010 背景、6% 白色卡片底与 8% 白色分隔线；上方黑底白色 King 标志、门店及居中金额，下方统一标签列和可选择的明细值，商品单独分区。待结账状态及真实退款信息保留。
3. 会话行分隔线左端改为姓名起点（161rpx），右端保持原位置。
4. 聊天和通讯录采用无圆形指示器的刷新方式，保留原有后台事件、返回页面与静默刷新能力。
5. 聊天/通讯录标题小红点向下移动 6dp，标题和通讯录基线不变。
6. 首页收起时 logo 与资产的缩放由 38% 减至 8%；收起后头部和三个按钮保留 20rpx 间距，与 banner 下方间距一致。无 banner 的状态独立计算展开高度，避免最小高度超过最大高度。
7. EXP 宽度由 360rpx 改为 245rpx，右侧对齐钻石金额的右边缘；右上方增加城市入口。启动时使用已授权的设备定位及原生逆地理编码确定城市；没有定位结果时显示城市入口，不填写假城市。用户可手动选择城市或使用定位城市；迟到的定位结果不会覆盖已选择城市。

## 数据边界

订单详情展示真实会员订单接口返回的状态、订单创建时间、门店、桌位、下单来源、付款时机、订单号、商品和退款信息。该接口未返回支付机构、支付方式及渠道交易号，不使用微信截图的示例内容替代。创建时间明确标为“订单时间”，不标为“支付时间”。

城市选择当前用于首页城市展示；尚未接入按城市过滤运营图片或门店列表。手选城市仅在当前页面状态中保存，重启后默认重新定位。未授权定位不会在启动时弹出权限请求，用户主动点击“使用定位城市”时才请求权限。

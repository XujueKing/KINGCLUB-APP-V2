## 审计结论

### 优点

- 关闭按钮在所有状态中保持可达，失败后主动作与次动作顺序稳定。
- 允许类型与拒绝类型文案清晰，不把“识别成功”包装成业务已完成。
- 解析使用单次 generation/SingleFlight；关闭、销毁、重扫后的迟到结果不导航。
- 前后台切换会暂停 Fake 取景并关闭补光灯，会话失效会清理当前意图。

### 可访问性与剩余风险

- 360、393、430dp 和 200% 文字测试通过；减少动画时两处状态切换动画降为零。
- Android 语义树已显示关闭、手电筒、开始扫码和各场景动作为可点击控件；截图不能代替真机 VoiceOver/TalkBack 读屏顺序复核。
- `UI 测试权限` 和 `展开 UI 测试场景` 是当前 Fake 验收入口，真实接入时必须由 adapter 代替，不得作为生产用户功能保留。

# 1.2.0（170）会员审核通知闭环

会员人工审核通过后保存系统消息和实时通知。待审核手机收到事件、重连或恢复前台后核实服务器状态，显示顶部审核通过横幅；系统消息与消息角标使用持久未读数据。点击横幅进入 APP，显示横幅不清掉系统消息。已读、重复事件、历史恢复和账号切换有保护。合作者审核通知沿用既有链路。

客户目录、通知、审核角标及四语言回归 37 项通过，lib 静态分析无问题。隔离数据库验证审核/通知/outbox 原子回滚、幂等、两管理员并发及不改评分/资产。服务端迁移 410 和通知兼容能力等待部署验证；签名打包及 USB 安装进行中，不表示已安装或已上传 TestFlight。具体设计见会员审核页 APPROVAL_NOTIFICATIONS.md。

## 页面与交互

客户名录：会员 / 营销 / 申请中 / 黑名单；全部、今日预约、今日到店、男、女筛选；昵称、KM 会员号或完整手机号搜索；真实筛选总数；头像、昵称（实名）、性别、注册时间、会员等级和联系电话。每页 30 条，分类/筛选/搜索变化清空旧结果，过期请求不能覆盖新结果。读取失败有重试，不显示为没有客户。

详情：会员 / 账目 / 备注。资料包含会员号、生日年龄、联系电话复制、订单数量、按币种累计实付、实际消费提成、会员等级、平台余额、金币、钻石、三照片评分、好友/发送消息/直属下级数量、状态、注册日期、推荐人及四项偏好。门店储值另列，不能与平台余额合计。未存储数据明确为空，不补造手机、照片评分或历史消费。

账目按月分页，读已有点单付款、活动付款/退款、储值流水与消费提成；金额带千分位，币种独立。备注追加记录，显示操作人和时间，幂等重试不重复。会员状态仅超级管理员可调整，确认原因、并发状态与保护管理员账户；待注册申请不能被该操作直接批准。

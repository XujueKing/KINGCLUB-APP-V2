# 合作者名录的负责范围

用户更正：超级管理员不分区域；省级合作者在其负责省份的下辖地区都应显示。城市筛选以管理范围匹配合作者，不再一律使用申请登记城市。

合作者名录选择城市时，可信配置中的超级管理员在所有城市显示；省级合作者按已指定省级代码包含该省所有同源市级代码（含直辖市、特别行政区）；区域合作者按已指定市级代码显示；普通合作者按最新已批准申请的登记城市显示。未选择城市仍显示完整名录。搜索、性别/到店过滤、状态、分页及读取授权保留。客户名录仍按会员城市筛选，不把合作者范围带到普通会员查询中。范围未指定不能推断为管理权或全省范围，不增加多级提成或授予平台权限。

超级管理员详情的负责区域显示“全平台”，不显示合作登记城市或“未分配”；设置界面仍不能修改可信超级管理员。其他身份保留登记城市与指定负责范围的区分。

每次名录筛选仍为一个 K261007002030 请求和 kingclub_partner_workbench→kingclub_partner_customers 一次调用。新增414迁移修改名录匹配过程，原412/413保持不动。验证覆盖两个湖南城市和省外、指定区域与登记城市冲突、两名独立管理员及搜索/授权/稳定分页。

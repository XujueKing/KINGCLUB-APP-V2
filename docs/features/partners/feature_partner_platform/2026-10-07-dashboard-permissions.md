# 合作平台工作台与授权

按用户最新确认：顶部使用本人头像、昵称及“合作者”标签；收益卡显示本月入账、可提现及待结算，随后是合作伙伴码、领取任务，个人列表为我的派对、提成明细、我的特约顾客、我的团队、任务记录。保持现有深色卡片与52dp胶囊按钮。

平台管理独立放在个人内容下方。提现审核、申请审核、任务发布、任务验收、客户名录分别授权；普通合作者不可见。权限管理仅超级管理员可操作，使用KM会员号选择已有会员，不自动授予任何真实账号权限。授权保留版本与操作记录，撤回后服务端立即重新校验。

领取任务与任务管理分开：领取页无创建/发布入口，商家身份不授予平台任务权限。按用户随后纠正，商家从商家平台发布本店任务，服务端验证门店所有者及任务归属；不获取平台任务或其他门店任务权限。平台管理员必须有任务发布权限。一次页面/动作仍调用K261007002030，由数据库过程返回个人资料、真实账本汇总和能力列表，客户端不推断权限。

新增权限记录仅用于平台管理，不与门店收银授权混用；直属团队及原分佣账本、七天结算规则保持不变。

## 已确认的产品边界

- “我的 → 专属客服”替换为“合作平台”。面向平台审批通过的营销、带局者和地推合作伙伴，不是商家员工管理后台。
- 门店按有效消费金额给平台 20%–40%，门店确定比例。营销同样按有效消费金额计算，不按平台佣金计算。
- 2026-10-07最终确认：有效消费只计微信、平台余额实际支付的消费金额；**本店储值本金、赠送金额、优惠券、金币均不计入**。组合支付逐顾客拆分支付来源，只对符合条件的部分计佣；退款按原归因扣回对应提成。此口径覆盖此前“本店储值本金计入”的答复。
- 用户于本轮确认：**15级，L1=6%，每级+1%，L15=20%**。消费1,000、商家30%、营销10%时，平台收入300、营销收入100；未扣其他奖励及费用前平台留200。
- 独立分佣账户，可申请提现或转入平台余额；不能混同本店储值卡、平台消费余额、活动押金。
- 任务包括注册获客（注册后扫合作伙伴码关联，按评分奖励8–20元）及未来商户签约获客。商家可以发布任务，平台支付营销个人。
- 特约顾客消费佣金拟用可配置2%，覆盖旧固定5%；保留提成明细、我的特约顾客。
- 客户名录仅超级管理员。预约座位管理等首页预约闭环后再开发；此模块不包含收银、编辑发布、软件设置。

## 合作身份与商家主体

2026-10-08 用户确认：合作体系有四种身份。超级管理员、省级合作者、市级合作者属于管理员部分，另有普通合作者。省级合作者只负责组织市区域合作者；市级合作者和普通合作者执行申请成为商家的任务。

商家经营主体一般由一个普通会员账号作为该主体的超级管理员管理。合作平台管理身份、商家主体管理权限和 L1–L15 收益等级分别定义；商家入驻任务的执行归因与商家管理员账号分别记录。

四类身份及区域权限尚未完整实现，详细权限和审批流程待设计。已确认职责见 [合作身份与权限设计](DESIGN.md)，商家侧见 [商家身份页](pages/merchant/DESIGN.md)，需求来源为 [RQ-20261008-01](../../../product/2026-09-09-native-product-review/REQUIREMENT_INBOX.md)。

## 实施顺序

1. 合作入口、申请状态、合作首页及权限；先验收统一UI。
2. 合作伙伴码、特约顾客、任务领取/绑定/验收；对接真实一次性事件。
3. 活动/订单归因、商家比例、等级、奖励计算和独立分佣账本。
4. 提现、转平台余额、通知和超级管理员名录，完成并发、退款、权限验收。

每个阶段按仓库的一页/一次动作→一次超级接口→一个存储过程规范推进；不导入旧账户、不执行历史奖励、不改真实余额。

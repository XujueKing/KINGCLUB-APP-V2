# App Shell 交互

## 主目的地

- 轻触切换；每个目标的触控区域至少 48×48 logical px。
- 图标、文字、selected 状态同时变化，不能只用金色区分。
- VoiceOver/TalkBack 朗读“首页，标签，已选中”等明确语义。
- 消息徽标作为同一语义节点的补充，不单独抢焦点。

## 消息聚合徽标

- 聚合规则为 `系统通知未读 + 好友会话未读`，本地演示初始值为 `3 + 2 = 5`。
- 阅读一条系统通知后总数减一；系统通知全部已读后只保留好友会话未读；进入好友单聊、手动标为已读或删除该 Fake 会话后清除好友会话未读。
- 将好友会话手动标为未读时增加 `1` 条 Fake 未读；同一来源只保留最新值，不重复累加。
- 轻触或重按“消息”、切换通讯录/聊天、展开/折叠置顶聊天均不清零。
- TalkBack/VoiceOver 在消息标签语义内补充“5 条未读”等信息；聚合为零时不朗读未读数量。

## 中央扫码

- 点击立即进入打开中状态，300ms 去重；等待权限/页面建立期间不能再次打开。
- 长按没有隐藏功能；不允许扫描动作被营销活动替换。
- 扫码页取消、拒绝权限、识别失败均回到原分支，不改变其栈和滚动位置。

## 重按与返回

- 子页重按当前 Tab：回该分支根。
- 根页重按当前 Tab：滚动到顶；若页面已在顶端则不产生可见抖动。
- Android 返回和 iOS 侧滑遵循功能级 [返回规则](../../navigation_and_back.md)。

## 防误触

- 底部栏高度和安全区一起计算，不让 Home Indicator 覆盖按钮。
- 键盘出现时是否保留底栏由具体页面决定；聊天输入页不得因键盘导致扫码按钮遮挡输入。
- 全屏媒体、相机和支付确认页可以按页面文档隐藏底栏，但仍属于当前分支/上层路由。

# KC-P-010 App Shell UI 审核

- 审核日期：2026-08-28
- 审核范围：五个固定一级目的地、悬浮底栏、未读徽标、安全区域和根级返回

## 用户目标与无障碍目标

会员可以在首页、消息、内容、私人储物柜和我的之间稳定切换，始终知道当前分支；底栏不遮挡关键操作，并能由 TalkBack 朗读标签、选中态和未读数。

## 已确认优势

- 五个目的地固定且始终保持同一顺序，没有服务端动态菜单或隐藏的第六分支。
- 当前项同时使用形状/底色和无障碍 selected 语义，不只依赖颜色。
- 消息徽标与消息语义合并，不额外抢占焦点；`0` 隐藏、超过 `99` 显示并朗读 `99+`。
- 每个目的地触控区域在三种目标视口和 100%/130%/200% 字体下均不小于 48×48 logical px。
- 离线提示保留当前分支；会话和会员切换状态会锁住新的底栏导航。

## 风险与边界

- 截图只能确认可见层级和遮挡，不能单独证明真实 TalkBack 手势、系统高对比算法或 Android predictive-back 动画；语义与返回行为由 Widget 测试补充验证。
- 五分支目前只保存进程内 UI/Fake 状态；进程重启后的会话复核仍属于启动鉴权阶段。
- 本次不验证真实网络恢复、WebSocket 未读同步、推送或服务端会员状态变化。

# 分支栈、返回与生命周期

- 文档状态：`Approved for Development`

## 1. 分支栈

- 四个主目的地各自维护独立进程内分支栈；切换 Tab 时保留该分支的页面层级和非敏感 UI 状态。
- 中央扫码是 Shell 上层全屏页面，不拥有分支栈；关闭或失败返回来源分支。
- 登录成功使用 reset 创建 Shell，并固定从首页分支根开始。
- 注销、撤销、账号不可用或会员状态失效会销毁全部分支栈和页面状态。
- V1 不持久化 Router 栈；进程被系统杀死后从 `/auth/bootstrap` 重新鉴权并回首页根。

## 2. Tab 点击

| 当前状态 | 点击行为 |
|---|---|
| 点击其他 Tab | 切换到该分支并恢复其进程内栈 |
| 当前分支在子页，再点当前 Tab | pop 到该分支根页 |
| 已在分支根页，再点当前 Tab | 发出 `PrimaryDestinationReselected`，由根页滚动到顶；不自动发真实请求 |
| 连续快速点击 | 300ms 内同一动作去重，导航动画期间不并发执行 |
| 点击中央扫码 | 单次打开 KC-P-012；正在打开或权限弹窗中忽略重复点击 |

## 3. 系统返回优先级

```text
临时弹层/键盘（按页面规则）
  -> 当前分支子页 pop
  -> 非首页根分支切换到首页根
  -> 首页根交给系统后台/退出语义
```

- Android predictive back 预览必须与最终目标一致。
- iOS 侧滑返回只作用于当前分支子页，不能滑回登录流程或另一个 Tab。
- 支付、注销、正在提交的表单等需要确认时，由具体页面文档覆盖第一优先级。

## 4. 前后台与状态保留

- 短暂前后台切换保留选中 Tab、分支栈和页面非敏感状态。
- 回前台先由 session 层复核粗粒度状态；Shell 不自行刷新 Token 或连接 WebSocket。
- session version 改变后，旧页面异步结果和旧导航 generation 全部丢弃。
- 内存压力允许页面释放重资源，例如视频播放器和相机；回到页面时由页面状态机恢复占位/播放条件。

## 5. 网络与全局状态

- 离线不强制离开 Shell；显示可关闭/可恢复的全局网络提示，由各页面决定缓存、空态或重试。
- 全局致命启动错误只属于 BootstrapHost，不在 Shell 内展示。
- 会话失效不通过普通错误页处理，必须在 session 清理完成后 reset 登录。

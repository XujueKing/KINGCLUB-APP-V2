# 统一搜索输入样式

用户要求搜索框与合作者平台保持同一灰色背景、无边框风格；聊天不能继续用棕色半透明输入底色。

背景采用合作者申请卡片的 #1C1C1E，中性白色文字 16sp、浅灰提示。公共输入主题与搜索装饰使用同一无边框规则。搜索框 12dp 圆角、52dp 最小高度，大字时随内容增高，聚焦及禁用不出现其他颜色轮廓。注册封面已确认的胶囊输入与聊天发送栏保留既有专用组件。

覆盖会话列表、通讯录、找朋友、创建群聊、聊天记录搜索、转发选择、单聊详情、群成员、发送位置、首页城市、资料城市、扫码点单、客户名录、任务选客。公共装饰保留原有清除、提交、查询、焦点与键盘行为。

客户名录改为会员 / 合作者 / 审核中 / 黑名单。参考旧小程序视觉占比，20sp 标准字重、60dp 点击行和下划线；常规中文四列均分，长语言及大字模式横向滚动，不压缩字号。详情会员 / 账目 / 备注同样式；联系电话放大至 16sp。

验收聚焦前后灰色一致无边框、四语言大字无溢出、查询及分类功能不变。截图只用合成资料。

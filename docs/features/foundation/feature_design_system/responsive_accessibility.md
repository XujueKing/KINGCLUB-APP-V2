# 响应式与无障碍

- 文档状态：`In Review`

## 1. 首发尺寸基线

| 视口 | 用途 |
|---|---|
| 360×800 | 窄 Android 基线 |
| 393×852 | 主流 iPhone 基线 |
| 430×932 | 大屏手机基线 |

- 宽度小于 360 时仍须无水平溢出，但不承诺专门视觉优化。
- 手机横屏仅保证关键流程不崩溃和可完成；相机、视频、二维码可按页面文档定义方向。
- 宽度大于 600 时内容最大宽度 600 并居中；平板多栏布局后续评审。
- 必须使用系统 SafeArea/MediaQuery，不能复制旧版手算状态栏高度。

## 2. 字体缩放与重排

- 测试 100%、130%、200% 系统文字缩放。
- 主要按钮、金额、协议勾选、错误提示和安全说明不得截断。
- 底部导航在极端缩放时保持图标与可访问名称；可缩短可见标签，但语义标签保持完整。
- 列表项允许增高；禁止用固定高度强行裁切多行内容。

## 3. 可访问性

- 所有交互目标至少 48×48 logical px，目标之间保留可辨间距。
- 焦点顺序与视觉阅读顺序一致；弹窗打开后焦点进入弹窗，关闭后回触发点。
- 图标按钮提供中文语义标签；装饰图片从语义树排除。
- 图片/视频的业务信息提供替代说明；验证码、二维码本身不可替代时说明用途和可用操作。
- 动态徽标、加载和提交结果通过 live region/语义公告表达，但避免重复朗读。
- 支持 VoiceOver、TalkBack、粗体文字、减少动态效果和高对比检查。

## 4. 键盘与输入

- 输入页在键盘弹出时保持当前字段、错误信息和主动作可见。
- 焦点不能被异步重建抢走；验证码自动填充仍需用户主动提交或批准的自动提交规则。
- 外接键盘基础 Tab/Shift+Tab/Enter/Escape 路径在表单和弹窗中可用。

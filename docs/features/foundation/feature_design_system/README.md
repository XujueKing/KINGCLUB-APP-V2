## 目标

为 48 页提供统一、可复核的品牌语言和交互基础，避免旧版页面各自散落颜色、字号、圆角、弹窗和状态样式。

## 已确认事实

- 旧版以黑色背景、香槟金 `#C9B69E`、白色正文和棕金渐变为主要视觉语言。
- 旧版存在 `logo_2.png`、`KINGCLUB.png` 及多套 Tab 图标，但是否直接复用仍需逐项检查清晰度、授权和多倍图适配。
- 首发目标为 Android API 24+ 与 iOS 15+ 手机端。

## 已确认方案

- 首发只冻结深色主题；浅色主题不进入本期 M1，避免 48 页同时维护两套未经业务验证的视觉状态。
- 延续“黑曜石 + 香槟金”品牌方向，但减少大面积发光、复杂渐变和低对比透明文字。
- 字体使用平台系统字体；品牌定制字体只有在授权、中文字符覆盖和包体影响确认后再评审。
- 颜色、间距、圆角、排版、动效全部通过语义 Token 使用，页面不得直接写十六进制颜色或任意尺寸。

## 页面清单

本功能不拥有业务页面；本期全部 48 页依赖 `Design System v1`。

## 不包含

- 浅色主题、平板专用导航和桌面端规范。
- 未经确认的自定义字体、3D/游戏引擎视觉或全局玻璃拟态。
- 业务专属复杂组件；它们应在所属功能文档中定义，并只复用本系统 Token/基础控件。
- 直接复制旧版低分辨率素材进入 Flutter assets。

## 已确认决策

1. 延续黑曜石 + 香槟金的高端夜生活品牌方向。
2. 首发仅做深色主题，浅色主题后续独立评审。
3. 系统字体优先，不在首发引入未授权品牌字体。
4. 旧 Logo 暂作为品牌参考，UI 阶段前再确认最终矢量/高清源文件。

## 开发门禁

本设计系统与全部 48 页均已达到文档准入，可以在 UI/Mock 阶段创建 Flutter Theme/组件代码。

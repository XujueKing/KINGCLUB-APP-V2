# 全 APP 右滑返回

- 状态：Approved for Development（用户 2026-10-07 要求全 APP 支持右滑返回）
- 范围：iOS / Android 客户端导航；不涉及接口或数据库变更。

## 交互

从屏幕左侧边缘向右滑返回上一页，左上返回按钮保留。普通内页跟手滑动，可中途取消；复用 Flutter Cupertino 的导航手势控制器，覆盖 MaterialPageRoute、KingPageRoute 与 GoRouter MaterialPage。

有 PopScope / 内部返回历史的页面先执行现有 maybePop 返回规则，不绕过未保存确认、支付处理中限制或聊天面板。auth/onboarding 使用 go 建立的步骤页执行同一受控返回，取消手势不清理流程。欢迎、启动、首页等没有可见返回的根页不通过右滑退出 APP。

首页内容详情保留原展开动画，通话保留最小化 / 结束确认，补充同一边缘手势。扫码业务结果沿现有规则回到扫码前入口，摄像头不能重新出现在结果页后面。

仅边缘手势触发导航；中部横向分页、竖向滚动、轻微拖动不触发返回。路由切换时禁止再次手势提交，避免连续 pop。

## 验证与交付

覆盖双平台完整返回与取消、GoRouter 生成页、受控根步骤、PopScope、内部历史、聊天面板、内容详情、通话及扫码结果栈。验证后记录实际结果和手机安装版本。

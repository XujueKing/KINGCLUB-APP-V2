# 真实模式演示入口隔离

依据：用户同意按新机器功能审计建议整改；本轮仅能力隔离，不接新的服务。

## 页面与状态

复用当前内页标题栏、返回箭头与全局转场。在内部 `/feature-unavailable` 展示固定 allowlist 功能名称与真实服务暂未开放说明；简体、繁体、英文、泰语文案齐备。仅返回，无写入、查询或成功凭证。此为既有功能不可用状态，不新增业务功能。

路由跳转前拦截支付 PIN、永久注销、订单列表/详情/演示支付、资产流水、AA/VIP/入场凭证，以及缺少真实桌台/报价上下文的点单流程。存在真实 API 配置、真实认证仓库或真实会员快照任一条件即启用，不等待会员异步加载。返回优先 pop；独立进入时回首页并继续既有登录守卫。

Mock 模式保留原流程供离线测试。有效桌台点单、真实支付页、注册、聊天和真实资料路由不受本门禁替换。未开放不等于没有订单/资产；不隐藏真实支付页的服务端确认。

## 验收

- 用真实仓库（无网络替身）及真实会员快照分别覆盖上述路由。
- 直接进入带参数或缺少 extra 的旧支付路由也先阻断，不构造 Fake 页面。
- 原 Mock 跨页测试通过；返回栈及四语言窄屏测试通过。
- 未连接后端，不能将门禁记为订单查询或注销已实现。

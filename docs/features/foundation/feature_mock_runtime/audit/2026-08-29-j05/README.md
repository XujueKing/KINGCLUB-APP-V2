## 验收路径

1. 从发现 Tab 浏览只读作品流，确认默认静音并且不出现点赞、评论、收藏、分享或关注入口。
2. 从作品作者入口进入“晨曦”用户主页，验证返回后仍保持发现 Tab 和原内容上下文。
3. 进入关系权限页执行拉黑，确认子页使用当前显示名，主页原子切换为“解除拉黑”且消息入口同步消失。
4. 执行解除拉黑，确认主页恢复陌生人状态并显示“添加到通讯录”。
5. 提交好友申请，确认申请页自动带入“晨曦”，返回主页后原子切换为“等待对方验证”。
6. 分别验证作品流加载、空数据和首次加载失败分支。

## 本轮发现与修复

- 修复用户主页向关系子页传递固定占位名“好友”的问题；确认文案和申请备注现使用当前主页显示名。
- 移除路由层绕过主页状态消费的回调，申请、备注、删除和拉黑结果统一返回主页并原子更新关系按钮。
- 新增回归用例，覆盖实际显示名传递、拉黑后的按钮组合、申请备注预填和出站等待状态。
- 本期已批准范围不包含关注/粉丝关系；发现页保持只读，不在 J05 中重新加入关注按钮。

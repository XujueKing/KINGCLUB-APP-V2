## 验收路径

1. 从 App Shell 进入“我的”，核对旧版头图、空白头像、资料、统计、资产、我的订单及内容页签。
2. 进入编辑资料，核对固定右侧值列、箭头列和完整偏好字段；系统返回回到同一“我的”分支。
3. 进入个人二维码，核对短期用途、倒计时、刷新和不暴露永久账号的说明。
4. 从余额进入四分类账单，从“我的订单”进入统一订单中心；两页只传受控引用，不执行支付或资产写操作。
5. 进入设置，依次验收支付安全、关于与法律、账号注销首屏及底部确认区。
6. 连续系统返回后仍停留在“我的”Tab，个人页没有被 App Shell 重建。

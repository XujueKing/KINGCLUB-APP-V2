# 超级接口验收

- [ ] handshake 与 API Key 两种请求均有正常和拒绝测试
- [ ] `interfaceKey` 对必填、类型、范围和额外字段生效
- [ ] 客户端不能伪造或覆盖可信用户上下文
- [ ] 未登录接口无法调用 session 接口
- [ ] 用户 A 无法通过替换 ID 操作用户 B 的对象
- [ ] 重放、过期时间戳、错误签名和重复 requestId 被拒绝
- [ ] Routine 只从服务端上下文取得当前用户身份
- [ ] 响应和日志不暴露 SQL、Routine 名、密钥或敏感业务数据
- [ ] 每个新接口完成分类、Routine 目录、权限、审计和文档登记
- [ ] Flutter SDK 有跨平台加密测试向量

# 原生能力隐私、测试与真实接入边界

## 隐私与数据生命周期

- 只申请完成当前任务所需的最小权限；权限用途文案必须与实际行为一致。
- 图片/视频进入业务上传前先在 App 内确认；取消、失败、退出登录或切号时清理临时引用。
- 不记录本地文件路径、EXIF、坐标、二维码原文或系统权限对象全文。
- 定位使用明确精度与生命周期；本期不持续后台采集，不用定位构建未批准画像。
- 通知权限拒绝不影响 App 内查看信息，不用无关功能强迫开启。

## UI/Mock 测试

- 每个使用能力的页面覆盖成功、取消、首次拒绝、永久拒绝、受限、无硬件、插件错误和会话失效中的适用状态。
- Fake 支持从系统设置返回后的状态变化、重复点击和迟到结果。
- UI 测试不读取真实相册、相机、位置、通知或设备标识。

## 真实接入验收

- `UI Flow Approved` 后按能力逐项选择插件，并核对维护状态、平台兼容、隐私清单和许可证。
- iOS Info.plist、Privacy Manifest 与 Android Manifest 只声明已批准能力；构建产物做权限清单审计。
- Android/iOS 真机分别验证首次安装、拒绝、永久拒绝、设置恢复、升级安装、前后台和无服务状态。
- 某能力接入失败可回退到批准的无权限路径；不得让 App 启动失败。

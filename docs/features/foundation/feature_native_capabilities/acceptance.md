# 原生能力与权限验收

## 文档准入

- [x] 相机、相册、扫码、通知、定位、预览和设置端口边界明确
- [x] 页面/能力矩阵、请求时机、最小权限和降级路径明确
- [x] 首次拒绝、永久拒绝、受限、系统关闭、无硬件和插件异常明确
- [x] 生命周期、重复请求、迟到结果、会话失效和临时数据清理明确
- [x] UI 阶段只用 Fake，真实插件与平台声明后置
- [x] 隐私、测试、真机验证和失败回滚目标明确
- [x] 用户于 2026-08-26批准 `Native Capabilities v1`

## UI 实现验收

- [ ] 使用能力的页面覆盖批准的 Fake 权限与结果状态
- [ ] 页面不直接依赖插件或平台异常字符串
- [ ] 拒绝/取消后仍可使用不依赖权限的流程
- [ ] 设置返回、生命周期和迟到结果不会触发错误导航或上传
- [ ] Mock 构建不访问真实相机、相册、位置或通知权限

## 真实接入验收

- [ ] 双端权限声明与实际用途、隐私文本和构建清单一致
- [ ] 首装、拒绝、永久拒绝、设置恢复、升级和前后台完成真机测试
- [ ] 临时媒体、坐标、扫码内容和日志符合最小化与清理规则

当前批准仅允许 UI/Mock 实现，不代表真实原生能力已经接入。

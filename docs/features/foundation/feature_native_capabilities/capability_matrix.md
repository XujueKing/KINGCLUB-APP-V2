# 原生能力与页面矩阵

| 能力 | 使用页面/功能 | V1 请求时机 | 无权限降级 |
|---|---|---|---|
| 相机扫码 | KC-P-012 安全扫码 | 用户点击开始扫码 | 手动返回；不接受任意文本冒充二维码 |
| 相机拍摄 | KC-P-006 会员形象、KC-P-041 编辑资料 | 用户选择“拍摄” | 改用系统相册选择器或取消 |
| 相册/文件选择 | KC-P-006、KC-P-041、聊天适用媒体入口 | 用户选择“从相册选择” | 保留拍摄/取消；不要求全库扫描 |
| 通知权限 | 消息、系统通知、订单状态提醒 | 用户理解用途后主动开启 | App 内消息/订单状态仍可查看 |
| 定位 | 门店/同城内容中明确需要的位置动作 | 用户发起附近/定位动作 | 手动选择城市/门店；本期不后台定位 |
| 媒体预览 | 作品流、头像、聊天媒体 | 打开已获准的本地/Mock 资源 | 展示占位和重试，不扩大存储权限 |
| 系统设置跳转 | 永久拒绝或系统服务关闭 | 用户点击“前往设置” | 留在当前页并说明受限能力 |

## 结果模型

所有能力返回类型化结果：`success/cancelled/denied/permanentlyDenied/restricted/unavailable/error`，并可携带稳定原因、可否重试和脱敏 requestId。业务页面不得解析插件异常字符串。

## 不进入本期

- 私人储物取件码只展示给员工扫描，不调用会员 App 扫码能力。
- 支付、推送送达、地图导航和后台任务的真实 SDK 属于后续集成工作包。
- 通讯录功能使用服务端好友关系；本期不申请系统通讯录读取权限。

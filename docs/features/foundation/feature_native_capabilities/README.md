## 目标与用户价值

统一相机、相册、扫码、通知、定位、媒体预览和系统设置跳转的权限状态与平台差异。

## 页面清单

本功能不拥有业务页面；权限拒绝、永久拒绝和恢复状态由使用能力的页面负责展示。

## 待设计内容

- iOS/Android 权限用途、请求时机和最小权限
- 首次拒绝、永久拒绝、系统关闭和受限设备状态
- UI Mock 阶段的 Fake 权限与 Fake 扫码/媒体结果
- 隐私清单、平台配置、埋点和真机验收矩阵

## 开发门禁

UI Mock 阶段只能使用 Fake 平台能力。项目达到 `UI Flow Approved` 后，才允许接入并验证真实插件或 Platform Channel。

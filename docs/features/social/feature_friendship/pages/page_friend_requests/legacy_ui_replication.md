# 旧版“新的朋友”UI 复刻规范

- Scope ID：`KC-P-016`
- 文档状态：`Approved for Development`
- 设计版本：`Legacy Friend Requests Replica v1`
- 视觉来源：用户于 2026-08-26 提供的通讯录双入口截图，以及旧版 `pages/newfriend`
- 数据阶段：全部离线 Fake，不连接服务器

## 页面结构

- 黑色背景，顶部居中标题 `新的朋友`，左侧返回，右侧添加图标。
- 列表采用旧版单列布局：头像、昵称、申请时间、验证消息、右侧状态或 `查看`。
- 首屏放置 2 条 Fake 新申请，与通讯录入口角标 `2` 一致。
- 点击申请打开本地申请详情面板；接受/拒绝只改变当前内存状态。
- 点击右上添加进入旧版“添加朋友”页面。

## 禁止项

- 不请求超级接口、WebSocket 或真实好友数据。
- 不显示手机号、实名或真实永久账号。
- 不把本地接受操作视为真实好友关系。

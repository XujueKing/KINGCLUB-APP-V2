# KC-P-018 旧版 UI 复刻基线

- 文档状态：`Approved for UI Mock`
- 视觉基线：旧版 `pages/createfriendinfo/createfriendinfo.wxml` 与 `createfriendinfo.wxss`
- 数据方式：仅本地 Fake，不调用好友超级接口或 WebSocket
- 最后更新：2026-08-27

## 复刻结构

1. 黑色全屏背景，左上旧版返回按钮，居中标题“申请添加朋友”。
2. 主体宽度沿用旧版 600rpx：先显示“发送添加朋友申请”标签和 90rpx 深灰输入框。
3. 第二组显示“设置备注名”标签和同规格输入框。
4. 底部保留 600rpx 宽“发送”按钮，并维持旧版较大的底部留白区域。

## Fake 行为

- 验证消息默认“我是 KingClub 会员”，允许 0～80 字。
- 私有备注默认目标公开昵称，允许 0～24 字，仅自己可见。
- 发送期间按钮显示处理中并禁止重复点击；450ms 后本地返回 `sent`。
- 发送成功后关闭本页，用户主页原子切换为“等待对方验证”。
- 草稿存在时返回需确认放弃；空白草稿直接返回。

## 安全边界

- 页面只接收进程内 `targetRef` 与公开昵称，不显示或传递永久账号、手机号、实名或 conversationId。
- 不发送 WebSocket，不创建真实好友申请，不持久化验证消息或备注正文。
- 错误、重复申请和目标不可用只使用稳定 Fake 状态，不展示服务端原文。

## UI 验收基线

- Android 竖屏首屏完整展示两个输入框和发送按钮，键盘出现时页面可滚动。
- 输入计数、提交中、提交成功、放弃草稿路径可重复演示。
- 视觉使用旧版黑、灰输入框与香槟金文字，不增加新版卡片或装饰元素。

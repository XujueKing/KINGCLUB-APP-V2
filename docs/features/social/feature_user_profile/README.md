# 统一用户主页

- Scope ID：`KC-F-017`
- 文档状态：`In Review`
- 所属业务域：`social`
- M0 范围：`In Release Scope`
- 设计版本：`Social User Profile v1`
- 最后更新：2026-08-25

## 目标与用户价值

用一个权威页面呈现陌生人、申请人、好友和已拉黑用户的允许信息与可执行动作，避免因入口不同产生互相矛盾的资料页。

## 已确认事实

- 旧版 `friendinfo`、`newfriendInfo`、`userInfo` 三套页面重复显示资料，却各自信任不同 URI 参数和本地状态。
- 旧页面显示/复制永久账号、颜值、收入、粉丝和作品等信息，并在同页混合关注、聊天、好友与分组操作。
- 本期已移出关注/粉丝详情、作品/动态/相册发布和角色管理；个人中心也已确认隐藏永久账号。

## 当前建议

- 只展示 `PublicMemberProfile` 允许字段：头像、公开昵称、认证标识、简介、城市/区域、职业、身高和批准的兴趣偏好。
- 不展示永久账号、手机号、实名、精确生日/年龄、IP、收入、颜值或内部审核原因。
- 页面动作完全来自权威 `relationshipState + allowedActions`：陌生人发申请、入站申请接受/拒绝、好友发消息/备注/权限、已拉黑用户仅显示有限状态。
- 不保留关注关系；M0 只围绕好友申请、好友、拉黑和单聊。
- 用户主页不展示作品/动态/相册列表，内容浏览归 KC-P-013。

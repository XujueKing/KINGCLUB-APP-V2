# KC-P-017 旧版 UI 复刻基线

- 文档状态：`Approved for UI Mock`
- 视觉基线：旧版 `pages/friendinfo/friendinfo.wxml` 与 `friendinfo.wxss`
- 数据方式：仅本地 Fake；不访问用户、好友、消息或媒体接口
- 最后更新：2026-08-27

## 复刻结构

1. 黑色全屏背景，左上角旧版金色返回按钮，不额外增加 App 标题栏。
2. 顶部资料区使用 120rpx 方形圆角头像，右侧依次展示备注/昵称、性别与认证标识、公开昵称和签名。
3. 第一组菜单为“朋友资料”；好友状态显示“朋友权限”，陌生人状态显示“来源”。
4. 页面主动作单独占一行：好友显示聊天图标与“发消息”，陌生人显示“添加到通讯录”。
5. 菜单背景、分隔线、文字色和间距按旧版 `#c9b69e` 黑金比例复刻。

## V2 安全取舍

- 保留旧版布局与文案层级，但不显示旧版永久会员号、手机号、实名、颜值、收入、粉丝统计和作品列表。
- 原“会员号”行改为“昵称”；页面只使用进程内 `targetRef` 选择 Fake 投影。
- “朋友资料”“朋友权限”“发消息”“添加到通讯录”在本阶段只演示本地交互，不创建真实关系或会话。
- 头像使用项目内旧版默认头像资产；不下载远程媒体。

## Fake 状态

- `friend`：默认从通讯录进入，显示朋友资料、朋友权限和发消息。
- `stranger`：显示来源和添加到通讯录，点击后本地变为“等待验证”。
- `incomingPending`：显示验证消息与接受/拒绝。
- `outgoingPending`：显示等待验证，只读。
- `blockedByMe`、`offlineCached`、`targetUnavailable`：保留旧版页面骨架并显示安全状态提示。

## UI 验收基线

- 以 Android 模拟器 393×852 逻辑尺寸为主视口。
- 头像资料区、两组菜单和主动作在首屏完整可见。
- 页面无真实账号、手机号或接口状态泄漏，无“离线 UI Mock”占位页。
- 返回通讯录路径有效；主动作具有可重复的本地反馈。

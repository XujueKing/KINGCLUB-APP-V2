# 通讯录

- Scope ID：`KC-F-015`
- 文档状态：`Approved for Development`
- 所属业务域：`social`
- M0 范围：`In Release Scope`
- 设计版本：`Contacts v1`
- 最后更新：2026-08-25

## 目标与用户价值

让会员快速找到已经建立好友关系的 KingClub 联系人，查看新申请，并安全进入统一用户主页或后续单聊流程。

## 已确认事实

- 旧版通讯录嵌在 `pages/index/index` 的聊天分支，和会话列表共享搜索、刷新和大量页面状态。
- 旧版直接把 `otherUserAccount` 拼入用户主页路由，列表结果还混入服务端下发 tab 数据。
- App Shell 已确认“消息”分支承载通讯录与会话；本期保留好友关系和稳定单聊，不包含完整群聊。
- 个人中心已确认不展示或复制永久统一账号，好友连接使用短期二维码。

## 用户已确认方案

- 通讯录只表示 App 内已经建立的好友，不等同于手机系统通讯录。
- 顶部固定提供“新的朋友”和“添加好友”；黑名单从页面更多菜单进入，不与正常好友混排。
- 支持按好友备注名和公开昵称搜索；不支持按手机号、实名或永久 `userAccount` 搜索。
- 以服务端返回的稳定 sectionKey 分组，客户端可展示拼音首字母，但不把本地排序结果当作权威关系状态。
- 不申请系统联系人权限，不上传手机号码簿。

## 本期不包含

- 系统通讯录同步、手机号/账号搜索、附近的人、雷达、推荐好友和批量邀请。
- 会话列表、消息未读聚合和聊天传输；这些由 messaging 域负责。
- 关注/粉丝列表、群成员目录或运营人员目录。

## 用户已确认决策（2026-08-25）

1. “通讯录”只做 KingClub 好友列表，不读取或上传手机通讯录。
2. 搜索只匹配公开昵称和自己的好友备注，不支持手机号、实名或永久账号。
3. 顶部固定“新的朋友/添加好友”，黑名单放到更多菜单。

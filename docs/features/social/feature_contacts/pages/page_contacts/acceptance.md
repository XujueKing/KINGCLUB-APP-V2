## 正式验收记录（2026-08-28）

- `ready`：聊天切换、新的朋友、添加好友、黑名单和用户主页出口均可用。
- `empty / fatalError`：空态可进入添加好友，致命错误可安全重新加载。
- `offlineCached / partialError`：保留已加载好友，展示明确状态并允许安全恢复。
- `avatarFailure / relationshipChanged`：头像失败使用本地图标；已解除关系的联系人不会残留。
- `sessionInvalid`：清除好友快照和搜索词、停用入口并请求全局登录重置。
- 搜索仅匹配公开昵称或私人备注，手机号与永久账号均无结果。

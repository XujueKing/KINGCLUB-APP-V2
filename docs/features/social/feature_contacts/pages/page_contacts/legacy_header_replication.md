## 已确认事实

- 通讯录主体区域继续使用当前已验收实现，不调整搜索、快捷入口、好友分组、索引和状态。
- 只把顶部区域从“大标题 + 副标题 + 测试/更多按钮”改为旧版居中双选项。
- 左侧保留旧版细圆圈加号，点击生成现有“添加好友”Fake 意图。
- `通讯录` 为香槟金亮色粗体选中态；`聊天` 为低透明度未选中态。
- 顶部底部保留一条低透明度横向分割线。
- 忽略参考图右侧的微信宿主按钮；Flutter App 不绘制对应按钮，也不保留占位。
- 不显示原顶部的 `仅 KingClub 好友`、UI 测试烧杯和更多按钮。

## 尺寸与样式

- 顶部有效高度约 `66dp`，内容在安全区内垂直居中。
- 左侧加号距页面左侧约 `17dp`，使用香槟金描边圆形图标。
- 双选项整体水平居中，两项间距约 `6dp`。
- 通讯录字号约 `20sp`、粗体；聊天字号约 `16sp`。
- 分割线左右留白约 `24dp`，颜色为低透明度香槟金/深棕。

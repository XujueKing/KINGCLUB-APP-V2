# KC-P-019 旧版 UI 复刻基线

- 文档状态：`Approved for UI Mock`
- 视觉基线：旧版 `pages/friendinfo2/friendinfo2.wxml` 与 `friendinfo2.wxss`
- 数据方式：仅本地 Fake，不调用关系超级接口
- 最后更新：2026-08-27

## 复刻结构

1. 黑色页面、左上旧版返回按钮、居中标题“朋友资料”。
2. “备注”分组沿用旧版黑金列表行；保留“备注名”“描述”，移除“电话”。
3. “更多信息”分组显示签名、来源和添加时间，全部只读。
4. 点击备注名或描述后打开旧版居中编辑弹层；输入、字数限制与确认修改可本地演示。

## V2 调整

- “描述”在 V2 契约中命名为“说明”，仍保持旧版行位置和弹层编辑方式。
- 不申请通讯录权限，不显示或保存私人电话号码。
- 保存仅更新当前页面 Fake 状态；退出重进不持久化。
- 修改后返回用户主页不会携带永久账号或会话 ID。

## 验收基线

- 备注名最多 24 字，说明最多 120 字，空值允许保存。
- 有未确认编辑时关闭弹层需明确放弃；页面返回路径有效。
- 首屏完整展示两个分组，不出现真实手机号、账号或网络加载提示。

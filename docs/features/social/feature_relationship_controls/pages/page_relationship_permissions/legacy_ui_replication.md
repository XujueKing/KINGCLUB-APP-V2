# KC-P-020 旧版 UI 复刻基线

- 文档状态：`Approved for UI Mock`
- 视觉基线：旧版 `pages/friendinfo3/friendinfo3.wxml` 与 `friendinfo3.wxss`
- 数据方式：仅本地 Fake，不调用关系超级接口
- 最后更新：2026-08-27

## 复刻结构

1. 黑色页面、左上旧版返回按钮、居中标题“权限”。
2. “设置权限”分组保留“聊天、朋友圈、交友等”和“仅聊天”两项，以旧版勾选图标表达单选。
3. “朋友圈和状态”分组保留“不让他/她看”“不看他/她”两个开关。
4. 下方保留“加入黑名单”和红色“删除联系人”独立行。

## V2 调整

- 旧“朋友圈”在数据契约中对应 KingClub 内容可见性，但为复刻旧版 UI，展示文案暂保持旧版。
- 拉黑、删除必须先显示影响说明并二次确认；不再点击即提交。
- 拉黑会结束好友关系并禁止消息；解除拉黑不会恢复好友。
- 删除好友只结束好友关系，不自动拉黑，也不处理聊天记录。
- 所有选择、开关和确认结果仅修改本地 Fake 状态。

## 验收基线

- 互动范围单选与两个内容开关可重复操作。
- 拉黑、解除拉黑、删除好友都有独立确认文案和取消路径。
- 破坏性操作完成后旧开关不再可操作，不出现真实接口或永久标识。

# 内容流页交互

| 触发 | 行为 |
|---|---|
| 进入发现分支 | 加载首屏，当前项按静音偏好准备 |
| 单击内容 | 播放/暂停 |
| 点静音 | 切换声音并保存非敏感偏好 |
| 上下滑 | 串行切换当前 ContentRef |
| 点作者头像/昵称 | openUserProfile(SocialTargetRef) |
| 下拉刷新 | 暂停、重取并原子替换 |
| 离开分支/后台 | 立即暂停所有媒体 |
| 返回前台 | 重验内容与播放引用后由用户/策略恢复 |
| 媒体失败 | 只重试当前项，不重置整个 Feed |

不实现双击点赞、长按下载或系统分享；手势不能与系统返回和读屏导航冲突。

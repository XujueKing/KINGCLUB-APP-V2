# 短视频与作品浏览

- Scope ID：`KC-F-014`
- 文档状态：`Approved for Development`
- 所属业务域：`content`
- M0 范围：`In Release Scope`
- 设计版本：`Read-only Content Feed v1`
- 最后更新：2026-08-25

## 目标与用户价值

在“发现”主目的地连续浏览经过审核的同城作品和短视频，并可安全进入作者主页；首发只建立稳定浏览体验，不承诺发布或内容互动写入。

## 已确认事实

- 旧 `openVideo` 只有硬编码测试作品，真实请求和预加载逻辑被注释，初始 `videoIndex=3` 超出三条列表范围。
- 旧页面的加载状态没有在现有执行路径复位，后台/销毁时没有停止播放或释放资源。
- 点赞、收藏、关注、评论和数量均为本地演示字段，没有可靠写入、幂等、审核或结果恢复流程。
- 旧作品可包含账号、精确距离和直接媒体 URL；这些字段不能原样迁移到客户端路由或日志。
- 已批准 App Shell 将 KC-P-013 固定为“发现”主分支，明确不提供发布按钮。

## 当前建议

- 发现页采用全屏纵向单作品流，当前可见项自动播放；离开分支、切后台、来电/音频中断时立即暂停。
- 首次安装默认静音，用户主动开声后只保存非敏感播放偏好；系统静音与无障碍设置优先。
- 只预加载下一项封面和受限媒体片段；低流量/弱网模式下禁自动预加载视频。
- Feed 使用稳定 cursor；服务端返回短时媒体播放地址、审核状态与最小作者投影，客户端不拼 COS 地址。
- 首发不显示点赞、收藏、评论、分享、关注和发布入口；可点击作者头像进入已批准 KC-P-017。
- 位置只显示城市/门店级公开标签，不显示“距你 7.1km”等可推断精确位置的信息。
- 内容下架、作者不可见、媒体过期或审核状态未知时立即停止播放并安全跳过/刷新。

## 本期不包含

- D2 作品发布、上传、草稿、剪辑、审核申诉。
- 点赞、收藏、评论、分享、关注、直播、广告和个性化推荐设置。
- 真实内容接口、CDN 签名、播放器 SDK、下载或推送接入。

## 已确认产品决策

1. 首发发现页只读浏览，不提供点赞、评论、收藏、分享、关注和发布。
2. 首次使用视频默认静音；用户主动开启后记住播放偏好。
3. 仅当前可见作品播放，离开“发现”或 App 进入后台立即暂停。
4. 位置只显示城市/门店级公开标签，不展示精确距离。
5. 作者头像可进入用户主页，但内容不可见或作者受限时使用安全通用提示。

## 开发门禁

用户已于 2026-08-25 批准本版本；全部 48 页批准前不创建 Flutter UI，全局 `UI Flow Approved` 前不接真实内容、媒体/CDN 或播放器能力。

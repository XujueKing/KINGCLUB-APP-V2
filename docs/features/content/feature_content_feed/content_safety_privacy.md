# 内容安全与隐私

- 内容与作者可见性由服务端投影决定；被拉黑、已删除、审核中或违规下架的内容不应通过缓存重新显示。
- 客户端不展示 userAccount、实名、精确生日、手机号、精确坐标或精确距离。
- 媒体 URL 使用短时签名或受控引用；不得写入路由、埋点、崩溃 breadcrumb 或剪贴板。
- 缓存仅保存封面/受控媒体片段，遵守账号隔离、容量与过期策略；退出账号清理。
- 不做后台播放、自动下载和相册保存。
- 埋点只记录匿名内容引用的哈希/类别和播放阶段，不记录完整标题、作者账号或 URL。
- M0 没有举报流程页面；内容不安全时提供稳定“内容不可用”状态，正式举报能力需另立文档。

# 同城统一账号验收

- [ ] KingClub 和物业对同一已验证手机号返回同一个 `U... userAccount`
- [ ] KingClub 并发首次注册不会产生两个账号
- [ ] 相同幂等键重试返回相同账号和相同结果
- [ ] KingClub 先注册后，物业权威库存在账号、手机号身份和真实 KYC 状态占位
- [ ] 占位用户没有物业成员、房屋关系、角色或权限
- [ ] 用户以后注册物业时复用原 `U...` 并补建物业业务成员
- [ ] 未核验实名不会被错误标记为 verified
- [ ] 账号冻结/归并事件能够撤销 KingClub 会话
- [ ] KingClub 身份接口不可由 Flutter 或公网普通客户端调用
- [ ] KingClub 单设备限制不会撤销物业会话
- [ ] 钱包、订单、会员和业务权限不会跨 App 自动共享

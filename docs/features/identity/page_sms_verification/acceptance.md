# 验证码页验收

- [ ] 六位输入、粘贴和系统自动填充只触发一次登录请求
- [ ] 错误码、过期、限流、离线、服务不可用和身份人工审核均有稳定映射
- [ ] 重试登录不重复发短信，重发后旧 challenge 不再被客户端使用
- [ ] 一次性凭据整体写入安全存储；任一写入失败不留下半会话
- [ ] 新设备登录后旧设备 HTTP/WS 会话失效，新设备正常进入目标路由
- [ ] 返回、前后台切换和进程重启不会把验证码存入普通持久化
- [ ] 日志、埋点、崩溃报告和 URL 不含验证码、手机号、challenge 或凭据
- [ ] Widget/集成测试覆盖成功、错误、过期、限流、双击、弱网和安全存储失败

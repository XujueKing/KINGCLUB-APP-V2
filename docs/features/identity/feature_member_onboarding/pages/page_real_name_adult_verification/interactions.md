# 实名与成年核验页交互

- 字段失焦后显示格式提示；服务端真实性错误显示在相关字段或页面摘要，不回显原值。
- 姓名和证件号码输入框仅在“未聚焦且为空”时显示占位文字；取得焦点后立即隐藏占位文字，避免光标与提示重叠；空值失焦后恢复。
- 页面不显示证件查看按钮；恢复成年声明勾选行，未勾选时点击“人脸核验”给出提示并留在当前页；离开页面或后台立即清理证件输入，不提供复制入口。
- 点击完整胶囊“人脸核验”后直接进入 Fake 核验，不再弹出重复确认层。
- 权限/供应商流程由明确按钮触发；取消后回 editing 或 snapshot 指定状态。
- 提交后返回手势交给 BackDecision，不能先 pop 再留下活体流程。
- 屏幕阅读器按步骤、成年核验、姓名、证件、成年声明、主按钮顺序聚焦；错误更新可被朗读。

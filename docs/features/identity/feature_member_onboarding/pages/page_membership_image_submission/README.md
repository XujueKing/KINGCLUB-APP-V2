## 用户任务

提交两张近期、清晰、能确认本人的会员审核图片，并在上传前了解图片用途和公开入会规范。

## 入口、出口与返回

- 入口：snapshot 允许编辑 `images` 且实名成年核验已通过。
- 成功：两槽位 commit 完成后进入 KC-P-007。
- 返回：回 KC-P-005 只读结果；临时未提交图片先确认丢弃。
- changesRequired：只显示需要替换的槽位和稳定公开原因。

## 线框

```text
[返回]                    步骤 2/4
完善会员形象资料
仅用于会员审核，具体规则 [查看]

[ 正面清晰照 ]       [ 半身/全身照 ]
  添加/替换              添加/替换
  状态/槽位错误          状态/槽位错误

照片要求：本人、近期、清晰、无严重遮挡
[下一步]
```

## 规则

- 两个槽位都必填；相册或相机由用户分别触发，不在进入页时请求权限。
- 只接受批准的图片 MIME、像素、文件大小和方向；最终规则以后端 upload intent 为准。
- 选择后提供裁切/预览/替换/删除；不做美颜、自动修改身体或外貌。
- 上传失败只影响当前槽位；成功 commit 后立即清理临时副本。
- 不展示“颜值分”、模型标签或侮辱性审核文案。
- 状态见 [states.md](states.md)，交互见 [interactions.md](interactions.md)。

## Mock 与埋点

- FakeMediaPicker 提供成功、取消、权限拒绝、格式错和合成图片。
- 埋点只记录槽位、来源类型、结果分类和耗时桶，不记录文件名、路径、图片摘要或审核标签。

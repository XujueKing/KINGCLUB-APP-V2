# 手机号登录页评审记录

## 2026-08-24 首次正式评审

### 已确认事实

- V1 仅支持中国大陆 `+86` 手机号短信登录；验证码通过后不存在账号则自动创建统一账号与 KingClub 会员。
- `K260824000101` 已实现手机号/设备/IP/场景限流、业务幂等和防账号枚举，密文异常矩阵已通过。
- `K260824000102` 要求提交用户实际看到并同意的当前 `terms/privacy` 发布版本。
- 服务端已有协议发布目录和同意记录数据模型，但冻结的六个 K 接口没有未登录协议目录/正文读取能力。

### 已冻结页面规则

- 客户端只做 `1` 开头 11 位数字的基础检查，服务端负责最终规范化，避免把运营商号段固化在 App。
- 协议复选框不默认勾选；协议链接和勾选为独立操作；可选授权不得捆绑。
- 发送结果不区分已注册/未注册，不暴露手机号、设备或 IP 中哪一维触发限流。
- 不确定网络重试复用业务 idempotencyKey，但每次传输使用新 requestId/nonce。

### 评审结论

页面目标、线框、手机号输入、短信发送、状态、限流、幂等、隐私、无障碍和测试标准已完成评审。协议目录来源未闭环，页面保持 `In Review`，不得通过客户端硬编码协议版本取得开发准入。

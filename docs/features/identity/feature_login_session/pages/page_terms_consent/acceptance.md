# 协议确认页验收

- [ ] 只接受服务端当前已发布的 terms/privacy 版本，版本变化会要求重新确认
- [ ] readOnly 与 loginRecovery 两种入口严格分离，路由不携带正文、手机号、challenge 或凭据
- [ ] 两项协议标签均可阅读，切换后在当前进程内保留各自滚动位置
- [ ] 未明确勾选时不能继续；不强制滚动到底，不默认勾选或自动同意
- [ ] 接受只更新内存 ConsentSnapshot；拒绝不会创建同意记录或会话
- [ ] 最终 consentRecord 只能由后续 K102 按服务端当前目录追加写入
- [ ] 目录不可用、正文缺失、离线和本地快照提交失败均失败关闭并可重试
- [ ] K107 缓存到期或版本变化会刷新目录、清除旧选择并阻止陈旧快照提交
- [ ] Markdown 大小、摘要和安全结构校验失败时不渲染为可同意内容
- [ ] 恢复模式查看期间 challenge 过期会销毁流程并回手机号页重新获取
- [ ] 营销、定位、通讯录等可选授权未与基础协议捆绑
- [ ] 埋点不含手机号、账号、凭据或正文交互细节
- [ ] Widget 测试覆盖两种模式、标签切换、版本变化、同意、拒绝、离线、正文校验失败和重复点击

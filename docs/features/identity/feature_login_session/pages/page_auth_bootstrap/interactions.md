# 启动鉴权页交互与生命周期

## 1. 启动时序

```text
App 启动
  -> 创建本轮 bootstrap generation
  -> 初始化配置、设备实例、安全存储
  -> 读取并校验完整凭据包
      -> 无凭据：replace /auth/mobile
      -> 访问凭据安全：K260824000104 me
      -> 需要刷新：K260824000103 refresh -> 原子保存 -> me
  -> 登录守卫复核 returnTo
  -> replace 目标路由
```

系统原生启动屏只承担首帧前遮罩；Flutter 首帧出现后由本页接管。不得为了品牌展示人为延迟成功导航。

## 2. 加载反馈

- 0～800ms：仅显示品牌标识，避免短任务闪烁文字和进度。
- 超过 800ms：显示不确定进度和“正在安全登录”。
- 超过网络层规定的单次超时：进入可重试或致命状态，不无限旋转。
- 页面不显示百分比，因为初始化和网络步骤没有可信总进度。

## 3. 重试规则

- 重试按钮只在 `offlineRetryable` 或 `fatal` 可用。
- 点击后立即禁用并新建 generation；快速连点只执行一次。
- 网络恢复自动重试最多一次；本轮自动重试后仍失败，必须等待用户操作或下一次明确网络变化。
- 重试刷新时先重新读取安全存储，避免再次使用已被另一任务轮换的旧 Token。

## 4. 生命周期与并发

- App 进入后台时不取消已经到达服务端的刷新请求，但暂停导航；回前台后先核对 generation 和当前凭据版本。
- 页面销毁、导航完成或新 generation 启动后，旧任务结果一律丢弃。
- 其他受保护请求在 bootstrap 完成前不得发起；统一等待 session 层同一个 Future/Promise。
- WebSocket 由鉴权成功后的应用装配流程建立，本页不直接连接；撤销/重用时只通知 realtime 层停止重连并清状态。

## 5. 返回、手势与系统行为

- Android 系统返回、iOS 返回手势和导航栏返回在本页均禁用。
- 无凭据导航到手机号页后，返回不得重新打开启动鉴权页。
- 系统字体放大时品牌与错误操作区不得溢出；横竖屏变化不重启鉴权任务。
- 读屏只在状态类别变化时公告，不按动画帧或重试倒计时重复播报。

## 6. 错误文案原则

| 场景 | 用户文案原则 |
|---|---|
| 离线/超时 | “网络暂时不可用，请检查后重试” |
| 会话失效 | 导航登录页后提示“登录状态已失效，请重新登录” |
| 新设备顶号 | 登录页提示“账号已在其他设备登录” |
| 安全校验失败 | “安全连接初始化失败，请重试” |
| 未知错误 | “暂时无法启动，请稍后重试” |

不得显示 HTTP 状态、接口编号、堆栈、内部错误原文、手机号、账号或 requestId；requestId 只进入脱敏诊断日志。

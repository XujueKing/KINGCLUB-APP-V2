# 验证码页

## 文档状态

`Approved for Development`。用户已于 2026-08-24 批准页面九项规则；实际编码仍须等待 Flutter foundation 文档准入。

## 页面目标

完成六位短信验证码录入，通过 `K260824000102` 创建或登录 KingClub 会员，并安全接收一次性会话凭据。

## 路由与返回

- **当前建议**：路由 `/auth/code`，唯一页面参数是内存中的不透明 `loginFlowId`，不得进入 URL、深链或系统恢复状态。
- 功能级登录流程协调器按 `loginFlowId` 保存 `challengeId`、规范化手机号、脱敏手机号、challenge/重发截止时间、当前协议版本和已验证 `returnTo`；页面只展示脱敏手机号。
- 流程上下文缺失、进程重启或 challenge 已过期时替换回 `/auth/mobile`，显示“请重新获取验证码”。
- 返回手机号页时销毁当前输入；服务端 challenge 可自然过期，不在客户端伪造取消成功。
- 登录成功后由 Session Repository 原子提交完整凭据，再替换路由至目标业务页；不得回到验证码页。

## 信息架构与线框

```text
[返回]
输入验证码
验证码已发送至 138****0000
[ _ ][ _ ][ _ ][ _ ][ _ ][ _ ]
00:60 后可重新获取   [收不到验证码？]
[验证并登录]
```

验证码视觉可分格，但语义上使用单一可访问输入；支持系统短信自动填充，禁止主动读取短信权限。

## 状态与交互

- `editing`：接收六位 ASCII 数字；允许粘贴常见空格/连字符包装，包含其他字符或规范化后超过六位时整体拒绝，不静默截断。
- `submitting`：手输、合法粘贴或系统填充达到六位后均走同一条“每个输入 revision 最多一次”自动提交路径；请求期间锁定输入和重发。
- `invalid_code`：清空输入并重新聚焦，显示通用提示，不展示或推算服务端剩余次数。
- `expired`：禁止继续提交，引导重新获取。
- `locked`：当前 challenge 达到失败上限，不再接受输入；冷却允许后可重新获取。
- `resending` / `resend_rate_limited`：重发是独立请求状态，按服务端截止时间显示，禁止通过本机时间修改绕过。
- `preflight_retryable`：客户端能证明 K102 尚未发出时保留输入，可用新握手重试且不重新发短信。
- `outcome_unknown`：K102 发出后连接中断，无法判断服务端是否已签发会话；不得重放同一验证码，清除流程并重新获取。
- `consent_version_changed`：清除验证码输入，保留仍有效的 challenge，重新读取 K107 并进入协议确认流程；同意后返回本页重新输入。
- `success`：一次性处理 `apiKey/refreshToken`，整体安全落盘成功后才导航；落盘失败立即清除部分数据并提示重新获取验证码登录，不重放已消费 challenge。

challenge 有效期和重发冷却是两个独立截止时间。重发使用 `K260824000101` 的新用户动作 idempotencyKey；只有新请求明确成功后才原子替换 challenge，迟到的旧请求结果不得覆盖当前流程。页面离开、账号被撤销或 App 被清理时，不保留验证码。

## API 与协议映射

登录调用 `K260824000102`：`challengeId/mobile/code` 来自当前流程；应用和设备字段来自可信上下文；`consents` 只提交服务端已发布且用户已确认的版本。成功响应中的密钥只能交给安全会话 Repository。

如果当前发布版本要求登录前同意，则使用手机号页已确认版本。若登录期间版本变化，服务端返回 `AUTH_CONSENT_VERSION_INVALID` 且不会验证或消耗短信 challenge；客户端清除旧勾选和验证码输入，刷新 K107，用户重新确认后可在 challenge 未过期时继续，不重新发送短信。

K102 当前没有可安全重放一次性凭据的业务幂等契约。只有客户端能证明请求未离开设备时才允许原 challenge 重试；请求发出后的超时、断连或响应解密失败统一按“结果未知”处理，返回手机号页重新获取验证码。下一次成功登录会按 KingClub 单设备规则撤销可能已提交但客户端未收到凭据的旧会话。

## 埋点、隐私与可访问性

- 埋点：`sms_code_view/submit/result/resend/help`；不得记录验证码、手机号、challenge、账号、Token 或密钥。
- 页面可见期间 Android 启用安全窗口策略，iOS 进入后台前覆盖任务切换快照；离开敏感流程后恢复，错误日志只保留稳定分类和脱敏 requestId。
- 读屏按“第 N 位”或单输入完整读法，不逐位泄露已输入数字；倒计时变化不应每秒打断读屏。

## 不做事项

不在本页展示实名、设置密码、修改手机号或处理多账号合并；身份冲突只显示通用人工处理入口。

# 登录与会话验收

- [ ] 验证码有 TTL、次数限制、发送限流、单次消费和审计
- [ ] 不存在手机号时按确认规则原子创建账号和 App 成员
- [ ] 并发首次登录不会创建重复账号
- [ ] 登录失败不泄露手机号是否已注册等不必要信息
- [ ] API Key 仅加密保存，refresh token 仅保存受控哈希
- [ ] 会话刷新执行 token 轮换并检测旧 token 重用
- [ ] 注销、冻结、改密和风控能及时吊销 HTTP 与 WebSocket 会话
- [ ] Flutter 重启可安全恢复，失效时回到登录流程
- [ ] 用户 A 不能通过请求参数冒充用户 B
- [ ] 凭据不出现在日志、URL、埋点、截图和普通本地存储
- [ ] 新设备登录会原子撤销旧 KingClub 会话和 API Key
- [ ] 旧 WebSocket 收到撤销事件并关闭，旧客户端安全退出
- [ ] 登录物业 App 不会撤销同一自然人的 KingClub 会话，反之亦然
- [ ] 正常、错误验证码、超时、重放、并发、单设备互踢和弱网场景有自动化测试
- [ ] 已存在手机号通过 KingClub 本地 HMAC 指纹投影解析，不在每次登录调用物业权威接口
- [ ] 本地投影缺失时调用 `S260824000401`，成功后幂等回填；接口失败时不得本地生成 `U...`
- [ ] KingClub 数据库不保存手机号明文，指纹密钥与物业隔离并支持版本轮换
- [ ] 协议版本由已发布目录校验，过期/伪造版本不能生成同意记录或会话
- [ ] 访问会话 2 小时、Refresh Token 30 天和 10 分钟提前刷新边界均有时钟测试

# 启动鉴权页

## 文档状态

`In Review`。文档已达到技术评审稿，尚未获得产品/视觉确认，不允许创建 Flutter 页面实现。

## 页面目标

应用启动时完成本地安全凭据读取、Refresh Token 恢复、`auth.session.me` 复核和首个业务路由选择。该页不是广告页，不展示敏感账号信息，也不允许用户停留操作。

## 路由与导航

- **当前建议**：路由名 `/auth/bootstrap`，无外部参数，禁止加入返回栈。
- 有效会话：替换路由到待恢复深链；无深链时进入 `/home`。
- 无凭据或明确失效：替换路由到 `/auth/mobile`。
- 网络暂时不可用且存在未过期本地会话：进入可重试离线态，不擅自清凭据。
- Refresh Token 重用、账号冻结或撤销：原子清除安全存储、关闭 WebSocket，进入手机号登录页并显示通用说明。

## 信息架构与线框

```text
[全屏品牌底色]
        KingClub 标识
        小型进度指示
        状态说明（超过 800ms 才显示）

失败时：通用说明 + 重试按钮
```

组件仅包括品牌标识、进度指示、状态文本、重试按钮和无障碍公告区域；不显示手机号、账号、Session 或服务器错误原文。

## 状态与交互

- `initializing`：初始化设备标识、环境和安全存储，防重复启动。
- `refreshing`：仅使用新握手密文调用 `K260824000103`，成功后原子替换全部凭据。
- `validating`：调用 `K260824000104`，只接受可信会话返回。
- `offline_retryable`：保留凭据，用户可重试；恢复网络后自动重试一次。
- `session_invalid`：清凭据后跳登录，不自动循环刷新。
- `fatal`：配置/加密初始化失败，显示通用错误和重试；记录脱敏 requestId。

前后台切换期间同一时刻只允许一个恢复任务；超时、取消或导航完成后不得回写旧状态。

## 数据、隐私与埋点

- 输入：安全存储中的 `sessionId/apiKeyId/apiKey/refreshToken/version/expiry`，以及待恢复深链；这些字段不得进入普通缓存、日志或埋点。
- 输出：内存会话快照与目标路由。凭据写入必须整体成功后再删除旧值。
- 埋点：`auth_bootstrap_started/result/retry`，只记录结果分类、耗时区间、网络类型和脱敏 requestId。
- 可访问性：进度状态可被读屏宣告；减少动态效果设置下禁用非必要动画；失败按钮触控区不小于 44×44。

## 依赖与不做事项

依赖安全存储、密文网络客户端、会话 Repository、连接状态和路由守卫。该页不请求短信、不展示协议、不连接 WebSocket、不拉取完整个人资料，也不处理首页业务初始化。

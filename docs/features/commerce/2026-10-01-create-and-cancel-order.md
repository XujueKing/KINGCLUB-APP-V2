# 下单与支付分离、主动取消

支付确认页新增“提交订单”：向既有K260919000814明确发送initiatePayment=false，不启动支付SDK、不占库存。随后“立即支付”沿用同requestId，服务器付款前争取库存，售罄不发起扣款。旧客户端省略此参数仍保留旧支付行为。

待付款订单可调用K261001001958主动取消；界面只按原订单权威状态更新。cancellationRequested必须为布尔值，关闭中禁用再次支付；未知保留原请求继续查询；paid不能当作取消成功。已有30分钟到期恢复继续适用，SDK取消本身不等于服务端取消。

新增只提交不启动SDK、继续支付不重复建单，以及取消expired/paid/pending/unknown场景。相关37项测试通过，变更源码与新增测试分析通过。服务端257/258和新代码必须先部署，之后才能发布新APP；目前尚未安装本批。

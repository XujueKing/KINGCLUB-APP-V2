## 一页一个接口

- K261028002080 → kingclub_store_home：输入 storeRef、section（featured/activities/vouchers/booking/about）、page（0..1000）；首页一次返回门店身份、公开资料、本人收藏状态、近期活动、团购券、预订产品和各栏目 hasMore。精选每类最多3条；独立栏目每页10条，先SQL分页再聚合。介绍无额外请求。
- K261028002081 → kingclub_store_voucher：输入 storeRef、offerRef；一次返回券的完整内容、适用门店、价格币种、有效期、预约/叠加/退款/核销规则及可操作状态。
- 收藏独立动作复用 K261005000810，返回结果更新本地收藏状态，不再拉整页。
- 点击活动进入既有活动详情，订位进入既有预订产品详情；属于新的页面读取，不用原接口逐项拼店铺主页。

身份来自已验证会员会话，过程校验会话、会员和门店公开状态；不信任客户端权限。只读过程无写入或行锁。团购券存储独立售卖定义，不能把第三方已核销权益当在售商品。首批仅公开目录/详情，不启用团购券收款；购买/发券/核销须接统一支付订单后开放，客户端按服务端 canPurchase=false 显示“暂未开放购买”，不伪造购买结果。

数据库：新增递增478迁移，复用 kingclubCommerceStore 增加公开介绍字段，新增 kingclubStoreVoucherOffer 保存券定义；表、过程和接口同批登记。无演示在售数据、无历史账务变更。公开资料只包含允许展示的地址/联系信息，不返回收款配置或会员隐私。

验收：页面布局与320/402宽及大字、LOGO点击隔离、空/错误/停售状态、栏目分页、会话变化丢弃旧结果；服务端一次CALL、参数拒绝、身份/门店范围及对象登记；必要验证通过后提交。数据库部署与真实请求耗时须另记实际结果，不能将静态检查当作线上完成。

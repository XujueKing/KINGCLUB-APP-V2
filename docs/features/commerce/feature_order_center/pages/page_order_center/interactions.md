# 订单中心页交互

| 触发 | 行为 |
|---|---|
| 切换筛选 | 重置 cursor，加载对应状态族 |
| 下拉刷新 | 权威替换首屏并去重 |
| 滚动到底 | 单次加载下一 cursor |
| 点订单卡 | 仅传 OrderRef 打开详情 |
| 收到状态事件 | 标记需刷新，不直接改列表状态 |
| 点空态入口 | 返回首页/扫码等已批准入口 |
| 长按页面标题 | 仅在 UI 验收包中打开 Fake 列表场景切换器 |
| 点“有状态更新” | 使用当前筛选器刷新首页，不直接修改单条订单 |

筛选选择可保留；订单内容不跨账号缓存。

UI Mock 的下拉刷新、游标加载和重试只操作本地 Fake 页；重复 `OrderRef` 必须去重。

AA 支付成功后的本地列表投影按创建时间置顶；从详情返回时保留当前筛选和滚动上下文，不重新触发支付或复制订单业务对象。

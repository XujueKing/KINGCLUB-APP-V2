# 搜索框与分类滚动修正

只读对照旧小程序 `pages/shoping/shoping.wxss` 的 input（36rpx 内容、上下 20rpx padding），以及 `shoping.js` 的 bindType / `shoping.wxml` 的 scroll-into-view。旧版点击左栏定位分类首项，不移除其他分类商品。

- 搜索框从固定 48dp 改为 76rpx 随屏宽换算，移除 Material 图标默认最小高度影响，文字垂直居中。
- 左栏点击按完整商品列表中的分类首项滚动；搜索词仍过滤当前大类商品。切换大类或搜索时回到列表顶部。
- 商品列表尾部留白至少覆盖底栏、安全区和额外间距，并允许最后一个分类首项滚到顶部；左栏末尾也避开底栏。
- 未新增演示商品，当前没有商品的分类不会伪造商品或改成过滤空列表。

验证：320×694、360×640、393×852、430×932 各用 1.0/1.35 系统字号，检查搜索高度、伏特加定位、价格和加号不被底栏遮挡，以及向上滑后其他分类商品仍可见。加上既有扫码入口、搜索、购物袋流程，共 17 项通过；两个文件静态分析通过。真实商品/支付接口不属于本样式节点完成范围。

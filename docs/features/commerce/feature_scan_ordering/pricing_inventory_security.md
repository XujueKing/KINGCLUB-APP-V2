# 计价、库存与安全边界

## 服务端权威字段

- 门店、桌位、营业场次和点单权限
- 商品可售、规格、单价、会员价、库存、限购
- 优惠适用性、税费/服务费、舍入规则和最终应付金额
- QuoteRef 的版本、有效期以及能否创建订单

客户端合计只标注“预估”，不得传回作为结算依据。金额使用最小货币单位整数；不使用浮点数计算。

## 防护规则

- 原始二维码内容、用户账号、价格、优惠和订单状态不得写入路由。
- QuoteRef 为不透明、短时、绑定账户/场次/桌位/购物车摘要的引用。
- 创建订单必须使用稳定幂等键；超时重试复用原键。
- 草稿在退出账号、上下文撤销、营业日结束时清理。
- 埋点不记录二维码、QuoteRef、订单号、完整商品备注或支付凭据。

用户已授权扫码点单真实接入及新库独立运行。本节点实现 K260919000809 客户端适配器，不新增接口或数据表。

请求仅携带服务器确认的 tableId、tableSessionRef，复用加密超级接口与安全会话。响应必须匹配会员、经营主体、品牌、门店、城市、营业日、场次和付款模式；请求期间退出或切换账号则丢弃响应。失败不得回退演示商品。

# 桌台上下文客户端接入

状态：开发中。用户已授权扫码点单真实接口开发；本节点不切换 B 手机现有视觉验收页面。

服务端独立分支新增接口 `K260919000801`，传入标准化 `tableId`，可附旧 `shopId` 提示（0 表示未指定）。最终门店、城市、品牌、经营主体、营业日和开台场次均由服务端桌台档案解析。接口尚未部署，migration 127 执行前须核对目标库已有对象及并行分支编号。

客户端沿用 KingclubSecureClient 和 SecureSessionStore；请求前验证登录，响应后重新读取登录绑定，拒绝账号切换或退出后返回的旧请求。校验响应桌号、会员、场次和必填归属字段，不用二维码内的店名、城市或桌名补齐缺失响应。无接口或异常不回退示例数据。

OrderingContext 保留现有 UI 构造兼容性，真实接口额外填入 tableId、tenantRef、brandRef、currency、timeZone。仅获得浏览上下文，不代表入座或付款授权。提交订单必须重新验证开台场次及库存。

当前页面内商品为示例列表，因此本次只加入经过测试的数据适配器；不把真实上下文接到示例商品结算。后续真实商品列表、库存、报价和订单一并接入后切换路由。四语言错误展示由页面接入节点统一处理，服务端错误码继续保留。

验证：接口适配器、桌卡兼容、上下文切换和入口测试共 22 项通过；本次 3 个 Dart 文件静态分析通过。包含未登录、请求中换账号/退出、错桌/错会员、缺失字段、异常营业日/付款模式和服务失败。响应已增加场次 paymentTiming（prepay/postpay）；未知模式拒绝使用。本轮没有真实网络/数据库联调，没有重新安装手机包。

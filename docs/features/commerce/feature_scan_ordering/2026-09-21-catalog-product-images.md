# 扫码点单服务器商品图接入

2026-09-21。继续完善扫码点单，管理页面仍待重新设计，本轮不改管理 UI。

## 原缺口与修改

服务器目录 809 已返回 bottleMaterial，但 APP OrderingCatalogProduct 忽略该字段，真实商品在点单列表和购物车都只显示占位图。现在解析 thumbnail 地址与源 SHA256，使用既有 CachedMediaImage / MediaCache 下载缓存；列表和购物车共享相同素材身份。

缩略图只允许服务器返回的 /attachments/UUID?token=... 相对地址，并拼接商业 API 根路径（保留 /kingclub-v2/commerce），拒绝外站、越界路径、多余查询参数和跨门店素材。版本必须为 png-contour-v1，摘要为 64 位小写十六进制。媒体源地址必须 HTTPS。没有 bottleMaterial 的既有商品继续支持占位显示。

缓存使用门店+生成版本+原图摘要+thumbnail 作稳定身份，并使用会员私有缓存隔离。短期令牌刷新不重复占用缓存；原图摘要变更切换素材。远程图片按 contain 展示，保留原布局、缺货遮罩；失败显示占位图。套餐/数量/价格/库存及原 UI 演示资源未改。

## 验证

目录、真实目录页面、购物车、响应式布局共 37 项测试通过，4 个修改文件静态检查无问题。新增验证商业路径拼接、令牌续期缓存稳定性、修图摘要变化、跨站/跨店地址拒绝，以及点单列表和购物车复用私有缓存组件。回归覆盖 320/360/393/430 宽度及普通/放大字体、缺货、购物车金额和空目录不回填演示商品。

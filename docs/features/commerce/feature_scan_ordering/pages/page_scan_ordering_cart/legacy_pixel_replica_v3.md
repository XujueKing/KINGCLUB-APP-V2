## 首屏布局冻结

1. 顶部只放返回与搜索框，App 不显示小程序胶囊和额外“订单”文本按钮。
2. 门店标志、门店名、888 在同一视觉行，地址在其下方左对齐。
3. 一级分类横排，选中线只出现在文字正下方。
4. 主体为左侧固定分类栏与右侧连续商品列表，不出现卡片容器。
5. 商品图、名称和价格按旧版行高排列；第四件商品可在首屏底部被固定结算栏自然遮住一部分，与截图一致。
6. 首屏默认购物袋数量为 2、合计 3710.00，用于和参考截图做同状态验收；交互测试可从空购物袋状态注入，但不可改变视觉基准态。

## 2026-08-29 v3.1 精校冻结

1. `888` 不再允许使用 Android `serif` 字体近似；直接移植旧版 `.F_888` 的三段 path，保留 `209.72:90` 比例，并在旧版 `tablestyle` 槽位内右对齐。
2. 商品图槽位严格按 `190 × 240 rpx` 等比换算；右侧信息列与图同高，采用旧版 `justify-content: space-between`：名称组贴上，价格与数量控件贴下。
3. 中文名使用 `32 rpx`、英文名和规格使用 `28 rpx`、价格使用 `36 rpx`、货币符号与数量使用 `24 rpx`；不得用统一字号压扁层级。
4. 中文、英文和规格三行保持紧凑连续；名称组与价格行之间留出旧版大段空白，不能把整组文字垂直居中。
5. 减号、数量、加号必须与价格基线处于同一横行，商品图和文字均不得因数量出现/消失而横向或纵向跳动。

## 2026-08-29 v3.2 左栏与门店头部精校冻结

1. 本轮以用户提供的旧版完整截图（图四）为视觉真值；头部门店区裁剪图和左栏裁剪图只用于局部测量，不得脱离完整截图单独放大。
2. 旧版 `utils/formatTime.wxs#formatText` 是分类换行的事实来源：4 字分类按 `2 + 2`、6 字分类按 `3 + 3` 显示。Flutter 必须显式复现该规则，不能依赖设备字体自动换行。
3. 左栏普通项恢复约 `26 rpx`、选中项约 `28 rpx` 的视觉层级；行高保持 `1.2` 左右，选中项 `畅饮\n套餐` 与普通项 `红葡\n萄酒` 均须稳定居中。
4. 左栏每项恢复旧版约 `120～132 rpx` 的纵向节奏；增大字号后不得压缩上下留白或让分隔线穿过文字。
5. 门店头部按完整原图缩回：King 标志、门店名和 `888` 不得比原图更大，左起点恢复到原图比例；标题保持单行且不给 `888` 挤压。
6. 一级分类保持旧版约 `32 rpx` 字号和单条金色选中线；本轮不改变商品卡内部已经确认的瓶图、三行文案、价格和数量控件结构。

## 2026-08-29 v3.3 结算前购物袋面板冻结

1. 用户本轮图一是点击底部购物袋后的唯一视觉真值；面板属于 KC-P-034，不得省略或用通用 ListTile BottomSheet 替代。
2. 面板背景使用旧版 `#94826c` 棕金，顶部左右分别为圆形选中标记 + `全选(共N件商品)`、删除图标 + `清空购物袋`。
3. 商品明细必须置于独立黑色圆角卡内：每行依次为圆形选中标记、透明瓶图、中文/英文/规格/价格、同一基线的减号/数量/加号；商品之间使用低对比分隔线。
4. 商品总价放在黑色商品卡下方的浅米金圆角卡内，左侧 `商品总价`、右侧 `¥ 3710.00`，不得并入商品行或底部栏。
5. 原点单页固定购物袋/合计/去结算栏保持在面板最下方；点击去结算才进入 KC-P-035。
6. 保留现有商品数量、清空二次确认、金额联动和 Fake Quote 安全逻辑；本轮只重建旧版信息架构和视觉比例。

## 交互冻结

- 搜索：过滤当前本地目录，清空后恢复。
- 一级分类：切换酒水、饮料、小吃；选中线平滑移动但不改变旧版静态样式。
- 左栏：点击后滚动/过滤到对应分类，选中块同步。
- 加减：立即改变数量、徽标与合计，控件位置不跳动；加购飞入动画可后续补，但不得阻塞本轮视觉验收。
- 购物袋：有商品时展开旧版棕金购物袋明细；清空需二次确认。
- 去结算：生成本地 UI Mock Quote 并进入 KC-P-035，不接真实接口或支付。
- 长按门店头部：保留隐藏的验收场景入口，正常用户首屏不显示 Fake/Mock/测试说明。

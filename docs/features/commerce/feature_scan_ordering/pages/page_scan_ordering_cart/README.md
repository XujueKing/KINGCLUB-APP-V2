## 用户任务与线框

确认当前门店/桌位，按旧版点单页面浏览商品并编辑购物车。2026-08-29 用户提供了旧版同状态截图，截图与旧版 `pages/shoping/shoping.wxml`、`shoping.wxss`、`app.wxss` 及原始图片资源共同构成本页唯一视觉基准。

```text
[返回] [搜一搜你想要的饮品]
[King club 标志] [KINGBAR 湖南工大店]        [888]
[株洲市天元区金华路瀚水栗源1栋102]
[酒水]      [饮料]      [小吃]
[畅饮套餐] | [原版透明瓶图] [中文名]
[威士忌  ] |                [英文名]
[白兰地  ] |                [750ML]
            |                [¥ 3380] [- 1 +]
...
[购物袋 2] [合计 ¥ 3710.00]             [去结算]
```

- 页面视觉上沿用旧版“合计”排版；其值仍只是本地 UI Mock 投影，点击后必须进入服务端权威报价契约对应的确认页，不能直接支付。
- 商品不可售、限购和目录更新必须在原位置说明。
- 200% 字体下底部操作条不遮挡商品和错误信息。

状态见 [states.md](states.md)，交互见 [interactions.md](interactions.md)，验收见 [acceptance.md](acceptance.md)。

## 旧版复刻基线

**已确认事实**

- 视觉与信息架构以旧版 `pages/shoping/shoping` 为主，保留黑色背景、黑金门店头部、顶部搜索、横向大类、左侧小类、右侧商品列表和底部购物袋。
- 门店头部必须复刻用户截图：使用旧版 `logo_2.png`，门店名为 `KINGBAR 湖南工大店`，右侧直接使用 `app.wxss/.F_888` 的原始矢量轮廓显示桌号，地址为 `株洲市天元区金华路瀚水栗源1栋102`；不得替换为系统字体数字、圆形 K、V8 卡片、定位图标或“桌位已验证”胶囊。
- 一级分类固定为 `酒水 / 饮料 / 小吃`；酒水选中态使用米白正文与单条金色下划线，未选项降低不透明度，不使用卡片或填充背景。
- 左栏固定保留 `畅饮套餐 / 威士忌 / 白兰地 / 伏特加 / 香槟 / 红葡萄酒 / 清酒 / 鸡尾酒`，选中项为米金矩形并仅右上、右下轻圆角；未选项为黑底、灰白字与细分隔线。
- 左栏文字必须执行旧版 `format.formatText` 规则：4 个汉字按 `2 + 2` 换行，6 个汉字按 `3 + 3` 换行；因此 `畅饮套餐`、`红葡萄酒` 必须显示为两行，不能因 Flutter 自动排版而保持单行。
- 商品区不得使用卡片、图片圆角底板或列表分割卡；使用旧版透明瓶图、中文名、英文名、`750ML`、价格与黄色圆形加减控件的自由排版。
- 商品信息列必须复刻旧版 `C3V2` 的上下分布：中文/英文/规格贴图像顶部，价格与加减控件贴图像底部；32/28/36/24 rpx 字号层级与行距不得被统一缩小。
- 默认截图态使用旧版原始商品资产与文案：轩尼诗 XO / Hennessy XO / 750ML / 3380，芝华士12年 / CHIVAS REGAL 12 YEARS / 750ML / 330，轩尼诗 VSOP / Hennessy VSOP / 750ML / 1240，瑞典绝对伏特加 / Absolut Vodka / 750ML。
- 底部固定栏必须复刻旧版购物袋、黄色数量徽标、合计金额和米金完整胶囊“去结算”；不得显示“购物袋是空的”“预估”“最终价格以确认页报价为准”等破坏旧版首屏的辅助文案。
- 购物袋展开后保留旧版的棕金头部、深色行项、清空入口与固定结算栏。
- 点击底部购物袋必须先显示旧版结算前面板：背景目录压暗、棕金圆角面板从底部升起、顶部全选/商品数与清空入口、黑色商品明细卡、浅色商品总价卡；不能直接跳到提交订单页。
- App 不复制小程序右上角宿主胶囊，但不改动旧版点单主体层级。

**UI Mock 安全偏差**

- 底部金额标记为“预估”，“去确认”只产生 Fake Quote，不调用真实超级接口或支付 SDK。
- 门店与桌位使用已验证的 Fake `OrderingContextRef`，路由不携带原始二维码或可信桌位 ID。
- 商品图直接复用旧版仓库的本地透明 PNG，仅用于 UI Mock 复刻；实际商品与价格将在接口阶段由服务端目录提供。

真机证据见 [2026-08-29 Android 验收](audit/2026-08-29-device/README.md)，视觉结论见 [design-qa.md](design-qa.md)。

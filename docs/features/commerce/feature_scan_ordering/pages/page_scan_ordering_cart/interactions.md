# 商品/购物车页交互

| 触发 | 行为 |
|---|---|
| 页面进入 | resolve OrderingContextRef 后加载目录/隔离草稿 |
| 加减商品 | 只修改商品 ID、规格和数量草稿 |
| 选规格 | 无效组合不可加入 |
| 清空购物车 | 二次确认后清理当前上下文草稿 |
| 点去确认 | 校验非空并请求服务端报价 |
| 报价发现失效项 | 原位标注并要求修正 |
| 点订单 | 打开本人订单中心 |
| 返回/切后台 | 保存非权威草稿，不保存二维码/QuoteRef |
| 搜索商品 | 在当前 Fake 目录内按名称/规格过滤，清空后恢复当前类目 |
| 点购物袋 | 展开旧版样式购物袋，可继续增减和二次确认清空 |
| 长按门店名 | 仅在 UI 验收包中打开 Fake 场景切换器 |

快速连点合并为确定数量；埋点不记录备注全文和引用值。

UI Mock 阶段的“去确认”会先显示本地报价加载，然后输出强类型 Fake Quote 意图；KC-P-035 完成后由路由层接续确认页。

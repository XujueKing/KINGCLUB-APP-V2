# 点单确认页交互

| 触发 | 行为 |
|---|---|
| 页面进入/恢复 | 解析 QuoteRef 并确认仍有效 |
| 报价变化 | 展示差异；用户接受后使用新 QuoteRef |
| 返回修改 | 丢弃当前 QuoteRef，保留商品选择 |
| 提交订单 | 使用稳定幂等键创建 |
| 提交超时 | 原键 reconcile，按钮保持受控 |
| 创建成功 | replace 到 PaymentResultRoute 或订单详情 |
| 订单无需支付 | 仍查询订单权威状态后进入详情 |
| 会话失效 | 清 QuoteRef 并登录 reset |
| 点商品明细的展开/收起 | 只改变当前显示行数，不修改报价 |
| 长按页面标题 | 仅在 UI 验收包中打开 Fake 状态切换器 |

金额变化不得静默提交；不得把金额、用户账号或订单 JSON拼入路由。

UI Mock 阶段使用稳定的本地提交键演示防重；“提交超时”只对账原提交，不生成第二个 Fake 订单。

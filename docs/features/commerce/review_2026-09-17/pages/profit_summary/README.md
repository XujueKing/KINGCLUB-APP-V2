# 收支与利润

状态：In Review，仅设计；文字线框 v1。适用 [公共页面契约](../README.md)；首期由超级管理员操作，后续配置角色。本文未确认的技术处理均为设计建议，不修改真实账户或库存。

## 目标、入口和返回

让老板看清实际销售利润和手里资金，并能点开每个数字的来源。

记账首页 → 收支利润；storeId、dateRange。返回保留日期，点数字到来源明细。

## 手机线框与字段

门店/期间/币种 → 销售净额/已售成本/毛利 → 费用/损耗/经营利润 → 资金余额/待结算 → 待补成本提示。

range、storeScope、currency；显示 amountMinor、completenessStatus、sourceRefs、asOf、businessDayPolicyVersion。

## 操作和业务变化

销售净额减实际出库批次成本算毛利，再减费用与未重复计入的损耗。采购付款、资金调拨、会员充值单独显示资金变化，不当新销售。AA 未成团款是待处理资金，退款到余额也不是新收入。

## 异常与更正

缺成本显示待补成本/利润暂不完整，不把缺失当零；多币种分开，不自动汇率相加。退款跨日显示本次调整和原销售链接；已结期间按更正机制处理。

加载用骨架；空记录提供新建/返回；离线仅存草稿，确认需联网。无权限返回工作台；会话过期重新登录后查询原操作。字段错误保留输入并定位，未知结果保留 requestId 查询，不重复新建。

## 契约与记录

GetOperatingSummary/GetProfitBreakdown/GetSourceDocuments；收入/成本/资金来源唯一，不因上桌、存酒、渠道到账再计一次。按卡座开台归集基础套餐成本，多桌不混为一次履约。

语义接口与字段尚未注册，正式 DTO/接口编号待统一定稿；事件记录门店、主体、来源、真实操作人、时间、请求和更正原因。金额精确整数、数量十进制加单位；不记录附件秘密地址或个人支付凭据。草稿/待确认/已确认/处理中明确区分。

# 桌台本次消费详情

更新：2026-09-18。In Review，文字线框 v1，仅文档。适用 [页面公共约定](../README.md) 与 [数据契约草案](../../CONTRACT_BASELINE.md)。

## 入口与返回

会员本人分配或合法桌台扫码、管理员工作台进入；storeId、tableSessionId。返回原分座/工作台/活动。

## 页面与字段

桌号/本次活动 → 分配/入座人数 → 套餐待备/已出/已上 → 本桌订单与 AA → 加餐/开台等允许操作。

GetTableSessionDetail；configSnapshot、assignedCount、seatedCount、sharedPackageFulfillment、visibleOrders、allowedActions。 ID、状态和字段均为语义草案，非正式 API 编号。

## 交互与边界

桌台码仅定位，查看成员和订单仍校验会员关系；会员付款明细仅本人可见，管理员在业务范围查看。桌号复用不能把昨晚账单算到今晚。管理员确认到店入座，与分座分开；开台走专门页面。整桌消费汇总不能再次要求所有会员付已付的钱。

加载骨架、空数据指引、错误重试、无权限返回、会话失效重登后读取原对象。离线缓存标更新时间，不确认报名/入座/付款；未知写结果查询原 commandId。返回保留筛选，重复提交不重复生效；版本变化重新读取。字段错误定位且保留有效输入。

## 审计与验收（未执行）

达到最小人数可开台；未成团 AA 标待付，不计已完成消费；部分上酒不二次扣库；外人扫码不获得整桌个人支付记录。

审计操作者、门店、对象和状态变化，不记录券码/个人支付秘密；四语言共用状态与语义键，日期按门店时区，读屏标签及大字布局须后续验收。以上先用合成 Mock，真实接口待项目 UI 验收与契约批准。

# 采购单

状态：In Review；线框版本 v1（文字线框）。适用 [公共页面契约](../README.md)，不代表编码批准。

## 目标、入口与返回

超级管理员建立采购计划，普通采购操作从目录选择供应商和商品。

库存 → 采购 → 新建；storeId、可选 purchaseId。返回采购列表，草稿提示保存/放弃。

## 线框与字段

供应商选择 → 商品行（数量/单位/实际采购单价）→ 合计 → 备注 → 保存草稿/确认采购。低频目录维护另页。

supplierId、lines[productId,quantity,unit,unitPrice]、currency、note；显示采购单号、状态、待收/已收数量、关联付款记录。

## 操作与结果

按已有供应商和商品选择；超级管理员可跳到独立主数据维护后回来选，不在采购字段自由造供应商/商品。确认采购后按批收货。付款另关联资金记录。

## 状态与异常

数量/单价不合法定位行；单位转换未配置禁止随意换算；目录停用或跨店引用拒绝。取消已收货采购不能直接删库存。 加载、空、离线、会话失效、无权限、返回和可访问性按公共契约执行。

## 数据与审计

CreatePurchase/GetPurchase；建单不加可售库存，采购付款不等于全部已售成本。更正保留原单和原因。 事件记录本页查看/提交结果及必要业务引用，审计实际操作者；不记录码值或支付秘密。字段为待定稿语义契约，真实接口编号/DTO 映射待审定。

## 验收设计

采购 10 瓶只建计划库存不变；选择不存在供应商被拒；收到 4 瓶时仍能查看待收 6 瓶；重复确认不建第二张采购单。

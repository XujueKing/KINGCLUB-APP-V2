# 记支出

状态：In Review，仅设计；文字线框 v1。适用 [公共页面契约](../README.md)；首期由超级管理员操作，后续配置角色。本文未确认的技术处理均为设计建议，不修改真实账户或库存。

## 目标、入口和返回

用业务分类记录真实支出，自动关联采购或备用金，避免重复记账。

记账 → 记支出；storeId、可选 sourceRef。返回当日支出，保留筛选。

## 手机线框与字段

业务分类 → 金额/币种 → 付款账户 → 发生时间 → 来源单/票据/备注 → 预览影响 → 确认。

categoryRef、amountMinor、currency、accountRef、occurredAt、sourceRef、attachmentRefs、note、commandId。正数金额，单据所属店/主体一致。

## 操作和业务变化

选进货付款时关联采购并展示已付/待付；选备用金领用跳到调拨；日常水电等费用按分类记录。已由订单/渠道自动记录的来源提示查看原记录，不能再手填同一收支。

## 异常与更正

凭证附件可后补但金额、账户与分类必填。缺模板/未分类可留待处理，报表标不完整；期间已锁不能直接回写。网络未知查原支出单。已确认更正须原单/原因，不直接改余额。

加载用骨架；空记录提供新建/返回；离线仅存草稿，确认需联网。无权限返回工作台；会话过期重新登录后查询原操作。字段错误保留输入并定位，未知结果保留 commandId 查询，不重复新建。

## 契约与记录

PreviewIncomeExpense/ConfirmIncomeExpense/CorrectIncomeExpense；现金支出与费用分类分别保存，采购付款冲采购应付/预付款，不再扣已售成本。

语义接口与字段尚未注册，正式 DTO/接口编号待统一定稿；事件记录门店、主体、来源、真实操作人、时间、请求和更正原因。金额精确整数、数量十进制加单位；不记录附件秘密地址或个人支付凭据。草稿/待确认/已确认/处理中明确区分。

# 订单详情与退款进度

状态：In Review，仅文档；文字线框 v1。适用 [公共页面契约](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md)。经营功能先由超级管理员使用，会员只操作本人权益；配置细节未确认处为设计建议。

## 入口、路由与返回

订单列表/付款结果/AA 成团进入；orderId。返回原入口；来源链接进入采购/库存/支付详情时保持范围。

## 线框与字段

订单号/门店 → 商品与成交优惠快照 → 支付明细 → 履约明细 → 退款明细 → 允许动作/来源记录。

orderId、version、lines、paymentComponents、fulfillments、refunds、allowedActions；具体动作由服务端状态决定。

## 操作规则

直接单付款确认出库；AA 全部付齐成团后整单出库；交付只是履约确认。退款申请展示可退明细、金额和去向，管理员确认后进入进度。普通订单按最终支付/券退款规则预览；加餐未成团固定退各付款会员 APP 余额。单点可存酒行提供存酒申请。

## 数据效果与状态

GetOrder/PreviewOrderRefund/RequestOrderRefund/GetRefund；累计退款不超过实收可退金额，退款和实物回库分开。存酒/已消费商品的退货需核对来源，不自动补回可售库存。

加载显示骨架；空列表给下一步；离线保留草稿/只读缓存但不确认交易；会话过期重登后读取原对象；越权/错店拒绝并提供返回。字段错误保留输入并定位；写请求携带 commandId 和版本，处理中查询原操作，重复提交不重复生效。不可逆业务结果以回执而非短提示展示。

## 审计与展示

语义接口/字段为草案，未注册正式编号。服务端校验主体、门店、对象归属；记录实际操作人、对象及变更来源，不记录完整券码/支付秘密。金额为最小货币单位整数及币种，数量为精确十进制和单位；切语言不改状态和金额。四语言文案、读屏标签、大字换行与非颜色状态标识按公共约定，资源键表待定稿。

## 验收设计（未执行）

部分退款保留原单；支付未知先查原付款不重付；成功退款未退实物不回库。AA 门票酒无存酒入口，直接购买酒可进入来源校验。

合成 Mock 需覆盖主流程、空/错/离线/会话失效、返回、版本变化、重复请求和四语言。项目 UI 验收后才验证真实接口与库存/资金事务，不将本页视为已上线或已验收。

# 库存流水与批次详情

状态：In Review，仅文档；文字线框 v1。适用 [公共页面契约](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md)。经营功能先由超级管理员使用，会员只操作本人权益；配置细节未确认处为设计建议。

## 入口、路由与返回

库存 → 商品库存 → 流水；storeId、productId、locationRef、可选 batchRef。返回保留日期/类型筛选。

## 线框与字段

当前可售/预留/待交付/保管分区 → 批次与进价 → 入出/调整流水 → 来源单与操作者 → 更正入口。

movementId、sourceRef、batchRef、quantityDelta、unit、unitCost、occurredAt、actorRef、reversalOf；预留事件单独标记。

## 操作规则

逐笔查看采购入库、销售出库、调酒差异、损耗、盘点和退货。预留释放不是实际收货，不能当入库收入；批次实际进价与已售成本可追溯。更正走来源流程，不提供直接改库存总数。

## 数据效果与状态

ListInventoryMovements/GetBatch/GetMovementSource；按账类和位置对齐数量。会员保管酒单独保管账，不能加入可售量。未知批次成本标待补，不按零处理。

加载显示骨架；空列表给下一步；离线保留草稿/只读缓存但不确认交易；会话过期重登后读取原对象；越权/错店拒绝并提供返回。字段错误保留输入并定位；写请求携带 commandId 和版本，处理中查询原操作，重复提交不重复生效。不可逆业务结果以回执而非短提示展示。

## 审计与展示

语义接口/字段为草案，未注册正式编号。服务端校验主体、门店、对象归属；记录实际操作人、对象及变更来源，不记录完整券码/支付秘密。金额为最小货币单位整数及币种，数量为精确十进制和单位；切语言不改状态和金额。四语言文案、读屏标签、大字换行与非颜色状态标识按公共约定，资源键表待定稿。

## 验收设计（未执行）

收货 10、预留 2 显示在库 10/预留 2/可售 8；付款出库 2 后在库 8/预留 0/可售 8；释放预留不创建采购入库。原流水与冲正均可查。

# 商品详情

状态：In Review，仅文档；文字线框 v1。适用 [公共页面契约](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md)。经营功能先由超级管理员使用，会员只操作本人权益；配置细节未确认处为设计建议。

## 入口、路由与返回

商品列表或分享进入；storeId、productId、可选 tableSessionId。返回原列表位置。

## 线框与字段

图片/四语言名称 → 售价/规格 → 套餐组成 → 可选履约方式 → 数量 → 加入购物车。

productId、variantRef、quantity、fulfillmentType；返回 offerVersion、components、purchaseRules、availability。

## 操作规则

数量按售卖单位和步长选择；展示实际套餐内容，不能把 AA 门票权益当可存酒商品。到店、自提、配送、链上区分类型；尚无契约的能力标明待开放，不调用真实 SDK。

## 数据效果与状态

GetProductOffer；商品下架或价格变更需刷新，加入购物车不保证库存。切规格清楚更新单位/价格。

加载显示骨架；空列表给下一步；离线保留草稿/只读缓存但不确认交易；会话过期重登后读取原对象；越权/错店拒绝并提供返回。字段错误保留输入并定位；写请求携带 requestId 和版本，处理中查询原操作，重复提交不重复生效。不可逆业务结果以回执而非短提示展示。

## 审计与展示

语义接口/字段为草案，未注册正式编号。服务端校验主体、门店、对象归属；记录实际操作人、对象及变更来源，不记录完整券码/支付秘密。金额为最小货币单位整数及币种，数量为精确十进制和单位；切语言不改状态和金额。四语言文案、读屏标签、大字换行与非颜色状态标识按公共约定，资源键表待定稿。

## 验收设计（未执行）

两瓶规格不是两杯；缺货、下架、参数错误都有原因。套餐内容可展开；会员端不展示供应商进价。

合成 Mock 需覆盖主流程、空/错/离线/会话失效、返回、版本变化、重复请求和四语言。项目 UI 验收后才验证真实接口与库存/资金事务，不将本页视为已上线或已验收。

# 券模板配置

状态：In Review，仅文档，文字线框 v1。执行 [公共页面契约](../README.md) 与 [已确认营业规则](../../CONFIRMED_OPERATING_RULES.md)。首期超级管理员操作，后续配置权限；未明确的默认行为均为待评审设计，不代表修改真实账号。

## 入口与返回

工作台 → 商品/权益 → 券模板；templateId 可选。保存回模板预览，发行操作另记录。

## 信息和字段

名称四语言 → 抵扣/折扣/门票类型 → 适用主体/店/商品 → 门槛/优惠/封顶 → 有效期 → 叠加及退券规则 → 结算例子预览。

templateId、type、amountMinorOrDiscountRate、currency、threshold、discountCap、validityPolicy、eligibleRefs、stackPolicy、aaEligibility、refundPolicyRef、version。

## 操作与结果

用户确认优惠与期限按券配置。模板必须能解释应付怎么算；固定日期或领券后期限明确一种。发行时冻结规则版本，后续改模板用于新券，不直接改已领券。抵扣券和门票权益分类型，第三方商品映射另外维护且不能伪造已授权。

## 数据契约与异常

SaveCouponTemplate/PreviewCouponCalculation；草稿/启用/停发分别处理。停发不使已持券失效；撤销已有券是带理由的独立动作。折扣范围、时间先后和门槛/封顶合法性校验，未配置叠加不默认无限叠加。

接口和字段是语义草案，未注册编号。服务端验证主体、门店、实际操作人、对象版本；写动作以 commandId 防重。加载骨架、空数据指引、无权限返回、会话过期重登后查原单；离线只读/保存草稿，不提交经营结果。失败保留输入并定位原因；超时未知保持原请求查询，不显示假成功。返回保留来源状态与筛选，切店不转移草稿。

## 审计、语言与验收

记录操作者、原/新版本、业务来源、状态、时点和原因；日志不保存完整券码或账户密钥。金额用最小货币单位整数并附币种；四语言共用语义状态，读屏标签/大字/非颜色反馈按公共约定，翻译资源尚待定稿。

合成例：原价 200，满 100 减 20，应付 180；8 折且优惠封顶 30，应付 170。模板改期限不缩短原券有效期；选择不适用店必须显示原因。

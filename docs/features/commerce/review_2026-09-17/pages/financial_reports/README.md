# 财务报表

状态：In Review，仅文档；文字线框 v1。[公共页面规则](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md) 适用。管理员经营操作先由超级管理员执行；会员限本人权益，不因后台全功能权限改变数据隔离。

## 入口与返回

记账 → 更多 → 报表；ledgerId、period、reportType。汇总数字 → 科目/来源，返回原报表。

## 页面和字段

账套/期间/币种 → 数据完整性 → 资产负债/利润/现金流选择 → 报表行 → 来源与生成时间。

reportType、templateVersion、asOf、completenessStatus、rows[rowCode,amountMinor,sourceRefs]、currency。

## 操作与数据效果

按已审定模板生成，来源来自账簿与现金流分类。缺成本、缺模板、未分类显示不完整；经营利润看板和正式账表口径分别说明，不能包装成相同结果。导出保留期间/版本/生成时间，不在本轮真实导出经营数据。

GetFinancialReport/GetReportDrilldown/RequestReportExport；异步任务区分准备/生成/失败，不能点击导出就假称已完成。

## 状态、审计及四语言

加载骨架，空记录给下一步；无权限返回，会话失效重登后查询原对象；离线仅只读/草稿，不确认账务或交付。失败保留输入，字段错误定位，未知结果持原 commandId 查询，不重复新建。返回保留门店、期间及筛选；切店不能改变原单归属。

接口/字段为语义草案，正式编号/DTO 未冻结。服务端校验主体、门店、实际操作者和对象版本；金额最小单位整数及币种，数量十进制加单位。审计来源、状态变更、操作者和更正原因；日志不记录完整地址、二维码、财务密钥。四语言共用状态键，金额与日期明确单位/时区，大字可换行、操作有读屏标签；文案资源仍待定稿。

## 验收设计（未执行）

报告数字能追凭证；现金增加的会员充值不能因此显示成商品销售；待结算收入与到账分开；缺模板报表不给虚假的全零成功。

还需合成 Mock 验证并发/重复请求、错店、未知状态、返回和四语言；真实服务验收在项目 UI 验收后按批准契约进行。本轮无付款、退款、导入、交割或生产账务操作。

## 未定范围

法定报表结构、税务政策与币种折算未确认；三张报表能力保留但不宣称已符合某制度。

# 佣金明细与结算

状态：In Review，仅文档；文字线框 v1。[公共页面规则](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md) 适用。管理员经营操作先由超级管理员执行；会员限本人权益，不因后台全功能权限改变数据隔离。

## 入口与返回

会员佣金入口或管理员记账 → 佣金；beneficiaryRef、issuerScope、period。返回原汇总。

## 页面和字段

待确认/可结算/已结算/冲回 → 来源订单 → 规则版本/计提金额 → 结算记录。

commissionEventId、orderRef、beneficiaryRef、ruleVersion、basisMinor、commissionMinor、currency、status、settlementRef。

## 操作与数据效果

佣金由来源业务及规则产生，不能录一个比例就立即付款。退款取消关联冲回，已结算退款后显示待追回/后续抵扣提案，不删除已付记录或擅自扣会员其他资产。超级管理员先查看/处理全部经营流程，实际转账仅在批准接入后实现。

GetCommissionStatement/PreviewCommissionSettlement/ConfirmCommissionSettlement；同一计提事件不重复结算，渠道未知保留处理中。结算付款和佣金费用不得各重复记一遍。

## 状态、审计及四语言

加载骨架，空记录给下一步；无权限返回，会话失效重登后查询原对象；离线仅只读/草稿，不确认账务或交付。失败保留输入，字段错误定位，未知结果持原 commandId 查询，不重复新建。返回保留门店、期间及筛选；切店不能改变原单归属。

接口/字段为语义草案，正式编号/DTO 未冻结。服务端校验主体、门店、实际操作者和对象版本；金额最小单位整数及币种，数量十进制加单位。审计来源、状态变更、操作者和更正原因；日志不记录完整地址、二维码、财务密钥。四语言共用状态键，金额与日期明确单位/时区，大字可换行、操作有读屏标签；文案资源仍待定稿。

## 验收设计（未执行）

订单回调两次只计提一次；支付处理中不能再次新建结算；已结算订单退款保留原结算及冲回来源。

还需合成 Mock 验证并发/重复请求、错店、未知状态、返回和四语言；真实服务验收在项目 UI 验收后按批准契约进行。本轮无付款、退款、导入、交割或生产账务操作。

## 未定范围

具体受益角色、比例/基数、成熟条件、结算周期及追回政策尚未冻结，不默认推荐层级或多级佣金。

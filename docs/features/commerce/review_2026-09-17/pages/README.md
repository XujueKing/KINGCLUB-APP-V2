## 所有页面共同契约

- 路由名和字段为语义草案，不注册正式接口编号；金额为最小货币单位整数及币种，数量为精确十进制字符串及单位。所有示例仅合成数据。
- 页面上方固定显示当前门店，明细属于原门店；切店有未保存草稿时提示保存/放弃，不能把原单移到新店。会员身份、管理员身份取服务端会话。
- 加载显示骨架；空列表显示具体下一步；校验错误定位字段；请求未知保留 requestId 并查询原结果；离线允许草稿但不能确认付款/库存/核销；会话失效重新登录后读原单；无权限展示原因及返回入口。
- 写操作提交时禁用重复按钮；结果查询中不能新建同一动作。失败保留可更正输入；成功回执包含单号、门店、时间、状态，不靠短暂提示代替回执。
- 列表返回保留筛选和滚动位置，详情刷新后返回原入口。四语言共用语义键；不硬编码显示文本，日期按门店时区，金额附币种。按钮有文本和读屏标签，状态不只靠颜色，大字模式可换行。
- 审计事件记录真实操作人、对象、门店、请求及状态变化，不记录完整券码、二维码令牌或支付凭据；业务失败原因和重复请求可关联查找。
- 每页下面的用例为未来 Mock/集成验收要求，均未执行。页面先走合成数据与全部状态，真实接入另遵守项目 UI 验收门禁。

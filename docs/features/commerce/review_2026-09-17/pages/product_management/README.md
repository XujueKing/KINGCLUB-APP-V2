# 商品与配方维护

状态：In Review，仅文档；文字线框 v1。适用 [公共页面契约](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md)。经营功能先由超级管理员使用，会员只操作本人权益；配置细节未确认处为设计建议。

## 入口、路由与返回

经营管理 → 商品资料；productId 可选，保存回详情或原采购选品。

## 线框与字段

商品名称四语言 → 类别/规格/基础单位 → 单品或套餐组成 → 门店售价/上下架 → 预览保存。成本显示来源批次，不用售价字段替代。

productId、localizedNames、type、baseUnit、unitConversions、components[productRef,quantity,unit]、storeOffer、version。

## 操作规则

超级管理员维护商品；采购、出库从商品表选择。套餐和调酒用配方版本关联实物商品，禁止循环组成及无换算单位。改配方/售价生成新版本，已成交订单保持快照。上下架不删除库存。酒类容量、耗品消耗型/周转型明确配置。

## 数据效果与状态

SaveProduct/SaveRecipe/SaveStoreOffer；套餐不另造可独立增减的虚拟实物库存。套内相同原料先合并用量再算可售份数。

加载显示骨架；空列表给下一步；离线保留草稿/只读缓存但不确认交易；会话过期重登后读取原对象；越权/错店拒绝并提供返回。字段错误保留输入并定位；写请求携带 requestId 和版本，处理中查询原操作，重复提交不重复生效。不可逆业务结果以回执而非短提示展示。

## 审计与展示

语义接口/字段为草案，未注册正式编号。服务端校验主体、门店、对象归属；记录实际操作人、对象及变更来源，不记录完整券码/支付秘密。金额为最小货币单位整数及币种，数量为精确十进制和单位；切语言不改状态和金额。四语言文案、读屏标签、大字换行与非颜色状态标识按公共约定，资源键表待定稿。

## 验收设计（未执行）

一套含啤酒 2 瓶，可售啤酒 5 瓶则最多 2 套；多个组成重复引用同款必须先累加。配方引用自身或单位缺失拒绝。旧单不随新价格变化。

合成 Mock 需覆盖主流程、空/错/离线/会话失效、返回、版本变化、重复请求和四语言。项目 UI 验收后才验证真实接口与库存/资金事务，不将本页视为已上线或已验收。

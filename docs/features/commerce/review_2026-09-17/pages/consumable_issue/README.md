# 耗品领用与损耗

状态：In Review，仅设计；文字线框 v1。适用 [公共页面契约](../README.md)；首期由超级管理员操作，后续配置角色。本文未确认的技术处理均为设计建议，不修改真实账户或库存。

## 目标、入口和返回

登记杯具、纸巾等易耗损耗用品从库存领用和损失。

库存 → 用品 → 领用/损耗；storeId、可选 issueId。返回用品记录列表。

## 手机线框与字段

用途 → 用品选择 → 领用位置/使用位置 → 本次数量 → 备注 → 确认。

productId、quantity、unit、sourceLocation、destinationLocation、purpose、requestId；只从用品目录选择。

## 操作和业务变化

建议按用品类别配置领用处理：消耗型用品在领用时结转费用；可重复用器具领到吧台先转位置，实际破损才登记损耗。页面明确显示“领用后库存/费用如何变化”，不要求员工选会计科目。

## 异常与更正

超库存拒绝；跨主体/错误用品类型拒绝；退回必须实物确认并引用原领用行。相同用品不能同时按采购付款和领用重复记费用。具体类别初始化仍为设计建议。

加载用骨架；空记录提供新建/返回；离线仅存草稿，确认需联网。无权限返回工作台；会话过期重新登录后查询原操作。字段错误保留输入并定位，未知结果保留 requestId 查询，不重复新建。

## 契约与记录

RecordConsumableIssue/RecordConsumableLoss/ReturnConsumable；数量事件、位置事件及费用事件使用不同类型，原单防重。

语义接口与字段尚未注册，正式 DTO/接口编号待统一定稿；事件记录门店、主体、来源、真实操作人、时间、请求和更正原因。金额精确整数、数量十进制加单位；不记录附件秘密地址或个人支付凭据。草稿/待确认/已确认/处理中明确区分。

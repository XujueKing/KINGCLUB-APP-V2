# 科目与明细账总账

状态：In Review，仅文档；文字线框 v1。[公共页面规则](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md) 适用。管理员经营操作先由超级管理员执行；会员限本人权益，不因后台全功能权限改变数据隔离。

## 入口与返回

记账 → 更多 → 科目/账簿；ledgerId、accountRef、period。总账 → 明细 → 凭证，返回原筛选。

## 页面和字段

账套/期间 → 科目列表 → 期初/本期借贷/期末 → 分录来源 → 凭证。

accountRef、accountCode、name、normalBalanceSide、enabled、openingMinor、debitMinor、creditMinor、closingMinor、currency。

## 操作与数据效果

默认模板初始化科目，普通经营无需编辑科目。超级管理员可维护符合约束的资料；已有过账的科目不能删除，停用仅阻止后续使用。明细与总账同口径，同一查询快照可以追溯。

ListAccounts/SaveAccount/GetGeneralLedger/GetSubLedger；每核算主体独立账套，门店是业务维度，不跨币种加总。期初缺失标未初始化，不把零当已有审定期初。

## 状态、审计及四语言

加载骨架，空记录给下一步；无权限返回，会话失效重登后查询原对象；离线仅只读/草稿，不确认账务或交付。失败保留输入，字段错误定位，未知结果持原 requestId 查询，不重复新建。返回保留门店、期间及筛选；切店不能改变原单归属。

接口/字段为语义草案，正式编号/DTO 未冻结。服务端校验主体、门店、实际操作者和对象版本；金额最小单位整数及币种，数量十进制加单位。审计来源、状态变更、操作者和更正原因；日志不记录完整地址、二维码、财务密钥。四语言共用状态键，金额与日期明确单位/时区，大字可换行、操作有读屏标签；文案资源仍待定稿。

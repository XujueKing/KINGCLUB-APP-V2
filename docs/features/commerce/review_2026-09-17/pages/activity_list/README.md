# 活动列表

更新：2026-09-18。In Review，文字线框 v1，仅文档。适用 [页面公共约定](../README.md) 与 [数据契约草案](../../CONTRACT_BASELINE.md)。

## 入口与返回

会员选择地区/门店进入；storeId、dateFilter。返回地区/门店页，保留筛选。

## 页面与字段

门店/日期 → 活动卡（名称、时间、套餐摘要、报名状态）→ 活动详情。

ListStoreActivities；activityId、name、startAt、enrollmentState、packageSummary、myRegistrationState。 ID、状态和字段均为语义草案，非正式 API 编号。

## 交互与边界

活动不显示单卡座余位作为报名上限。我的待分配报名有明确入口；停止报名的活动可看本人记录，不假装已开台。切店旧请求结果丢弃。

加载骨架、空数据指引、错误重试、无权限返回、会话失效重登后读取原对象。离线缓存标更新时间，不确认报名/入座/付款；未知写结果查询原 commandId。返回保留筛选，重复提交不重复生效；版本变化重新读取。字段错误定位且保留有效输入。

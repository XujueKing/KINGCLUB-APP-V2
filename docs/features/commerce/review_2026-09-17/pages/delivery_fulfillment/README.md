# 配送与退货交付

状态：In Review，仅文档；文字线框 v1。[公共页面规则](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md) 适用。管理员经营操作先由超级管理员执行；会员限本人权益，不因后台全功能权限改变数据隔离。

## 入口与返回

会员结算填写配送信息，订单查看物流；管理员待发货/退货进入。orderId、shipmentRef；返回订单。

## 页面和字段

地址/范围/运费预览 → 商品待发 → 本次发货数量/承运信息 → 配送进度 → 签收或异常 → 退货实收检查。

addressRef、addressSnapshot、shippingFeeMinor、currency、shipmentLines、carrierRef、trackingRef、deliveryEvidenceRef、returnRef、commandId。

## 操作与数据效果

提交前校验范围和运费，成交保存地址快照；付款后地址变更需重验，已发货不静默改。部分发货分别跟踪；填写单号不等于送达。退货先关联退款/售后单，实物到店且可再售才回库，不按退款金额自动增库存。

QuoteDelivery/ConfirmShipment/RecordDeliveryResult/ConfirmReturnedGoods；发货/签收/退款/退货各态独立，已付款出库不在发货时重复扣。真实物流未接时不展示假轨迹。

## 状态、审计及四语言

加载骨架，空记录给下一步；无权限返回，会话失效重登后查询原对象；离线仅只读/草稿，不确认账务或交付。失败保留输入，字段错误定位，未知结果持原 commandId 查询，不重复新建。返回保留门店、期间及筛选；切店不能改变原单归属。

接口/字段为语义草案，正式编号/DTO 未冻结。服务端校验主体、门店、实际操作者和对象版本；金额最小单位整数及币种，数量十进制加单位。审计来源、状态变更、操作者和更正原因；日志不记录完整地址、二维码、财务密钥。四语言共用状态键，金额与日期明确单位/时区，大字可换行、操作有读屏标签；文案资源仍待定稿。

## 验收设计（未执行）

3 件分两批发，第一批不能标整单收货；退款 1 件但未退货不回库；退回破损件走损耗，重复实收不重复回库。

还需合成 Mock 验证并发/重复请求、错店、未知状态、返回和四语言；真实服务验收在项目 UI 验收后按批准契约进行。本轮无付款、退款、导入、交割或生产账务操作。

## 未定范围

配送范围/运费、签收证据、自动收货期限、退货运费和地址变更责任待配置；不强制接物流平台。

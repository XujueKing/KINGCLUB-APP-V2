# 活动详情与我的报名

更新：2026-09-18。In Review，文字线框 v1，仅文档。适用 [页面公共约定](../README.md) 与 [数据契约草案](../../CONTRACT_BASELINE.md)。

## 入口与返回

活动列表或我的报名进入；storeId、activityId、可选 registrationId。报名成功回此页，返回原列表。

## 页面与字段

活动时间/规则 → 套餐说明 → 本人权益/报名状态 → 待分配或桌号 → 报名/查看卡座/退票进度。

GetStoreActivity/GetRegistration；活动版本、权益条件、registrationState、assignmentRef、tableSessionRef、ticketReturnState。 ID、状态和字段均为语义草案，非正式 API 编号。

## 交互与边界

报名跳已定义报名页；未分配明确提示等待安排，无桌号占位。已分配进入桌台详情，实际入座另记。人工失效与退票各自显示，不自动套用 AA 30 分钟退款。

加载骨架、空数据指引、错误重试、无权限返回、会话失效重登后读取原对象。离线缓存标更新时间，不确认报名/入座/付款；未知写结果查询原 commandId。返回保留筛选，重复提交不重复生效；版本变化重新读取。字段错误定位且保留有效输入。

## 审计与验收（未执行）

同活动分到三桌，各人只显示当前有效分配；换座后旧桌入口提示已变更；活动配置更新不静默覆盖原权益。

审计操作者、门店、对象和状态变化，不记录券码/个人支付秘密；四语言共用状态与语义键，日期按门店时区，读屏标签及大字布局须后续验收。以上先用合成 Mock，真实接口待项目 UI 验收与契约批准。

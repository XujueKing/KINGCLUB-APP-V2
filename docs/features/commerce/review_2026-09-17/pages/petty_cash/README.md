# 备用金领用与归还

状态：In Review，仅设计；文字线框 v1。适用 [公共页面契约](../README.md)；首期由超级管理员操作，后续配置角色。本文未确认的技术处理均为设计建议，不修改真实账户或库存。

## 目标、入口和返回

记录钱在资金账户与吧台经手人之间的移交，清楚知道交了多少钱。

记账 → 备用金；storeId、shiftId。成功进入调拨回执，返回班次资金明细。

## 手机线框与字段

领用/归还 → 转出/转入账户 → 经手人 → 金额/币种 → 交接时间/备注 → 确认。

direction、sourceAccountRef、destinationAccountRef、amountMinor、currency、handlerRef、shiftId、occurredAt、requestId。实际操作人由会话记录，不能用经手人替代。

## 操作和业务变化

先由超级管理员确认真实交接。领用转出账户减少、吧台账户增加；归还反向。一个人可办理但仍记录实际经手和确认信息；后续双人确认作为可配置项，不增加当前审批层级。

## 异常与更正

同账户互转、币种不匹配、金额非正、余额不足拒绝。现金尚未交接时可存草稿，不能提前显示已领。错误通过反向更正单处理，不能删流水。

加载用骨架；空记录提供新建/返回；离线仅存草稿，确认需联网。无权限返回工作台；会话过期重新登录后查询原操作。字段错误保留输入并定位，未知结果保留 requestId 查询，不重复新建。

## 契约与记录

TransferPettyCash/GetCashTransfer；内部调拨两端同事务、同来源编号，平台不同主体账户不混用。领用不是经营费用。

语义接口与字段尚未注册，正式 DTO/接口编号待统一定稿；事件记录门店、主体、来源、真实操作人、时间、请求和更正原因。金额精确整数、数量十进制加单位；不记录附件秘密地址或个人支付凭据。草稿/待确认/已确认/处理中明确区分。

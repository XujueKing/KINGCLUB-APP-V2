# 自提订单与交付

状态：In Review，仅文档；文字线框 v1。[公共页面规则](../README.md) 和 [营业规则](../../CONFIRMED_OPERATING_RULES.md) 适用。管理员经营操作先由超级管理员执行；会员限本人权益，不因后台全功能权限改变数据隔离。

## 入口与返回

会员订单详情 → 自提码；管理员待自提 → 订单/扫码。orderId、fulfillmentRef；返回订单原状态。

## 页面和字段

提货门店/时间 → 商品已备/已提/待提 → 会员提货码 → 员工本次实交数量 → 确认/回执。

orderId、fulfillmentRef、lineQuantities、codeRef、expiresAt、version、commandId；码是短期凭据不含可直接授权的用户输入。

## 操作与数据效果

付款成功已出销售库存，备货放待交付区域；取货确认只登记实物交付，不再扣可售库存。部分自提逐行记录，全部交完才完成。扫码先预览，原店管理员核对后确认。

GetPickupOrder/IssueOrderPickupCode/PreviewOrderPickup/ConfirmOrderPickup；与存酒码用途分开。错店、码过期、已用、取消、退款中或超待交付数量拒绝；超时请求查原交付。

## 状态、审计及四语言

加载骨架，空记录给下一步；无权限返回，会话失效重登后查询原对象；离线仅只读/草稿，不确认账务或交付。失败保留输入，字段错误定位，未知结果持原 commandId 查询，不重复新建。返回保留门店、期间及筛选；切店不能改变原单归属。

接口/字段为语义草案，正式编号/DTO 未冻结。服务端校验主体、门店、实际操作者和对象版本；金额最小单位整数及币种，数量十进制加单位。审计来源、状态变更、操作者和更正原因；日志不记录完整地址、二维码、财务密钥。四语言共用状态键，金额与日期明确单位/时区，大字可换行、操作有读屏标签；文案资源仍待定稿。

## 验收设计（未执行）

买 3 件先提 1，剩余 2；扫码重放不再提 1；付款已扣库存取货不二扣。未按时来不自动标已收货或销毁。

还需合成 Mock 验证并发/重复请求、错店、未知状态、返回和四语言；真实服务验收在项目 UI 验收后按批准契约进行。本轮无付款、退款、导入、交割或生产账务操作。

## 未定范围

可预约时间、超时联系/退款、代取政策待定；不得套用 AA 的 30 分钟规则。

# 日结与交班

状态：In Review，仅设计；文字线框 v1。适用 [公共页面契约](../README.md)；首期由超级管理员操作，后续配置角色。本文未确认的技术处理均为设计建议，不修改真实账户或库存。

## 目标、入口和返回

每天核对收款、库存待办和现金，把未完成事项留到下一班继续处理。

经营工作台 → 今日核对/交班；storeId、businessDate、shiftId。完成后回日结记录，不自动关闭门店或销售入口。

## 手机线框与字段

营业日/时区 → 各账户期初/收入/退款/支出/调拨 → 实点现金 → 差额 → 库存/退款/渠道待办 → 确认交班。

shiftId、accountCounts[accountRef,actualAmountMinor]、note、expectedVersion、commandId；系统数服务端计算。营业日切点为门店设置，未配置先提示设置，不默认把旧 04:00 当确认规则。

## 操作和业务变化

系统预期现金 = 期初 + 现金实收 + 调入 − 现金退款 − 现金支出 − 调出。现金实点单独输入；渠道待结算和会员余额不当现金。差额记录原因和待办，不改订单抹平。

## 异常与更正

未完成退款、待交付、渠道差异列出责任来源。设计建议允许带可追踪待办交班，但阻止重复交班、无实点及数据未知的账户确认；日结不是会计月结，不能把待办标已完成。跨班晚到事件按实际入账和原业务来源记录调整，不覆盖旧快照。

加载用骨架；空记录提供新建/返回；离线仅存草稿，确认需联网。无权限返回工作台；会话过期重新登录后查询原操作。字段错误保留输入并定位，未知结果保留 commandId 查询，不重复新建。

## 契约与记录

PreviewShiftClose/CloseShift/GetShiftClose；draft → reviewing → closed，closeId 幂等。日结快照记录统计范围/时点，后续调整另附。具体硬性阻断项目作为可配置设计继续评审。

语义接口与字段尚未注册，正式 DTO/接口编号待统一定稿；事件记录门店、主体、来源、真实操作人、时间、请求和更正原因。金额精确整数、数量十进制加单位；不记录附件秘密地址或个人支付凭据。草稿/待确认/已确认/处理中明确区分。

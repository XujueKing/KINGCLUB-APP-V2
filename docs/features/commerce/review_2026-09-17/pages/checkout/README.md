# 点单结算

状态：In Review；线框版本 v1（文字线框）。适用 [公共页面契约](../README.md)，不代表编码批准。

## 目标、入口与返回

会员核对商品、使用优惠券，选择自己付款或分份 AA。

购物车进入；storeId、cartRef、可选 tableSessionId。返回保留购物车；创建后进入订单或 AA 进度。

## 线框与字段

门店/桌号 → 商品明细 → 优惠券选择 → 原价/优惠/应付 → 直接买单或 AA → 确认区。AA 额外显示份数、每份金额及 30 分钟退款说明。

商品引用/数量、couponRef、paymentMode、shareCount；返回 quoteId、quoteVersion、originalAmount、discountAmount、payableAmount、currency、份额明细。

## 操作与结果

服务端报价与券规则校验；选择券后刷新应付。直接付款提交预留并走支付状态；AA 创建固定金额/份数和服务端截止时间，转进度页分享。

## 状态与异常

券过期、商品不适用、库存/价格变化给出原因并重新确认。支付未知查询原订单。无外部核销能力时不显示第三方自动核销成功。 加载、空、离线、会话失效、无权限、返回和可访问性按公共契约执行。

## 数据与审计

QuoteCart/CreateDirectOrder/CreateAAGroup；按券配置应用抵扣/折扣，优惠、份额及尾差有快照。AA 份额能否用券由配置定义，不默认叠加。 事件记录本页查看/提交结果及必要业务引用，审计实际操作者；不记录码值或支付秘密。字段为待定稿语义契约，真实接口编号/DTO 映射待审定。

## 验收设计

选择抵扣券/折扣券后金额可解释；不适用券有原因；最后一件被抢购后不得负库存；直接支付成功出库，AA 仅创建时不出库。

以上先用合成 Mock 场景评审，随后在项目 UI 验收通过后验证真实事务、幂等及接口错误映射；本轮未执行。四语言、大字和读屏须覆盖主操作、错误及回执。

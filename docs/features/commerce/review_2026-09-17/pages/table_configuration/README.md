# 卡座配置

状态：In Review，仅文档，文字线框 v1。执行 [公共页面契约](../README.md) 与 [已确认营业规则](../../CONFIRMED_OPERATING_RULES.md)。首期超级管理员操作，后续配置权限；未明确的默认行为均为待评审设计，不代表修改真实账号。

## 入口与返回

工作台 → 配置 → 卡座；storeId、tableId 可选。返回卡座配置列表。

## 信息和字段

桌号/名称 → 最小人数/最大人数 → 男女配比条件 → 启用状态 → 保存预览。

tableId、label、minSeats、maxSeats、genderConstraints、enabled、version；min/max 为正整数且 min ≤ max。

## 操作与结果

按用户确认，每桌达到 minSeats 可开台且不得超过 maxSeats。配比表达式需与人数兼容：设计建议采用可校验的性别人数上限/下限模板，具体模板由配置明确，不把固定比例自动四舍五入。性别未知时提示人工核实，不推断或伪造会员资料。

## 数据契约与异常

SaveTableConfiguration/PreviewTableConstraints；新开台复制配置快照。已有分座/营业中的卡座修改需预览影响，默认仅应用未来开台；停用不取消当前订单或移走会员。

接口和字段是语义草案，未注册编号。服务端验证主体、门店、实际操作人、对象版本；写动作以 requestId 防重。加载骨架、空数据指引、无权限返回、会话过期重登后查原单；离线只读/保存草稿，不提交经营结果。失败保留输入并定位原因；超时未知保持原请求查询，不显示假成功。返回保留来源状态与筛选，切店不转移草稿。

## 审计、语言与验收

记录操作者、原/新版本、业务来源、状态、时点和原因；日志不保存完整券码或账户密钥。金额用最小货币单位整数并附币种；四语言共用语义状态，读屏标签/大字/非颜色反馈按公共约定，翻译资源尚待定稿。

最小 6 最大 10：6 可开、5 不可、11 不可；最小 12 最大 10 拒绝。配置改为最大 8，不把已分配 10 人静默丢弃；跨店桌号相同仍用各自 ID。

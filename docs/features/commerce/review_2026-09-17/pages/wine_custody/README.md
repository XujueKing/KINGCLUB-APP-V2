# 存取酒办理

状态：In Review；线框版本 v1（文字线框）。适用 [公共页面契约](../README.md)，不代表编码批准。

## 目标、入口与返回

购买会员申请存取酒，超级管理员在原门店核实实物并确认。

会员订单/存酒记录进入申请；管理员扫码打开对应申请。参数 storeId、sourceOrderLineRef 或 custodyRef、operationRef。返回来源订单/存酒详情。

## 线框与字段

会员：来源酒款/可存余量 → 本次数量 → 原店/3个月期限 → 办理码/结果。管理员：用途/购买会员/来源 → 实物数量/位置 → 确认及回执。

operationType、sourceOrderLineRef、custodyRef、quantity、unit、expectedVersion；二维码仅短期不透明凭据；返回保管余量、到期时间、事件引用。

## 操作与结果

AA 门票酒直接说明不可存；单点或购买套餐来源校验购买者和未重复存入数量。扫码查看不记账，管理员核实后确认存入。取用填本次取出量，服务端适配旧剩余量参数并核销。

## 状态与异常

错店、非购买会员、过期/已用码、数量超余量拒绝；未知结果查原操作。保管期到期不自动销毁实物，不刷新期限或转售。多人 AA 加餐不自动归发起人。 加载、空、离线、会话失效、无权限、返回和可访问性按公共契约执行。

## 数据与审计

CreateWineDepositRequest/ConfirmWineDeposit/CreateWinePickupRequest/ConfirmWinePickup；所有变动进保管账，不进可售库存，不重复记销售。 事件记录本页查看/提交结果及必要业务引用，审计实际操作者；不记录码值或支付秘密。字段为待定稿语义契约，真实接口编号/DTO 映射待审定。

## 验收设计

AA 门票酒拒绝；同一会员另购酒可存；他人订单不可存，其他店不可取；同一码重放只扣一次；部分取后余量正确。

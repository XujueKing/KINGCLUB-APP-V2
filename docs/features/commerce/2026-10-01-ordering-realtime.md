# 扫码点单的通知与前台恢复

扫码点单入口复用 KINGCLUB 已认证实时事件流，收到 connection.ready 或 commerce.changed 时合并刷新桌台资格与商品目录；通知不直接提供金额、库存或身份授权。加载过程中继续收到通知时，完成后再次读取，后台不发起刷新；返回前台重新核验。会员会话变化清除已有上下文，晚响应由请求代次隔离。

同一会员、门店、桌台场次的目录刷新保留有效选品，更新价格与规格，移除已下架商品；先付款保留抢单规则，后付款仍受当前可用数量限制。刷新期间暂停交互，旧报价延时回调不进入确认。换场次、读取失败或清台状态不得继续使用旧购物车。已付款回调仍按原场次扣除本次选品，不因同场次目录刷新失效。

验证：点单入口、购物车、确认、作用域、实时目录、余额入口合计36项测试通过；三个修改文件静态检查无问题。覆盖通知合并、同场次刷新保留选品、后台不读、恢复后清台退出旧购物车。尚未安装新版iPhone，未用真实新订单完成APP与SUNMI双端现场验收；服务端当前通知主要针对订单所属会员，本次没有增加全桌广播。

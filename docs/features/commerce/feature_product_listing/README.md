# 本店商品上架

用户确认：店长在收银机或手机提交，超级管理员在手机审批，超级管理员也可直接上下架。本次复用统一商品、门店员工授权和采购超级接口 K261007002032；不创建另一套商品库。

设置 → 商品上架。顶部选择已授权门店；两个筛选是待审批和全部商品。待审批显示真实商品名称、规格、提交人及申请上架/下架；只有服务端返回 review 授权才显示退回/批准。全部商品显示生效开关，店长切换产生申请并保持原状态，超级管理员直接修改。商品已有待审申请时禁止继续改动。

listing_context 通过一个过程返回完整页面；set_listing/review_listing 同次返回更新页面，完成动作后不再拉取。接口沿用 ProcurementRepository 的会话及门店返回校验；会话改变后的迟到结果拒绝。未知结果先刷新，禁止自动重新发送；无权限或读取失败不显示伪造商品。

后端迁移 447 复用 active 和库存操作单据，验证本店 shift.manage 和配置中的超级管理员身份。客户端不提交角色标志。商品版本变化不能批准，退回后店长重新提交。前台流程测试覆盖普通店长不可批准、超级管理员可批准、一次动作直接更新页面。

实现范围仅上下架。套餐编辑、销售包装编辑及更多渠道独立配置仍按此前商品管理目标后续完成。本会话不覆盖聊天/登录或正在进行的手机安装任务；此页面随 APP 后续更新提供。

# 门店支付宝入口与旧版图标

用户要求：使用旧小程序 `images/ALIPAY.png`；当前门店未配置支付宝时隐藏入口，不显示可选择但不能付款的选项。

实现沿现有门店/支付编排，新增只读能力查询 K261002001959，返回当前门店标识与 `alipayAvailable` 布尔值。服务端验证已登录且已批准的会员、有效门店，再复用支付宝配置预检；全局关闭、门店未启用、配置或凭据缺失均返回 false，不向客户端下发商户设置或密钥。APP 查询期间及查询失败时默认隐藏。入口采用旧版原始小 PNG，尺寸与微信图标一致；隐藏时连同该行间距一起移除。

已有支付单恢复、幂等键与查单不受入口隐藏影响；渠道结果未知时不得改成微信重复付款。查询不创建订单、不占库存、不发起第三方扣款。范围是点单付款页面；平台钱包充值有独立账户配置，不用门店配置混用。

验证计划：未配置/配置有效/读取失败/切换门店或账号迟到响应/页面恢复重新查询；沿用微信、支付宝原订单恢复检查。支付相关页面已有其他会话的后付费修改，仅提交本节点新增变更。

验证结果：Flutter 支付入口、原请求恢复及桌台读取相关 46 项测试通过；新增文件及付款页面静态分析无问题。后端 `npm run verify` 通过（3134 项测试、TypeScript 检查、编译、migration dry-run 和部署静态检查）。未执行真实支付宝扣款。

本节点为代码与接口登记交付；服务端 migration 264 和手机新包尚未发布。与并行开发的后付费及整桌收款变更分别提交，发布时须先更新服务端接口，再安装包含本节点的 APP；旧服务暂不识别查询时客户端安全隐藏支付宝。

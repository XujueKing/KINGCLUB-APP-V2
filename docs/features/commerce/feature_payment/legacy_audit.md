# 支付旧版审计

- 文档状态：`Approved for Development`
- 审计基线：`KingClub-app / master / 505d222 / 1.1.37`

| 旧行为 | 风险 | V2 处理 |
|---|---|---|
| URL 传 `orderData` | 金额、身份、类型可陈旧/篡改 | 只传 PaymentIntentRef |
| mode 多分支 | 业务创建、支付与结果展示耦合 | 订单先创建，支付编排独立 |
| 客户端分摊资产 | 舍入、超额、竞态和重放 | 服务端权威计算 |
| SDK success 即成功页 | 回调可能丢失/伪造/服务端未确认 | 查询权威支付状态 |
| `mode=8` | 路由参数可伪造成功展示 | 删除该语义 |
| 超时重试 | 可能重复创建/扣款 | Attempt 引用与幂等恢复 |

旧接口和 mode 编号仅作迁移映射线索，不进入 Flutter 领域模型。

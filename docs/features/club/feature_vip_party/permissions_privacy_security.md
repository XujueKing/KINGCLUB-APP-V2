## 隐私规则

- 公开列表只显示局长批准的公开昵称/头像摘要，不显示手机号、账号、生日、性别或其他成员。
- 已确认成员页只显示参与所需的公开资料和状态，不显示支付金额、余额、手机号或实名。
- inviteOnly 组局必须同时校验邀请目标、状态、过期时间和当前会话，不因链接泄露开放访问。
- 离开组局、取消或会话切换后清理成员投影和邀请引用。

## 安全规则

- 创建、加入、邀请、撤销和招募开关均需幂等、版本校验、审计事件和稳定结果码。
- 客户端不得决定 host 身份、成员应付、退款、赔付、库存或资格。
- 举报、骚扰、争议和人身安全入口复用后续客服/申诉设计；不能用群聊或公开手机号替代。
- 日志与埋点不得包含完整成员名单、邀请 token、订单 payload 或支付凭据。

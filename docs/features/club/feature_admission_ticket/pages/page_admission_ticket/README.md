## 旧版视觉复刻与安全升级

- 保留旧版 `ticket` 的深红紫径向背景、顶部 `POSITIONING CARD`、圆角渐变票卡、居中桌位/场次、粉色二维码区和底部英文规则标题。
- 保留“已入场”斜置印章的视觉表达，但状态必须来自 Fake 权威投影，而不是路由传入对象。
- 删除旧版同桌性别席位阵列、永久成员编号和客户端票价；页面只展示本人的场次、区域、套餐摘要和状态。
- 静态 `memberId` 网页码替换为可轮换的本地 Fake 不透明 token 二维码，倒计时归零后换码；不连接真实签发或核验服务。
- 未开放、已入场、已离场、结束、撤销、离线和隐私遮盖状态仍使用同一票面框架，避免变成另一套新 UI。

## 用户任务与线框

查看本人权威入场状态，在允许时间内向工作人员出示动态二维码，或对受控离场上下文作明确确认。

```text
[返回]         POSITIONING CARD          [帮助]

[状态：可入场 / 已入场 / 已离场 / 已失效]
8月25日 20:30—次日04:00
VIP 区 V8 · 星光香槟套餐

        [动态二维码]
       00:24 后更新
  请向工作人员出示，请勿截图或分享

[规则摘要]
仅限本人 / 有效时间 / 入场与再次入场说明

状态变体：
- 未到时间：将在 20:15 开放
- 已入场：21:03 已入场，不显示二维码
- 场内离场码：确认登记离场？      [取消] [确认离场]
- 离线/暂停：无法生成凭证         [请工作人员协助]
```

- 二维码区域之外必须有文本状态，读屏不朗读 token。
- 页面进入前台可请求临时提高亮度，退出后恢复；原生行为在 UI 阶段单独评审。
- 不提供截图、保存、分享、复制和显示永久编号。
- 200% 字体下二维码保持可扫描尺寸，其他信息纵向滚动，操作不遮挡状态。

状态见 [states.md](states.md)，交互见 [interactions.md](interactions.md)，验收见 [acceptance.md](acceptance.md)。

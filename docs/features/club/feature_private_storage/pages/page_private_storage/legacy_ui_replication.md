## 视觉规则

- 标题位于安全区下方居中，白色约 `16sp`、中等字重。
- 信息图标复用旧版 `/images/fail.png`，不得用文字或手绘图形替代。
- 分类栏距九宫格顶部约 `8dp`；选中项为白色并带香槟金下划线，未选中项约 40% 白色。
- 九宫格宽度约页面的 84%，三列等宽；单格接近正方形。
- 格子边框为低透明度香槟金，内部使用旧版深棕径向层次；格间留约 `4dp` 黑色间隔。
- 首屏使用截图中的空格状态，不擅自增加酒瓶、商品图、数量或文案。
- 指示点固定两枚；当前页为香槟金，其他页为低透明度白色。
- 底部继续复用已批准的旧版五 Tab 胶囊，不在页面内部重复实现。

## Fake 交互

- 点击 `酒 / 物`：切换当前分类并回到第 1 页，九宫格仍为截图基准空状态。
- 左右滑动九宫格：在两页空储物格之间切换并同步指示点。
- 点击中央信息图标：弹出离线 Fake 说明 `当前没有可展示的存酒或物品`。
- 空格不可进入取件码页；待后续用户提供有内容状态参考后再补储物对象视觉。
- 不展示内部库位、员工姓名、永久 storedId 或用户账号。

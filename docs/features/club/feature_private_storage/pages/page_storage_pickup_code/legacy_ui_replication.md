# KC-P-048 旧版 UI 复刻规格

状态：Approved for Development（仅 UI / Fake）

## 复刻基线

- 旧版页面：`pages/savecode/savecode`。
- 保留黑色径向背景、顶部返回、`ITEM PICKUP CODE`、中央二维码、品名/英文名/数量/剩余量/日期信息以及底部储存说明。
- 从旧版消费者界面移除永久 `storedId`、内部库房位置、保存人员和静态网页二维码。

## V2 展示内容

- 顶部中文标题“取件凭证”，同时保留旧版英文标题。
- 展示公开品名、规格、数量、剩余量、存入日期、到期日期和可取状态。
- 二维码采用 30 秒本地 Fake 轮换，显示倒计时；视觉码不包含 URL、账号或永久储物编号。
- 明确提示“仅向工作人员出示，请勿截图分享”。

## UI/Fake 状态

- 正常轮换、即将过期、已过期、部分交付、已取出、暂停取件、离线、后台隐私遮盖。
- 默认演示“可取”状态；后台立即遮盖，回前台重新签发 Fake 视觉码。
- 消费者只能展示凭证，不能自行核销或宣布取件成功。

## 入口

- 私人储物柜保持旧版空柜默认画面。
- 点击中央信息图标后，可从说明弹层进入“查看取件凭证演示”，不改变默认空柜复刻画面。

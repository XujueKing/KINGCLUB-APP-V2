# 储物柜、翻转与媒体缓存

用户依据旧小程序截图要求还原，进一步授权程序、真实接口、数据库整理，以及翻转和流动动画。

- 柜子使用三列九宫格、原酒瓶/券/翻转/二维码PNG、原瓶形SVG；素材在assets/legacy/storage随包提供，不请求旧站。酒/物分页、选中、数量、剩余、有效期均取真实接口。
- 瓶/卡440ms纵轴翻转，过半切面，不镜像文字。背面酒液按服务端剩余百分比裁切，以正弦波和移动高光连续流动，0%/100%不越界；离页、后台、减少动画模式暂停。
- 小屏保留滚动，顶部和底栏使用真实安全区。已确认底栏90%茶色磨砂、无白边、未读气泡规格不改变。
- 真实提取码30秒轮换；实时重读余额，不显示永久旧码/内部仓位/员工资料。后台隐藏、失效或不可取不显示QR。
- 所有当前远程图片入口改用统一缓存；私有图片以会员隔离，签名变化使用不可变文件版本键复用，退出清私有缓存。固定封面视频继续本地播放。
- MediaCache存手机系统缓存目录，图片预算200MiB、视频800MiB，单文件20/200MiB，LRU淘汰；HTTPS、并发去重、临时文件完整后改名。图片/视频再次访问优先读磁盘，系统空间紧张也可能清理缓存。版本键必须随内容变化，不存签名URL。
- CachedMediaVideo为MP4文件缓存播放器，当前内容流仍为原有Mock，没有真实远程视频数据，不能宣称整条视频业务已接通；后续远程播放器统一使用此组件，不另建网络入口。不自动预下载未打开视频，也不支持HLS分片。
- 设置页显示真实缓存大小并实际清理；私有媒体不跨账号复用。提取码不写入媒体缓存。

验证：Flutter analyze；缓存命中/去重/签名变化/私有隔离/淘汰/清理、柜子切换/翻转/三屏幕布局、真实QR轮换与后台失效、底栏和已冻结会话流程回归。截图见build/storage-qa，使用独立测试fixtures；不作为真实会员库存。

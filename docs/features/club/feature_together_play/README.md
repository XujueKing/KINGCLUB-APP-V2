## 页面与行为

- 列表：当前城市（市级）与可横滑日期条，下方按所选城市、活动日期显示组局卡片；不使用旧代码固定 08.26 日期。空日期明确空态，不用其他城市活动补位。
- 卡片：沿旧 Choose.wxss 的 690/750 内容宽、20rpx 圆角、紫粉背景和金色日期选中态。旧 888 改为主题。显示发起人类型、活动时间、地点、费用规则、报名人数/总人数。已报名参与者显示圆头像，空位低亮显示；空位不是可选座。
- 状态：未报名显示“抢定”，报名成功显示二维码图标；待支付显示“继续支付”，满员/截止/取消禁止抢定。打开整卡进入同一活动详情，不直接扣款。免费者也必须确认报名，不能从金额为零推导已报名。
- 详情：海报、主题、发起者、城市/地点、完整日期时间（含跨日结束时间）、参与者、费用说明、包含内容、成局/退款规则，底部报名或已报名凭证入口。
- 发起：会员或已授权商家；主题、日期时间、城市地点、人数、费用方式、背景/海报。服务端重新验证商家权限与所属桌台，不接受客户端自报商家身份。
- 素材：服务端提供可用样例背景和海报；自传先上传审核，pending/rejected 不得用于公开发布。服务器重新验证素材归属及审核状态，不能以客户端布尔标记绕过。

## 费用与人数

费用方式：AA、男 A 女免、发起者请客全免。收费金额按整数分；资格、应付金额和订单最终状态由服务端确定。用户已确认发起时固定人均价，发起人先从余额冻结整场全部费用。参加者成功付款直接给商家/收款方，同时解冻发起人等额押金。免费报名实付为零，不按人数虚构解冻金额。付款结果未知不解冻，回调重放不得重复解冻。

用户已确认：开始前至少48小时才能普通取消。发起人取消按整场总费用扣20%，赔给商家；发起人必须有APP平台余额，不能用单店余额。商家取消须全额退还参加者实付，并额外补偿该实付的10%。踢人由提出方承担被踢者原付款退款、该实付100%的额外补偿和该实付20%的商家补偿。免费参加者无补偿。比例金额按分四舍五入，每一收款方单独计算。

核对现有服务：平台现金账户是 kingclubProfileAssets.cashBalance，现有 platform-cash-debit 使用行锁和幂等付款记录。现有桌台 partySize 不具有招募/押金能力。新冻结应与现金可用额及既有余额支付共用账户锁，不能仅加展示冻结数字而让既有付款仍可花掉押金。此阶段未修改、部署账本或执行真实资金操作。

总人数由发起时决定，绑定卡座/桌台时不得超过其容量。已报名数只能来自有效席位，待支付与已取消不能点亮成已报名；并发最后一个名额、重复提交、支付回调重放由服务端原子约束。已有桌台 partySize 是到店人数登记，不是同城招募活动，不能直接复用成活动服务。

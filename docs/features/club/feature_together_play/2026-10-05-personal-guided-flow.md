# 个人开局分步引导

2026-10-05 用户要求：个人入口仍是首页“组局玩”；标题与聊天统一，个人开局采用多个页面逐步完成。一起玩仅浏览活动，右上角选择城市，不出现发起入口。

## 页面与交互

1. 门店与方案：选择城市，进入独立商家列表选择门店，选择通用 AA／男A女免／我请客方案或自定义，输入活动主题与欢迎语。
2. 卡座与套餐：选择开始和结束时间、可用卡座、人数及该商家提供的套餐，显示套餐价格。
3. 参加规则：选择男女颜值、年龄、收费方式和男女分摊、金币使用。
4. 活动介绍：补介绍、已审核背景及最多三张海报，进入已有服务器报价和押金确认页。

每步都有进度及下一步，后续页面可上一步；返回保留输入。切换城市清除门店、卡座和套餐，切换门店清除原店卡座和套餐。选择取消不修改原选择。首步必填及时间、收费输入先在当前步骤校验，最终仍执行完整草稿和服务器校验。个人不允许切换官方身份。

方案目前是 APP 通用收费预设，不冒充商家配置的活动模板。套餐仍从所选门店接口读取。欢迎语与介绍按顺序写入现有 description，以空行分隔，避免界面填写后未保存；尚无单独 welcome 字段。邀请制、自占名额等缺失契约不增加无效开关。

商家选择采用整页扁长卡片：形象背景、圆角 Logo、店名、地址与真实评分。缺图显示店铺占位，缺评分显示“暂无评分”，不生成假评分。仅显示当前城市且 personalPartyEnabled 明确为 true 的商家。

# 预订与发布页面设计

## 共同视觉

沿用当前APP：背景 `#111111`，卡片 `#202020`，主要文字白色，次要文字 `#A6A6A6`，香槟金 `#CEBEA4` 用于主要操作和选中提示。内页使用聊天会话的17dp居中标题、统一返回箭头，标题栏背景透明。表单灰色填充无描边；按钮52dp、胶囊圆角；列表行至少52dp，选择器按既有城市和日期页实现。

主要内容左右16dp、卡片内20dp、卡片间16dp。价格采用所属门店币种与千分符，报价原始精度由服务端提供。键盘出现时隐藏底部支付操作，金额输入不能把支付按钮推到键盘上方；点击空白可收键盘。保存草稿与离开提醒用于编辑页，普通返回手势保持统一。

## 商家页面

商家平台店铺卡下增加三个主要入口：预订产品、发布AA邀请、卡座合作任务。已有采购、费率、任务入口保留，预约管理进入统一排位页。

产品编辑分四步：位置类型及绑定桌台 → 图片与介绍 → 可售日期/时段、预订方式和最低消费 → 预览及上架。顾客看到价格前先能看懂“现在付多少、到店还需满足什么”。未指定可用桌台或容量的产品不能上架。

官方活动发布分五步：场地和时间 → AA/男A女免/全免费及套餐 → 容量池与参加条件 → 海报和说明 → 预览发布。身份与门店锁定，不出现可自称官方的开关。具体桌号不在顾客购买前披露，但商家必须选择实际资源范围。

卡座任务列表显示月份、编号、容量、资金门槛与收取方、收益规则和状态。合同编辑依次选自然月和位置、门槛/收款方、分成与完成条件、条款预览、发布。已有顾客预约造成冲突时列出占用时间；不提供“一键清空预约”操作。

## 合作者页面

合作者平台增加“发布AA邀请”和“我的签约卡座”，保留任务大厅、我的派对和收益入口。发布入口先选择有效合同；没有合同进入任务大厅寻找合作，不允许随意选择商家/桌号。

合同详情先显示门店及编号、月份、容量，再显示资金要求、收益规则和任务目标，最后是条款及领取操作。未付款、结果未知、审核中、暂停或到期都不能发布。签约后的入口直接进入编号桌台，不让合作者修改合同归属。

合作者发布分五步，第一步编号桌台固定；套餐、人数、时间和规则限定在合同授权内。10人V2显示“已报名4/10人”，而非“已就坐4人”。详情将报名、到店核销分别列出。客户身份和头像仅在已授权展示范围内返回。

## 成功及通知

成功页复用统一 `success1/2/3` 与注册过程的52dp返回按钮，不重新制作紫色成功图。预订成功返回预约详情；合同生效返回签约卡座详情；发布成功进入活动详情。进入摄像头后完成业务返回摄像头之前的页面。

系统消息复用已有消息卡：标题、店铺、事项、时间、金额与币种，点击进入订单/预约/合同详情。合同与任务提示同时联动合作者消息红点、我的红点和前台横幅，不用商家后台的成功提示替代顾客消息。

## 设计验收

在320、390、430dp和放大文字下检查标签、价格、日期、手机号和按钮不溢出；颜色之外用下划线/文字说明区分选中和状态。点击区域至少44dp。空列表说明当前城市/日期无产品，并允许改变筛选，不自动换城。输入不遮挡规则与下一字段，支付前能看见完整门店、日期、位置和金额。可点击预览用于评审布局，不验证真实库存、退款或到账。

合同资金页面：条款后分别展示保证金/承包资金，金额、状态、原渠道和收退凭证；双方操作按服务器可操作状态呈现。有效订台与现金净消费进度用“当前 / 目标”，明确两项目标满足方式。待资金仅显示付款/核对/凭证操作，生效才显示发布；完成条件核对后各自申请退回。离线凭证表单固定本笔金额，退款渠道不可改；填写凭证、确认实际款项，保持灰色无描边和52dp按钮，空白收键盘，付款栏不移到键盘上方。服务端状态未知使用核对中的说明，不显示成功页。
# 商家多桌活动与分座补充（2026-10-08）

商家发布向导的预留位置使用同店多选，最多30桌。每桌一份基础套餐，显示单桌价格、桌数和整场合计；最终金额与容量由数据库重新报价。合作者仍只使用本人整月合同的固定编号。购买前商家位置池编号不公开。

商家平台增加“活动分座”：先选活动，再显示位置容量、已安排人数和实际付款的顾客。选择顾客与位置后统一确认。未付款不能安排，已核销不能调桌；退款顾客释放该桌人数，保留历史安排记录。一个确认动作返回整个活动分座结果，避免重新拼接请求。手机界面保持当前深色卡片、白色标准标题和52dp按钮。

公共活动仅返回当前会员购买后被分配的位置，不公开其他顾客名单或位置池。多桌活动必须先分座再核销入场。此补充不代表套餐实际出酒、顾客定金或最终消费抵扣已经接通。

## 定金原单状态页（收款仍关闭）

我的预约中已付定金的记录进入独立原单状态页，一次K261008002055读取门店、位置、时段、原定金、预约和退款。沿用白色标准标题、暗色卡片、52dp按钮。付款核对中不能显示预约成功；位置未取得明确说明会原渠道退回。取消确认说明释放位置和异步退款，保留与确认按钮同尺寸，间隔12dp。原渠道退款处理中/待核对/已退回分别显示，仅服务器确认已退回才呈现到账结果。

页面在前台每10秒核对未决原单，离开应用停止；恢复前台核对一次。查询/取消期间防重复请求，后返回的旧读取不能盖过新取消结果；错误保留已确认资料及原单引用，允许核对重试。确认、到店、已关或已退终态不轮询。此页只处理已有原单，不开放新定金收款。
# 2026-10-09 AA 邀请逐页评审补充

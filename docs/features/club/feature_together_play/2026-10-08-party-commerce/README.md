# 商家预订和合作者组局

首页面向顾客发现活动与预订位置，发布能力转到商家平台和合作者平台。商家能发布散台、卡座、包厢预订产品，也能发布报名后分座的活动；合作者通过整月独占合同取得编号桌台的发布权，顾客报名时能看见具体位置及人数。

本设计采用2026年10月8日确认的经营规则，覆盖此前普通会员从首页创建派对、从收藏店铺预订时创建个人派对的设计。历史派对、报名、付款、入场券和收益保留。

## 已确认

| 事项 | 规则 |
| --- | --- |
| 首页入口 | 加入派对改AA邀请；创建派对改吃喝玩乐；普通会员不发布 |
| 发布入口 | 商家平台、合作者平台；普通合作者不能创建平台任务 |
| 预订产品 | 散台、卡座、包厢；图片、介绍；免费或定金预订；最低消费可有可无 |
| 顾客定金 | 抵扣最终消费；提前或不足4小时取消均退定金、释放位置 |
| 商家活动 | AA、男A女免、全免费；报名买单后分座，购买前不披露具体桌号 |
| 合作者活动 | 必须绑定合同中的编号卡座或包厢；显示已报名人数与总容量 |
| 月签约 | 对签约桌台整月独占；可无资金门槛、保证金或承包金额 |
| 签约收款 | 商户或平台收取；保证金和承包金额均按合同量化条件退回 |
| 合同分成 | 已有规则为默认，可调整；发布与成交时快照，不改写已入账收益 |
| 已有佣金 | 有效消费仅微信、平台现金；券、金币、储值本金和赠送不计；核销后入账，7天结算 |
| 关联顾客 | 2%从该顾客对应的带局者收益中拆出，不额外增加平台支出 |

## 本批工作次序

先完成现状核对、经营规则和页面设计，再实现会员发现、商家发布与预订产品管理、月签约和合作者发布，最后闭合预订付款、取消退款、收银抵扣、核销、通知和收益。每个批次记录真实完成状态；不会把设计预览、空页面或安装成功当成交易闭环。

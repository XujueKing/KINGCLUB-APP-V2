# 一起玩随机分配与卡座揭晓 UI 验收

- 验收日期：2026-08-31
- 设备：Android Medium Phone 模拟器（1080 × 2400）
- 结论：通过

## 验收范围

1. 预订前只展示“随机卡座”，不展示具体卡座号。
2. 确认订单只说明系统随机分配，以及营业日前一天揭晓。
3. 预订成功但尚未到揭晓时间时，展示“卡座待揭晓”，不展示卡座号或入场二维码。
4. 到达服务端给出的揭晓状态后，才允许展示定位卡与入场凭证。
5. 待揭晓状态沿用黑金主题，不使用粉色。

## 视觉证据

- `01-pending-reveal.png`：预订已确认、卡座待揭晓状态。
- `02-package-no-seat.png`：套餐详情不含具体卡座号。
- `03-confirm-random-assignment.png`：订单确认页展示随机分配与揭晓时间。

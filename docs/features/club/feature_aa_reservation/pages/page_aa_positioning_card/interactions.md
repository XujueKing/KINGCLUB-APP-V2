# AA 已选座定位凭证页交互

| 触发 | 行为 |
|---|---|
| 点 AA 列表紫色定位卡 | 进入本页并读取对应 `AdmissionRef` 的投影 |
| 点左上角返回 | 有上一页时回到原 AA 日期和滚动位置；无路由栈时兜底进入 `/club/aa` |
| Android 系统返回 | 执行与左上角返回相同的逻辑 |
| 二维码轮换 | 仅前台且 `ready` 时定时签发新的本地 Fake token |
| App 进入后台/切换任务 | 立即遮盖二维码 |
| App 回到前台 | 重新签发 token，旧码不复用 |

- 整张紫色定位卡为点击热区，不另加“查看凭证”按钮。
- 凭证页被直接打开或作为恢复页时，返回操作不得因没有可 `pop` 的页面而失效。
- 不支持截图分享、保存二维码或消费者自行确认入场。

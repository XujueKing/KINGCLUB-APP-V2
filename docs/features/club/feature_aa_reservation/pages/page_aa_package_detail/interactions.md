# AA 卡座套餐详情页交互

| 触发 | 行为 |
|---|---|
| 页面进入 | 用 AaOfferRef 重读权威详情，不信列表卡片快照 |
| 点规则 | 展开/弹出当前 `termsSnapshotRef` 的只读摘要 |
| 点继续 | 创建 AaQuote；成功后 `openAaOrderConfirmation(AaQuoteRef)` |
| 报价创建售罄 | 保留详情并展示售罄，提供返回列表刷新 |
| 报价创建价格变化 | 更新详情，要求用户再次点击继续 |
| 返回 | 回列表并保留日期/滚动位置 |
| 长按标题（仅本地验收） | 切换正常、价格更新或刷新后售罄；不显示常驻调试入口 |
| 价格更新后点继续 | 第一次确认新价格，第二次才创建本地 Fake quote 并进入确认页 |

- 继续操作使用 SingleFlight 和稳定幂等键；失败重试不得创建多个 quote/草稿。
- 页面停留过久或恢复前台时先刷新详情；刷新完成前禁用继续。
- 活动标签必须附可展开规则，不用只展示“优惠”而隐藏条件。
- 埋点记录详情加载、规则展开和继续结果类别，不记录价格策略内部条件。
- 价格更新提示必须同时包含旧价、新价和重新确认要求；售罄状态不得保留可提交按钮。

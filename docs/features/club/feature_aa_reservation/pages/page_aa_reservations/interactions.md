# 一起玩 AA 预订页交互

| 触发 | 行为 |
|---|---|
| 选择日期 | 更新选中项并加载该 `serviceDate` 投影 |
| 点套餐 | `openAaPackageDetail(AaOfferRef)` |
| 点系统推荐 | 请求/读取推荐 offer 后仍进入套餐详情 |
| 点待支付继续 | `openPayment(paymentIntentRef)`；下游未批准时走 AA-M16 |
| 选择已确认但未揭晓的日期 | 顶部显示黑金待揭晓卡和揭晓时机，同日套餐入口禁用 |
| 选择已进入揭晓窗口的日期 | 顶部显示旧版紫色定位卡，同日套餐入口禁用 |
| 点紫色定位卡任意区域 | `openAaPositioningCard(admissionRef)`；进入完整二维码定位凭证页 |
| 下拉刷新 | 重读日期、已有预订和套餐，保留合法选中日期 |
| 左上角或 Android 系统返回 | 有来源路由时回到来源页；页面被直接打开或作为预览启动页、没有上一页时，兜底进入 KingClub 首页；不创建订单或占位 |
| 长按标题（仅本地验收） | 打开无常驻入口的 Fake 状态面板；可切换正常、待支付、已确认待揭晓、已揭晓、售罄、离线快照、无可推荐套餐 |
| 离线状态点刷新 | 恢复默认可订 Fake 投影，不调用网络 |

- 快速连点套餐只允许一次导航。
- 返回操作不得因 `/club/aa` 是启动路由、路由栈为空而无响应。
- 列表刷新时不以客户端倒计时或本地余量判断可订状态。
- 维护/离线只保留查询和既有订单安全出口，不允许提交。
- Fake 状态面板不得出现在生产交互中，也不得改变旧版标题栏视觉。
- 埋点仅记录 `serviceDateBucket`、offer 匿名引用、入口和结果类别，不记录成员/订单明细。

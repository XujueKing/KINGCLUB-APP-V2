# 资产与流水语义

## 资产类型

| 类型 | 单位 | 展示 |
|---|---|---|
| `cashBalance` | 人民币分（整数） | 格式化为 ¥，不使用浮点计算 |
| `goldCoin` | 枚（整数） | 不换算人民币 |
| `diamond` | 枚（整数） | 不与金币互换 |

## 余额分层

- `available`：当前可用于服务端允许用途的数量。
- `frozen`：已占用、不可再次使用。
- `pending`：结果尚未最终入账。
- `asOf`：摘要的服务端时间点。

## 流水状态

- `pending`：处理中，不能当作最终余额变化。
- `posted`：已入账。
- `reversed`：原交易被冲正，原记录保留并关联冲正记录。

流水方向 `credit/debit/neutral` 与正负号同时由服务端给出并校验；客户端只格式化，不重算余额。未知资产或状态只读显示“状态更新中”并允许刷新。

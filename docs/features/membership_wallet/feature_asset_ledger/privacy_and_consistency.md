# 钱包隐私与一致性

- 页面恢复前台时重读摘要；缓存必须标记 `asOf`，离线只读且不声称最新。
- 下拉刷新原子替换摘要和首屏流水，不能先改余额再迟到覆盖列表。
- 推送/事件只提示刷新，不携带或直接修改金额。
- 退出账号、会话撤销或切换账户时清除全部资产缓存和 cursor。
- App 进入后台/任务切换界面时用隐私遮盖；截图能力的系统限制在 UI 阶段单独评审。
- 埋点不得包含余额数值、流水金额、entryRef、OrderRef、订单号、支付方式或备注全文。
- 非本人/不存在的引用使用同一安全错误，避免对象枚举。
- 金额、金币和钻石绝不通过不同 App 的统一身份自动共享。

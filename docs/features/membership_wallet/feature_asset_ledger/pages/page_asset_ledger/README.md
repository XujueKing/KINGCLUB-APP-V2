## 用户任务与线框

按旧版四个账单分类查看订单、余额、金币和钻石流水。

```text
[返回]             账单记录
[订单] [余额] [金币] [钻石]
[2026年度]                 [支出 / 收入]
本月收入/支出（服务端摘要）
订单消费                         -¥68.00
8月25日 20:31 · 已入账             [订单]
退款处理中                       +¥20.00
8月24日 18:10 · 处理中
```

- 不显示跨资产“总资产”，不同单位不使用同一金额格式。
- 正负号必须同时配合“收入/支出/处理中/冲正”文本，不只依赖颜色。
- 页面没有充值、提现、兑换和转赠按钮。

状态见 [states.md](states.md)，交互见 [interactions.md](interactions.md)，验收见 [acceptance.md](acceptance.md)。

## 旧版视觉复刻基线

- 视觉来源固定为旧版 `pages/mybalance/mybalance.wxml` 与 `mybalance.wxss`。

- 流水行保留圆形业务图标、左侧标题/时间、右侧大号变动数量；入账增加量使用旧版金色强调。
- 2026-08-28 用户要求恢复完全复刻：保留旧版 `订单 / 余额 / 金币 / 钻石` 四个等分页签。

- 普通订单流水仍留在当前页；只有带 Fake `OrderRef` 的记录可进入现有订单详情，不新增生产连接。
- 旧版通过滚动到底自动翻页，默认态不得显示醒目的“加载更多”按钮。
- 旧版微信胶囊和小程序页面 chrome 不属于 App UI，不复刻。

## Fake UI 实现范围

- 长按页面标题打开本地专项场景选择器，覆盖 ASSET-M01～M20。
- 支持资产切换、年度切换、下拉刷新、稳定加载更多、普通流水展开和关联订单安全跳转。
- 离线缓存必须显示 `asOf`；未知类型/状态使用通用只读样式；会话失效清空资产内容并触发登录 reset。
- 页面内所有余额、数量、流水和引用均为固定 Fake 数据，不调用超级接口、WebSocket、支付或生产存储。

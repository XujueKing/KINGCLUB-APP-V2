# 钱包与资产流水旧版 UI 复刻规范

- 旧版来源：`KingClub-app/pages/mybalance`
- 稳定基线：`master / 505d222 / 1.1.37`
- 设计状态：`Approved for Development`
- 复刻版本：`Legacy Asset Ledger Replica v2 / Read-only Fake Flow`

## 视觉结构

1. 页面背景固定为旧版 `#0e090c`，不增加通用白色 AppBar。
2. 顶部使用返回按钮、居中“账单记录”标题和等宽右侧占位。
3. 标题下直接进入旧版 `订单 / 余额 / 金币 / 钻石` 四个横向等分页签，不插入摘要卡。
4. 选中项字号增大并显示 `#ffb400` 下划线；默认入口按来源选中余额、金币或钻石，页内仍可切换订单。
5. 年度筛选位于左侧，当前资产年度收支摘要位于右侧。
6. 流水使用旧版全宽暗色行、圆形图标、两级文字和右对齐数量；行间只用低透明分隔线。
7. 滚动到底自动加载下一页；默认态不显示“加载更多”按钮，也不显示充值、提现、兑换、红包、转赠或资产抵扣入口。

## 资产与状态表现

- 余额使用 `¥` 和两位小数；金币、钻石使用整数与“枚”。
- 正负号和“收入/支出/处理中/已冲正”文本同时出现，颜色不能是唯一状态信息。
- `pending` 使用低饱和金色状态；`reversed` 保留原记录并显示冲正关联说明。
- `offlineCached` 在摘要区显示缓存时间和只读标记，不把缓存伪装成最新数据。
- 未启用资产从 tab 和摘要中隐藏；未知类型或状态显示“状态更新中”。

## 交互边界

- 左右滑动或点击 tab 只切换本地 Fake 资产，不混用 cursor。
- 年度切换重置当前列表；刷新时摘要和首屏一起替换。
- 普通流水在当前页展开；只有带 Fake `OrderRef` 的条目可以进入订单详情。
- 页面不允许复制余额、金额、流水引用或订单引用。
- 会话失效时先清空可见资产和 cursor，再触发全局登录 reset。

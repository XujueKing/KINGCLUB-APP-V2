# Design QA — 钱包与资产流水页

- source truth：旧版 `pages/mybalance`、用户已确认的账单截图和页面文档
- implementation evidence：`audit/2026-08-29-formal-copy-v3/`
- viewport：Xiaomi 14 Pro，1080 × 2400
- state：余额页、订单退款展开、关联订单

## 结果

- 顶部“账单记录”、四等分页签、年度汇总、金色选中线和紧凑流水间距保持旧版基线。
- P1：展开退款流水后显示“Fake 服务端”，破坏正式用户界面。
- 修复：展开摘要改为正式入账文案；处理中文案仅说明状态仍在确认，不提前承诺。
- P1：星光香槟套餐流水错误关联 V8 待支付订单。
- 修复：不透明 `OrderRef` 改为对应 V2 AA 已完成订单，跳转后商品名称和业务状态一致。
- 余额、金币、钻石仍使用独立单位，无跨资产换算、充值、提现或转赠动作。
- 金币页的 `+50 枚 / -30 枚`与钻石页的整数枚数保持独立单位，汇总区不出现人民币符号。
- 金币抵扣流水的关联对象修正为 888 号桌已支付订单，与 `-30 枚` 抵扣语义相符。

## 限制

- 页面仍是本地 UI/Fake 数据；真实资产、订单、退款和超级接口继续受项目级门禁阻断。
- 生产前还需要复测 200% 系统字体和完整屏幕阅读器顺序。

final result: passed for formal user copy and linked-order continuity in UI/Fake scope

# 常规控件尺寸调整
用户反馈封面、首页和流程页 input/button 过矮，要求更舒展。

常规单行输入和主按钮统一52dp：欢迎NEXT、手机登录输入及按钮、实名认证输入、注册偏好与图片提交、创建派对下一步、支付/扣款结果返回，以及公共实心/描边按钮。欢迎按钮宽度从80%调为84%；确认订单支付按钮从112调128宽。主题普通输入上下内边距16dp，首页快捷卡高度比例140/680调160/680；保留返回、扫码工具按钮及紧凑操作语义。

验证覆盖小屏、200%字体、注册键盘及扫码支付布局；首页旧视觉基线更新为当前内容及加高后布局。只改展示尺寸，不改交易和导航行为。

用户实机复核后要求高度从56dp微调为52dp；保留已调整的宽度和字号，普通输入内边距同步回到16dp。

全 APP 固定高度复查：补齐设置退出、资料保存、封面调整、支付 PIN/注销账号、注册审核、好友申请、聊天数量确认、资产操作、订单付款/详情及派对流程主按钮，统一引用 kingControlHeight。保留标题栏、列表行、图标、缩略图及紧凑工具的尺寸。验证码整行圆角同步为高度一半。设置/支付安全/注销/订单详情/开台/设置路由共41项测试通过，15个修改文件静态分析通过。

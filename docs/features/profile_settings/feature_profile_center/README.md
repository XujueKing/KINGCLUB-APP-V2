## 目标与用户价值

让已登录且会员准入通过的普通会员查看自己的 KingClub 展示资料，进入订单、资产、私人储物柜和设置等个人任务，安全编辑批准字段，并通过受控短期二维码发起好友连接。

## 已确认事实

- 旧版“我的”内嵌在 `pages/index/index`，同时展示背景图、昵称、永久账号、等级、余额、金币/钻石、获赞/关注/互关/粉丝、颜值、个人字段、作品/动态/相册和管理入口。
- 旧 `myinfo` 的字段和是否可编辑由服务端 `menuMyList` 动态决定，并用数字 `indexNum` 写入；支付密码入口也混在资料编辑页。
- 旧头像先拼接含 `userAccount` 的上传 URL，再用共享 Authorization 上传并提交旧接口。
- 旧 `mycode` 将永久 `userAccount` 直接放进可长期传播的 URL 二维码，同时复用页面展示群二维码。
- App Shell v1 已确认“我的”分支归属资料、订单、钱包、私人储物柜和设置；代理、员工、财务、账号绑定和群二维码不进入本期。
- Member Onboarding v1 已确认不展示颜值分/内部标签，偏好使用稳定 optionId，并允许以后在个人资料中修改。

## 用户已确认方案

### 我的主页固定结构

1. 资料卡：头像、昵称、会员已认证标识和个人简介。
2. 资料动作：编辑资料、个人二维码。
3. 个人服务：订单中心、钱包与资产流水、私人储物柜、设置。
4. 可选提示：资料完善度和稳定提醒类别；不读取服务端动态菜单。

### 编辑字段

- 可编辑：头像、昵称、个人简介、常驻城市/区域、职业、身高，以及四类兴趣偏好。
- 只读：统一 `userAccount`、实名/成年结论、会员状态和服务端审核状态。
- 本期不编辑：真实姓名、证件、手机号、出生日期、性别、余额、等级、支付密码或背景封面。

### 个人二维码

- 使用服务端签发、短期（建议 10 分钟）、可撤销的 `friendInviteToken`，不编码永久 `userAccount` 或任意 URL。
- 扫描后只进入好友预览/申请流程，不自动建立好友关系。
- M0 不提供保存到相册、系统分享或永久码；过期后在前台安全刷新。

# 旧版个人中心审计与 V2 取舍

- 文档状态：`In Review`
- 审计基线：`KingClub-app / master / 505d222 / 1.1.37`

## 已确认事实

| 旧版能力 | 旧行为 | V2 去向 |
|---|---|---|
| 我的主页 | 与 index 的其他四个逻辑页共用超大状态对象 | 独立 KC-P-040，作为 me 分支根 |
| 账号 | 显示并一键复制永久 `userAccount` | 本期不展示；身份只来自 Session |
| 资料标签 | 年龄、颜值、IP、区域、身高体重、生肖、职业、婚姻、学校、收入等混排 | 固定、最小、用户可控的展示资料；删除颜值和内部/高风险标签 |
| 关系与内容 | 获赞/关注/互关/粉丝、作品/动态/相册内嵌 | 本期从我的主页移出，避免无目标页面的死入口 |
| 资产 | 余额、金币、钻石直接展示并跳旧余额页 | 只提供 KC-P-039 资产入口，权威明细在独立页 |
| 动态菜单 | 管理、设置等通过字符串 URL 直接 `navigateTo` | 客户端固定类型化 RouteIntent allowlist |
| 资料读取 | `S231202504070679` 返回动态 `menuMyList` | 固定字段 schema + profileVersion |
| 资料更新 | `S231202504070680(indexNum, modiffyVlue)` | 字段化 patch、校验、乐观并发和幂等 |
| 头像 | 含账号的 URL 拼接上传，再提交 `imageUrl` | upload intent/commit；不把账号放对象名/日志 |
| 二维码 | 永久账号 URL、群二维码共用页面 | 短期好友邀请 token；群二维码移出本期 |

## 已确认风险

- 服务端动态字段和数字索引无法提供稳定类型、校验、可访问性或版本控制。
- 永久账号二维码可被无限复制，无法按邀请撤销、过期或限定用途。
- 页面和上传链信任本地 `preUserInfo.userAccount`，并在日志、URI 与对象路径暴露身份。
- 旧主页展示“颜值”和大量推断/高敏感标签，与已批准的审核公平性方案冲突。
- 支付安全、经营管理和公开资料编辑混在一起，权限边界不清。

## 当前建议的保留原则

- 保留夜生活品牌资料卡、昵称/头像/简介和个人服务入口。
- 只保留能在本期 48 页落地的入口；未纳入页面的统计与内容不做假入口。
- 展示资料、统一身份、会员审核、资产和安全设置分别由各自领域拥有。
- 所有跨域跳转使用批准的类型化 RouteIntent，不接字符串 URL。

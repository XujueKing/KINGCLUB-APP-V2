# 个人资料隐私与安全

- 文档状态：`Approved for Development`

## 数据边界

- 统一 `userAccount`、实名、手机号、出生日期、KYC 引用和会员审核内部状态不进入可编辑 ViewModel。
- 我的主页展示的是 App 内资料投影，不作为登录身份、会员权限或对象授权依据。
- 公开给其他会员的字段范围由未来用户主页/关系权限文档决定；本功能批准不自动意味着所有编辑字段公开。
- 不展示颜值分、模型标签、精确 IP、收入、婚姻、学校或未经用户明确设置的推断属性。

## 媒体

- UI Mock 只使用合成头像，不读取真实相册/相机。
- 真实阶段需先说明用途，再由用户点击头像触发权限；临时文件在取消、完成、会话失效或页面销毁后清理。
- 文件名、路径、对象 key、日志和埋点不得包含 `userAccount`、手机号或昵称。
- 头像需做 MIME/大小/像素/方向和内容安全检查；不提供美颜或身体/外貌重塑。

## 二维码

- payload、tokenRef 和二维码图像不写 URI、普通缓存、剪贴板、日志、埋点、崩溃附件或持久化截图基线。
- token 只用于好友预览/申请，过期、撤销、错 App、会话失效时失败关闭。
- M0 不提供“保存相册”和系统分享，降低永久传播与隐私误解；以后增加必须单独评审有效期和撤销体验。
- 切后台隐藏二维码内容；回前台复核 session 与过期时间后再显示或刷新。

## 埋点

- 允许记录页面/动作类别、字段名枚举、结果类别、耗时桶和冲突类型。
- 禁止记录字段值、昵称文本、简介、城市/职业、身高、偏好值、媒体路径、二维码 payload 或 token。

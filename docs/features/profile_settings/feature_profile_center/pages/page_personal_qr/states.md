# 个人二维码页状态

| 状态 | UI | 可执行动作 | 退出条件 |
|---|---|---|---|
| `initialLoading` | 不可扫描占位 + 签发提示 | 返回 | 签发成功/失败 |
| `ready` | 二维码、昵称和剩余时间 | 刷新、返回 | 过期/后台/刷新 |
| `refreshing` | 隐藏旧码 + 刷新进度 | 返回 | 新码成功/失败 |
| `expired` | 不可扫描过期占位 | 刷新、返回 | 新码成功 |
| `offline` | 不显示二维码 + 需要联网提示 | 重试、返回 | 恢复网络 |
| `error` | 不显示二维码 + 稳定错误 | 重试、返回 | 签发成功 |
| `backgroundHidden` | 隐私遮罩，不显示码和倒计时详情 | 无业务动作 | 回前台校验 |
| `sessionInvalid` | 清空 token，不显示业务错误 | 无 | 全局 reset |

## 不变量

- 除 `ready` 外任何状态都不得显示可扫描二维码。
- 客户端倒计时只决定 UI；服务端过期、撤销和身份校验才是权威安全边界。
- 刷新时旧码立即从 UI 消失，不在失败后重新展示可能已撤销的旧码。
- 页面不可见、会话失效或 generation 变化时立即清除载荷。
- 迟到的签发响应不得恢复旧页面或旧会话的二维码。

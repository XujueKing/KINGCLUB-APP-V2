# 个人二维码页状态

## 当前状态

| 状态 | UI | 动作 | 退出条件 |
|---|---|---|---|
| `ready` | 身份信息 + 长期二维码 + 扫码说明 | 返回 | 离开页面 |
| `sessionInvalid` | 清理当前页面并请求重新认证 | 确认 | 全局 reset |

## 不变量

- `ready` 状态的二维码在页面重建、进入后台和恢复前台后保持同一内容。
- 页面没有倒计时、即将过期、过期、刷新、离线、后台隐藏或迟到响应状态。
- 页面不提供保存、分享、复制和扫码入口。
- 真实二维码数据契约未批准前，只使用 UI/Fake 稳定内容，不访问生产接口。
- 历史短期码状态仅保留在 `legacy_ui_replication.md` 供追溯，不属于当前产品状态机。

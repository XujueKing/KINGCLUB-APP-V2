# 长期个人二维码小程序复刻规格

- 文档状态：`Approved for Development`
- 用户决定：2026-09-12 明确取消时效
- 旧版依据：`pages/mycode/mycode.wxml`、`mycode.wxss`、`mycode.js`
- 交付范围：Flutter UI + 稳定本地二维码；不接真实接口、保存或分享

## 固定视觉与行为

- 标题为“我的二维码”，使用全局标准返回键。
- 主体保持用户图二的纵向结构：身份区整体下移，使用 480rpx 宽身份行、80rpx 圆角头像和单行会员号，不额外显示昵称。
- 二维码白色画布保持 500rpx；黑色码区按旧版 `qrcode.js` 的四模块静区缩小到约 412rpx，并使用原始 `kingLogo.png` 作为约 96rpx 中心标志。
- 身份行与二维码之间保持 40rpx，二维码与 24rpx 灰色说明之间保持 30rpx。
- 二维码以稳定 Mock 好友入口生成。
- 页面不存在倒计时、刷新按钮、过期遮罩、后台隐藏和安全说明卡。

# KC-P-042 旧版 UI 复刻规格

状态：Approved for Development（仅 UI / Fake）

## 复刻基线

- 旧版页面：`pages/mycode/mycode`
- 顶部标题保持“我的二维码”，左侧返回。
- 黑色背景；用户信息在二维码上方，头像按本期确认保持空白。
- 二维码为白底黑色视觉区，提示文案为“扫一扫上面的二维码图案，加我成为朋友”。

## V2 安全调整

- 仅生成视觉 Fake 码，不嵌入账号、Token、URL 或其他真实身份凭证。
- Fake 邀请码有效期 10 分钟，显示剩余时间；刷新后替换视觉码并重置倒计时。
- 应用进入后台时二维码区域隐藏，回到前台后需主动刷新。
- 不提供保存、分享或复制二维码内容。

## Fake 状态

- 正常、即将过期、已过期、离线刷新失败、生成失败、后台隐藏。
- 所有状态都在本地切换，不请求服务器。

## 用户任务

当面向另一位 KingClub 用户出示一个短期、可撤销的好友连接二维码，避免暴露永久账号。

## 入口、出口与返回

- 入口：我的主页“个人二维码”；路由无账号、token 或外部参数。
- 前置：authenticated + membership approved，且在线时才能签发或刷新。
- 出口：仅返回我的主页；本页不承担扫码、好友预览或自动加好友。
- 后台规则：App 进入后台或页面不可见时立即隐藏二维码；回前台后校验过期时间再显示或刷新。

## 线框

```text
[返回]              我的二维码

           [头像] 会员昵称
       让对方使用 KingClub 扫码添加

       ┌────────────────────┐
       │                    │
       │   短期好友邀请码    │
       │                    │
       └────────────────────┘

          09:42 后失效
          [立即刷新]

二维码不会包含你的永久账号
```

## 二维码契约

- 载荷是服务端签发的随机 `friendInviteToken` 表达，不编码 `userAccount`、手机号、Authorization 或任意网页 URL。
- 已确认有效期为 10 分钟；每次刷新撤销或替代前一个 token，服务端消费时仍验证签发人状态、过期和撤销。
- 扫描结果只进入好友预览/申请；建立好友关系需要后续明确确认。
- M0 不保存到相册、不调用系统分享、不复制 payload，也不签发永久码或离线码。

## 视觉与无障碍

- 二维码有足够静区与对比度，周围不叠加动态纹理；品牌装饰不能侵入码区。
- 倒计时不用每秒向读屏播报，仅在剩余 1 分钟、过期和刷新完成时提供状态提示。
- 读屏描述为“用于发起好友申请的短期二维码”，不朗读或暴露 token 内容。
- 不宣称可以完全阻止系统截图；通过短有效期、后台隐藏和服务端校验降低传播风险。

## 数据与隐私

- token 只保存在当前页面内存中，不进入路由、磁盘缓存、日志、埋点或错误报告。
- 埋点仅记录签发/刷新/过期的结果类别和耗时桶，不记录载荷或用户资料。
- 会话失效、登出、账号切换或页面销毁时清除 token，并尽力调用撤销契约。

# 个人二维码页交互

| 触发 | 行为 | 防重/失败处理 |
|---|---|---|
| 首次进入 | 调用 Fake `issueFriendInvite` 获取 token 与权威过期时间 | SingleFlight；加载时无旧码 |
| 点击立即刷新 | 先隐藏旧码，再调用 `refreshFriendInvite` | 禁用重复点击；失败不恢复旧码 |
| 倒计时归零 | 立即移除码并进入 `expired` | 不依赖截图或本地时钟继续授权 |
| App 进入后台 | 清除渲染并进入 `backgroundHidden` | 不在任务切换预览中保留码 |
| App 回前台 | 对照权威过期时间；有效则恢复，无效则刷新/过期 | 不直接相信暂停前倒计时 |
| 页面返回/销毁 | 清除内存 token，尽力撤销 | 撤销失败不阻塞返回 |
| 会话失效 | 清除 token 并交给全局守卫 reset | 不保留返回栈 |

## 明确不提供的交互

- 不长按复制、保存图片、分享到外部应用或显示二维码原始文本。
- 不在本页启动相机扫描，也不把扫描结果在本页消费。
- 不自动提高系统亮度或修改持久系统设置。
- 不支持群二维码、经营二维码或带自由跳转地址的码。

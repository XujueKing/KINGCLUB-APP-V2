# 个人二维码页交互

## 当前交互

| 触发 | 行为 | 约束 |
|---|---|---|
| 页面进入 | 立即展示身份信息和长期个人二维码 | 不启动计时器，不请求签发接口 |
| App 进入后台/恢复前台 | 页面视觉与二维码内容保持不变 | 不隐藏、不刷新、不替换 |
| 页面重建 | 使用同一稳定内容重新渲染 | 不生成随机码 |
| 点击返回 | 返回我的主页 | 直接路由也有明确后备返回 |
| 会话失效 | 清理当前页面并交给全局守卫重新认证 | 不保留错误返回栈 |

## 明确不提供的交互

- 不显示倒计时、刷新、过期、离线或后台隐藏提示。
- 不长按复制、保存图片、分享到外部应用或显示二维码原始文本。
- 不在本页启动相机扫描，也不在本页建立好友关系。
- 不支持群二维码、经营二维码或带自由跳转地址的码。
- 历史短期码签发流程见 `legacy_ui_replication.md`，已被 2026-09-12 用户决定废止。

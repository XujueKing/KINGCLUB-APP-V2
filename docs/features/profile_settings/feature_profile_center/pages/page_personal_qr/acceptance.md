# 个人二维码页验收

## 载荷与生命周期

- [ ] 码中不含永久账号、手机号、Authorization 或网页 URL。
- [ ] 10 分钟有效期、刷新替换、过期、撤销和迟到响应均可 Fake 演示。
- [ ] 页面隐藏、销毁、登出、会话失效及账号切换会移除内存 token。
- [ ] 除 `ready` 外所有状态均不可扫描；刷新失败不恢复旧码。

## 交互与隐私

- [ ] 不提供保存、分享、复制载荷、永久码、离线签发或群二维码。
- [ ] App 后台时以隐私遮罩覆盖，回前台重新校验有效期。
- [ ] 日志、埋点、路由、缓存和错误报告均不含 token。
- [ ] 文档不把客户端倒计时或“防截图”当成安全授权边界。

## 可用性与无障碍

- [ ] 二维码静区、尺寸与对比度满足扫描需要，品牌装饰不侵入码区。
- [ ] 读屏获得用途和到期状态，但不会朗读 token；倒计时不会每秒播报。
- [ ] 网络断开、签发失败和过期均有明确恢复动作。

## 交付门禁

- [ ] 用户批准后才可标记 `Approved for Development`。
- [ ] 全部 48 页批准前不创建 Flutter UI；全局 UI Flow Approved 前不连接真实签发/撤销接口。

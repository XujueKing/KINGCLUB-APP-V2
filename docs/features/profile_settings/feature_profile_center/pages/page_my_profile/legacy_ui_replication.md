## 旧版字体标尺（2026-08-28 复验）

旧版以 `750rpx` 为页面设计宽度。Flutter 页面必须按当前页面宽度换算，禁止用偏大的通用标题字号替代：

| 区域 | 旧版源码 | 393dp 预览基准 | 字重 |
|---|---:|---:|---|
| 昵称 | `38rpx` | `19.9dp` | `600` |
| 账号 | `22rpx` | `11.5dp` | 常规 |
| 统计数字 | `34rpx` | `17.8dp` | `600` |
| 统计名称 | `26rpx` | `13.6dp` | 常规 |
| 资料标签 | `24rpx` | `12.6dp` | 常规 |
| 未选内容页签 | `28rpx` | `14.7dp` | 常规 |
| 已选内容页签 | `32rpx` | `16.8dp` | `600` |
| 等级文字 | `18rpx` | `9.4dp` | 常规 |

- “编辑主页”和资产数字不得使用粗体标题样式；视觉重量应低于昵称和选中页签。
- 中文正文统一使用系统无衬线字体，不额外增加字间距，不使用 `w700/w800` 模拟旧版 `600`。
- 页面验收需同时检查字号、字重、基线、块间距，不以“内容齐全”代替视觉复刻。

## 可操作内容

| 入口 | Fake 行为 |
|---|---|
| 二维码 | 打开个人二维码离线预览，明确不包含真实账号/token |
| 设置 | 打开固定设置 Fake 面板，含支付安全、注销、通知、缓存、关于和退出 |
| EXP/等级 | 打开等级说明，展示青铜 L-0、EXP 50 |
| 账号复制 | 只把 Fake 账号写入页面内提示，不访问系统剪贴板 |
| 四项统计 | 打开对应旧版统计空列表 |
| 编辑主页 | 打开可编辑资料 Fake 表单并可本地保存返回 |
| 余额/金币/钻石 | 打开对应 Fake 资产流水页 |
| 作品 | 旧版三列作品区域；当前使用空内容说明，不伪造用户作品 |
| 动态 | 旧版时间线区域；截图基准为空 |
| 相册 | 旧版三列相册区域；当前使用空内容说明，不伪造真人照片 |

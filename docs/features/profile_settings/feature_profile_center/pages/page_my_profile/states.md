# 我的主页状态

| 状态 | UI | 可执行动作 | 退出条件 |
|---|---|---|---|
| `initialLoading` | 资料卡和服务入口骨架 | Shell 导航 | 快照返回 |
| `ready` | 完整资料卡和固定服务入口 | 刷新、固定 RouteIntent | 刷新/失效 |
| `incompleteProfile` | 可用资料 + 明确完善提示 | 编辑资料、其他入口 | 资料补全 |
| `partialError` | 可用资料 + 局部错误提示 | 局部重试、其他入口 | 局部数据成功 |
| `offlineCached` | 缓存资料 + 离线与更新时间 | 浏览、重试、允许的本地导航 | 恢复网络 |
| `refreshing` | 保留旧资料 + 刷新状态 | 单次刷新、其他稳定入口 | 成功/失败 |
| `fatalError` | Shell 内全页错误 | 重试、切换 Tab | 快照成功 |
| `sessionInvalid` | 不在页面内渲染业务错误 | 无 | 全局 reset |

## 不变量

- 固定服务入口不会由服务端动态菜单增删或重排。
- 局部失败不清空已经成功且仍属于当前会话世代的资料。
- `offlineCached` 必须标记缓存及更新时间，不能冒充实时权威状态。
- 任一状态都不得泄露统一账号、手机号、实名或余额。
- 旧 generation 的迟到响应不得覆盖新会话或更新快照。

## 用户任务

查看自己的会员展示资料，并快速进入资料编辑、个人二维码、订单、资产、私人储物柜和设置。

## 入口、出口与返回

- 入口：App Shell“我的”Tab；重复点击当前 Tab 时回到顶部。
- 前置：authenticated + membership approved；不满足时由全局守卫 reset。
- 出口：`openEditProfile`、`openPersonalQr` 以及订单、资产、储物柜、设置的固定 RouteIntent。
- 返回：本页是“我的”分支根；系统返回由 App Shell 统一处理，不返回登录或准入页。

## 页面组成

| 区域 | 内容与约束 |
|---|---|
| Brand Header | 固定品牌标题与设置按钮，不使用用户自定义封面 |
| Profile Card | 头像、昵称、会员认证标识、简介及非敏感展示字段 |
| Profile Actions | 编辑资料、个人二维码两个固定动作 |
| Personal Services | 订单、钱包与资产、私人储物柜、设置固定入口 |
| Notice | 可选资料完善度或清洗后的稳定类别提示 |

## 显示边界

- 不显示、复制或嵌入统一 `U... userAccount`、手机号、实名、生日等身份信息。
- 不展示旧版作品/动态/相册、获赞/关注/互关/粉丝统计、颜值、金币/钻石或经营管理入口。
- 金额不能直接出现在首页快照；用户进入资产页后再按该页面的隐私规则加载。
- 下游页面尚未批准时入口仍保留，但 Fake 阶段显示“功能准备中”，不得跳入空白页。

## 视觉与无障碍

- 使用 Design System v1 品牌背景和层级卡片；不开放背景封面上传。
- 头像有昵称替代文本，认证标识同时提供文字语义，不只依赖颜色或图标。
- 200% 字体下资料动作和服务入口允许改为单列，文本不得截断。
- 页面不复制 App Shell 底栏；线框底栏仅表示上下文。

## 数据与隐私

- 只消费清洗后的 `MyProfileSnapshot` 展示投影，不把服务端原始对象直接绑定 UI。
- 埋点只记录 `me_view`、固定 actionId、结果类别和耗时桶；不记录昵称、简介、城市、职业或头像 URL。
- 离线缓存按会话世代隔离，登出、账号切换或会话失效时清除。

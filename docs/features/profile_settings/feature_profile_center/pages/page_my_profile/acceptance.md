# 我的主页验收

## 文档与范围

- [ ] 只包含资料卡、编辑/二维码动作及订单、资产、储物柜、设置固定入口。
- [ ] 不出现旧作品/动态/相册、关系统计、颜值或经营管理入口。
- [ ] 不显示或复制统一账号、手机号、实名、生日和资产金额。

## 状态与交互

- [ ] `initialLoading`、`ready`、`incompleteProfile`、`partialError`、`offlineCached`、`fatalError`、`sessionInvalid` 均可独立 Fake 演示。
- [ ] 下拉刷新保留旧内容且防重复；局部失败不会清空成功区域。
- [ ] 重复点击“我的”Tab 回顶，不创建重复路由。
- [ ] 未批准的下游入口以稳定提示收口，不进入空白页。

## 隐私与无障碍

- [ ] 埋点、日志和缓存不包含用户资料正文或头像 URL。
- [ ] 头像和认证标识具有可读语义；200% 字体不截断。
- [ ] 会话切换或失效后旧缓存与迟到结果不可见。

## 交付门禁

- [ ] 用户批准后才可标记 `Approved for Development`。
- [ ] 全部 48 页批准前不创建 Flutter UI；全局 UI Flow Approved 前不连接真实接口。

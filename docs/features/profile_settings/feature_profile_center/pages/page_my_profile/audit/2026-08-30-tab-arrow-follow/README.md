# 内容页签箭头跟随验收（2026-08-30）

## 规则

- `作品 / 动态 / 相册` 互斥选中，默认选中“动态”。
- 当前项使用原有加粗样式，并在文字右侧显示同一枚 `20dp` 小下箭头。
- 切换页签时箭头随选中项移动；页面始终只有一个箭头。
- 箭头和文字共用点击区域，不新增独立操作。

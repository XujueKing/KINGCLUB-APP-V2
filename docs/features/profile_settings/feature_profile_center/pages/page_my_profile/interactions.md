# 我的主页交互

| 触发 | 离线 UI Mock 行为 |
|---|---|
| 点击个人二维码 | 打开二维码预览；二维码不含真实身份凭证 |
| 点击设置 | 打开支付安全、账号与安全、通知、缓存、关于、注销和退出入口 |
| 点击 EXP | 打开青铜 L-0 等级说明 |
| 点击账号复制 | 仅显示 Fake 复制反馈，不写系统剪贴板 |
| 点击四项统计 | 打开对应旧版空列表并可返回 |
| 点击编辑主页 | 打开昵称与签名本地表单；头像继续保持空白 |
| 点击资产 | 打开对应 Fake 资产说明，不产生资产变化 |
| 点击作品/动态/相册 | 本地切换旧版内容区；默认动态，均不读取用户媒体 |

## 不变量

- 所有交互仅在当前内存中执行，退出应用后不保证保留。
- 不发起 HTTP、超级接口、WebSocket、支付、推送或系统权限请求。
- 不把 Fake 账号、资产或二维码当作真实凭证。

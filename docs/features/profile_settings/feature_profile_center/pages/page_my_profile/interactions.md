# 我的主页交互

| 触发 | 离线 UI Mock 行为 |
|---|---|
| 点击个人二维码 | 打开二维码预览；二维码不含真实身份凭证 |
| 点击设置 | 打开支付安全、账号与安全、通知、缓存、关于、注销和退出入口 |
| 点击 EXP | 打开青铜 L-0 等级说明 |
| 点击账号复制 | 仅显示 Fake 复制反馈，不写系统剪贴板 |
| 点击四项统计 | 打开对应旧版空列表并可返回 |
| 点击编辑主页 | 打开黑金资料表单；可修改本地封面、昵称与签名，头像继续保持空白 |
| 点击资产 | 打开对应 Fake 资产说明，不产生资产变化 |
| 点击我的订单 | 只触发 `OrderCenterRoute` 打开统一订单中心；不传递订单业务对象 |
| 点击作品/动态/相册 | 本地切换旧版内容区；默认动态，均不读取用户媒体 |

页签视觉不变量：只有“动态”处于选中态时显示小下箭头；切换到“作品”或“相册”后箭头随选中态一起消失。

## 不变量

- 除用户主动保存的封面外，所有 Fake 交互仅在当前内存中执行；封面保存在应用私有目录供 UI 验收跨启动查看。
- 不发起 HTTP、超级接口、WebSocket、支付、推送或系统权限请求。
- 不把 Fake 账号、资产或二维码当作真实凭证。
- 从订单中心返回时保留“我的”Tab 和个人页本地状态，不重新创建 App Shell。
- 编辑主页保存成功后，封面、昵称和签名在当前“我的”页面一次性更新。
- 封面本地写入失败时不得覆盖最后一次成功封面；页面给出稳定提示且不伪报成功。

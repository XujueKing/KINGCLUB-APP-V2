# 我的主页交互

| 触发 | 行为 | 防重/失败处理 |
|---|---|---|
| 首次进入 | 加载当前会话的 `MyProfileSnapshot` | 相同 generation 使用 SingleFlight |
| 下拉刷新 | 保留旧内容并刷新快照 | 刷新期间不重复发起 |
| 重复点击“我的”Tab | 回到列表顶部；已在顶部时可执行一次轻量刷新 | 不重建 Shell 分支 |
| 点击编辑资料 | 发出 `openEditProfile` | 路由拒绝时显示稳定提示 |
| 点击个人二维码 | 发出 `openPersonalQr` | 不预取或持久化二维码 token |
| 点击个人服务 | 发出对应固定 RouteIntent | 未开放功能显示“功能准备中” |
| 点击局部重试 | 仅重试失败模块 | 不清空其他模块 |
| 会话失效 | 清理资料缓存并交给全局守卫 reset | 不保留返回栈 |

## 导航约束

- UI 不拼接路径字符串、不接收服务端 URL，也不通过自由文本决定跳转。
- 编辑和二维码返回本页时刷新展示版本；重复返回结果只消费一次。
- 订单、资产、储物柜、设置由各自页面拥有加载与隐私策略，本页不提前请求其数据。

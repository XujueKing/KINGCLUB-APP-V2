# 我的个人信息页交互

| 触发 | 行为 |
|---|---|
| 从“我的”页点击“我的个人信息” | 进入本页，不进入旧编辑封面页 |
| 从设置页点击“个人信息” | 进入本页 |
| 点击返回 | 返回实际来源页 |
| 点击头像 | 打开系统相册；选择后进入方形裁切页，确认后本地保存并刷新圆形头像 |
| 取消选择/裁切或相册权限失败 | 保持原头像并显示非阻断提示 |
| 点击会员称呼 | 打开黑金文本编辑弹窗，本地更新当前页 |
| 点击签名 | 打开黑金文本编辑弹窗，本地更新当前页 |
| 点击修改支付密码 | 进入现有支付安全页 |
| 点击其他只读行 | 无动作 |

手机号、会员号、年龄/性别、颜值、能量等级和灵根只读；头像文件只写入 App 私有目录，不调用真实上传接口。

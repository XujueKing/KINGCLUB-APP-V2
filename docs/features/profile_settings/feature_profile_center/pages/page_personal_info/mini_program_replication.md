# 小程序“我的个人信息”复刻规格

- 文档状态：`Approved for Development`
- 用户视觉基准：2026-09-12 会话截图（1080 × 2400）
- 旧版依据：`pages/myinfo/myinfo.wxml`、`myinfo.wxss` 与全局 `app.wxss`
- 交付范围：Flutter UI + Mock/Fake 数据和跳转，不接真实资料或媒体接口

## 尺寸基准

- 内容宽度 `660rpx`，圆形头像 `200rpx`。Flutter 使用固定 `64dp` 标题栏，因此标题栏后的头像上间距校准为 `20rpx`、下间距保留 `60rpx`，使实机位置与用户图一一致。
- 行内容纵向内边距 `30rpx`，底部分隔线为香槟金 13% 透明度。右侧值使用固定尾部列并右对齐；所有值的右边缘一致，三处可编辑箭头位于同一固定列。
- 标签 `30rpx`，值 `28rpx` 灰色；右箭头使用旧版 `next.png`。
- 能量值行复用旧版绿色能量图标，不使用 Emoji 或重画图标。
- 头像为整块可点击控件，复用旧版 `chooseImage` 语义：选择相册图片后进入方形裁切页，确认后以圆形头像显示并保存到 App 私有目录；取消、权限拒绝和读取失败均保留原头像。

## 数据投影

UI Mock 按用户截图提供稳定展示数据；头像只本地持久化。真实接入时由批准后的个人资料投影与头像上传 adapter 替换，不允许页面直接恢复旧版上传 URL 或动态 `menuMyList` 路由。

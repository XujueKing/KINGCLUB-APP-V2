- 设计版本：`Profile Center Wireframe v1 / Edit`
- 最后更新：2026-08-25

## 用户任务

安全修改自己的公开展示资料与兴趣偏好，明确知道哪些字段可改、保存是否成功以及冲突时如何恢复。

## 入口、出口与返回

- 入口：我的主页“编辑资料”；路由无用户身份参数。
- 前置：authenticated + membership approved。
- 成功出口：返回我的主页并携带一次性的 `profileVersion` 更新结果。
- 返回：无改动直接返回；有未保存改动时弹出“放弃修改/继续编辑”。

## 可编辑字段

| 字段 | 已确认 v1 校验 | 说明 |
|---|---|---|
| avatar | 图片类型、尺寸和内容安全由媒体契约约束 | Fake 阶段只模拟选择/裁剪/上传 |
| nickname | 去首尾空白后 2～24 个字符 | 不接受全空白或控制字符 |
| bio | 0～120 个字符 | 可清空 |
| cityOptionId / districtOptionId | 必须来自版本化目录 | 区域必须属于城市 |
| occupation | 0～40 个字符 | 可清空，不用自由文本表示身份权限 |
| heightCm | 120～230 的整数或空值 | 只作公开资料，不作实名事实 |
| preferenceOptionIds | 每类 0～1 个稳定 optionId | 到店时段、酒水、音乐、社交四类 |

以上长度和范围已冻结为 v1 UI 契约；服务端仍需独立执行等价或更严格校验。

## 只读与排除字段

- 统一账号、实名/成年结论、手机号、会员状态、审核状态只读，且本页不展示明文身份值。
- 不修改真实姓名、证件、出生日期、性别、余额、等级、支付密码或背景封面。
- 字段结构由稳定客户端契约定义，不恢复旧版服务端数字 `indexNum` 动态菜单。

## 视觉与无障碍

- 每个字段有持久标签，错误提示同时说明原因和修复方式，不只使用红色。
- 保存按钮在保存中显示明确进度并禁用重复提交。
- 键盘遮挡时当前字段和错误提示仍可滚动到可见区域；200% 字体不截断。

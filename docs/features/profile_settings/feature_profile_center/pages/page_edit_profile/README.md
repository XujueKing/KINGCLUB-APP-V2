## 用户任务

安全修改自己的公开展示资料与兴趣偏好，明确知道哪些字段可改、保存是否成功以及冲突时如何恢复。

## 入口、出口与返回

- 入口：我的主页“编辑资料”；路由无用户身份参数。
- 前置：authenticated + membership approved。
- 成功出口：返回我的主页并携带一次性的 `profileVersion` 更新结果。
- 返回：无改动直接返回；有未保存改动时弹出“放弃修改/继续编辑”。

## 可编辑字段

| 字段 | 已确认 v1 校验 | 说明 |
|---|---|---|
| avatar | 本期固定为空白头像 | 不提供点击、选择、裁剪或上传入口 |
| coverRef | 系统相册图片经本地裁剪/位置调整后的应用私有文件 | 选择后先调整和预览，随整页保存；本阶段不上传 |
| nickname | 去首尾空白后 2～24 个字符 | 不接受全空白或控制字符 |
| bio | 0～120 个字符 | 可清空 |
| cityOptionId / districtOptionId | 必须来自版本化目录 | 区域必须属于城市 |
| occupation | 0～40 个字符 | 可清空，不用自由文本表示身份权限 |
| heightCm | 120～230 的整数或空值 | 只作公开资料，不作实名事实 |
| preferenceOptionIds | 每类 0～1 个稳定 optionId | 到店时段、酒水、音乐、社交四类 |

以上长度和范围已冻结为 v1 UI 契约；服务端仍需独立执行等价或更严格校验。

## 只读与排除字段

- 统一账号、实名/成年结论、手机号、会员状态、审核状态只读，且本页不展示明文身份值。
- 不修改真实姓名、证件、出生日期、性别、余额、等级或支付密码。
- 字段结构由稳定客户端契约定义，不恢复旧版服务端数字 `indexNum` 动态菜单。

## 视觉与无障碍

- 页面、文本编辑弹窗、封面选择器、退出确认和错误状态统一使用黑曜石、香槟金与深棕色；禁止粉色背景、粉色文字和粉色选中态。
- 每个字段有持久标签，错误提示同时说明原因和修复方式，不只使用颜色。
- 保存按钮在保存中显示明确进度并禁用重复提交。
- 键盘遮挡时当前字段和错误提示仍可滚动到可见区域；200% 字体不截断。

## 2026-08-29 用户确认变更

- 编辑主页全部改为黑金主题，不保留旧小程序粉色弹窗。

## 2026-08-29 相册选择补充确认

- “更换封面”改为紧凑型黑金胶囊，不再遮挡封面主体；整张封面仍是可点击热区。
- 点击入口直接调用系统相册单选图片，与头像媒体选择采用同一系统选择语义。
- 相册取消不产生脏状态；读取失败显示稳定提示并保留原封面与其他资料草稿。
- 本轮只保留设备本地预览引用，不上传服务器、不提交真实资料接口，也不新增相机入口。

## 2026-08-29 封面调整与本地保存冻结

- 头像按用户已确认范围继续保持空白，本期不提供头像交互；此前头像 Fake 失败面板撤销。
- 相册选图后进入黑金“调整封面”页，预览框严格使用主页封面比例，可拖动和缩放图片。
- 确认调整后生成本地裁剪结果；取消调整不改变原封面，也不产生脏状态。
- 点击整页“保存”后，裁剪结果复制到应用私有目录；重新启动 App 后继续显示。
- 持久化只属于 UI Mock 的设备本地状态，不上传服务器，不创建未来服务端媒体契约。

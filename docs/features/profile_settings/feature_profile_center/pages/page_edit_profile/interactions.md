# 编辑个人资料页交互

| 触发 | 行为 | 防重/失败处理 |
|---|---|---|
| 首次进入 | 加载 `EditableProfile`、目录版本和 `profileVersion` | 相同 generation SingleFlight |
| 修改文本/选项 | 更新本地草稿并即时做确定性校验 | 不逐键发送网络请求 |
| 点击空白头像 | 无动作，仅表达本期头像未设置 | 不打开相册或 Fake 场景 |
| 更换封面 | 系统相册单选 → 黑金调整页拖动/缩放 → 本地裁剪预览 | 任一步取消均不改草稿；读取/裁剪失败保留原封面 |
| 点击保存 | 校验 → 必要时提交头像 → 提交 `ProfilePatch` | 使用幂等键并禁用重复点击 |
| 保存成功 | 返回新 `profileVersion`，我的主页刷新一次 | 不回传整份资料到路由 |
| 保存超时 | 进入 `resultUnknown`，按幂等键或版本查询确认 | 不直接重复创建提交 |
| 版本冲突 | 提示资料已变化，允许重新加载并人工合并 | 不执行 last-write-wins |
| 有改动时返回 | 显示放弃确认 | 继续编辑时保留草稿 |
| 无改动时返回 | 直接返回我的主页 | 不弹确认框 |

## 离线演示入口

- 长按顶部“我的个人信息”打开不改变旧版首屏外观的 Fake 场景面板。
- 面板可指定下一次保存为成功、版本冲突、结果未知、明确失败或会话失效，也可演示偏好目录过期刷新。
- 空头像本期不可点击，不再展示头像选择或上传失败场景。
- 点击紧凑“更换封面”入口打开系统相册；选图后必须完成封面位置调整，确认后才更新本地草稿。
- 整页保存时把裁剪结果写入应用私有目录，供 UI Mock 跨启动显示；正式上传、内容审核与服务端媒体接入仍受门禁阻止。
- 保存中按钮禁用并显示进度，快速重复点击只产生一个逻辑提交。

## 内容与目录规则

- 城市/区域和四类偏好只保存稳定 optionId；显示文案可随目录版本变化。
- 不把服务端原始错误或审核内部原因直接显示给用户。
- 本地草稿只存在于当前编辑会话；M0 不做跨启动草稿恢复。
- Fake 演示必须覆盖头像失败、版本冲突和保存结果未知，不能只演示成功路径。
- 昵称、签名等文本编辑弹窗统一使用黑金主题；键盘出现时不得恢复旧版粉色弹窗。

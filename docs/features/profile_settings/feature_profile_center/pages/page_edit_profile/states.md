# 编辑个人资料页状态

| 状态 | UI | 可执行动作 | 退出条件 |
|---|---|---|---|
| `initialLoading` | 固定表单骨架 | 返回 | 编辑投影返回 |
| `editing` | 黑金表单、封面预览 + 空白头像 + 脏状态 | 修改、换封面、保存、返回 | 选择媒体/保存 |
| `coverSelecting` | 系统相册单图选择器 | 选择本地图片、取消 | 返回 editing |
| `coverAdjusting` | 主页比例预览、拖动和缩放 | 确认裁剪、取消 | 返回 editing |
| `saving` | 保留表单 + 保存进度 | 无重复保存 | 成功/失败 |
| `versionConflict` | 冲突说明 + 重新加载/保留草稿选择 | 重新加载、返回编辑 | 新版本加载 |
| `resultUnknown` | 保存结果未知提示 | 查询最新版本、稍后重试 | 确认成功/失败 |
| `validationError` | 字段级错误 | 修正字段 | 本地校验通过 |
| `loadOrSaveError` | 保留安全草稿 + 稳定错误 | 重试、继续编辑、返回 | 成功/放弃 |
| `sessionInvalid` | 不继续显示敏感草稿 | 无 | 清理并全局 reset |

## 不变量

- 原始快照、草稿和 `profileVersion` 必须来自同一会话世代。
- 保存中只能存在一个逻辑提交；迟到响应不得覆盖新编辑或新会话。
- 头像本期始终为空且不可交互。
- 冲突不能静默覆盖服务器较新版本。
- 会话失效时清除内存草稿、媒体临时引用和可能的上传意图。
- 封面选择与其他资料共享一次保存语义；单独选择封面不视为保存成功。
- 系统相册取消或读取失败不得覆盖当前封面引用，也不得清除其他资料草稿。
- 调整页取消或本地裁剪失败不得覆盖当前封面引用；整页保存成功后才替换应用私有封面文件。

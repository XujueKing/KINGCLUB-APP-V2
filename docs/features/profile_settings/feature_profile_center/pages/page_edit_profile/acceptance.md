# 编辑个人资料页验收

## 表单范围

- [ ] 仅可编辑头像、昵称、简介、城市/区域、职业、身高和四类偏好。
- [ ] 实名、手机号、性别、生日、余额、等级、支付密码及封面不在表单内。
- [ ] 字段使用稳定名称和 optionId，不依赖服务端数字菜单索引。
- [ ] 所有长度、取值范围和城市区域从属关系均有确定性校验。

## 状态与一致性

- [ ] 加载、编辑、媒体选择/上传、保存、校验失败、版本冲突、结果未知、会话失效均可 Fake 演示。
- [ ] 保存防重复并携带幂等键与 `profileVersion`。
- [ ] 头像上传与资料 commit 分开表达，上传成功不会误报整页保存成功。
- [ ] 冲突不会静默覆盖，结果未知不会盲目重复提交。
- [ ] 未保存退出确认和键盘返回行为一致。

## 安全与无障碍

- [ ] 上传地址、日志、埋点和路由不含统一账号、Authorization 或资料正文。
- [ ] 会话失效清除草稿和媒体临时引用。
- [ ] 字段标签、错误、进度可由读屏理解，200% 字体和键盘遮挡场景可用。

## 交付门禁

- [ ] 用户批准后才可标记 `Approved for Development`。
- [ ] 全部 48 页批准前不创建 Flutter UI；全局 UI Flow Approved 前不连接媒体或资料接口。

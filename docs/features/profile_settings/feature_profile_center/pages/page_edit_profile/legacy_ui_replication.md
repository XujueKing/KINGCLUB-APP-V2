# KC-P-041 旧版 UI 复刻规格

状态：Approved for Development（仅 UI / Fake）

## 复刻基线

- 旧版页面：`pages/myinfo/myinfo`
- 顶部标题保持“我的个人信息”，左侧返回。
- 黑色背景、暖金文字、细分隔线；头像居中且按本期确认保持空白。
- 信息采用旧版逐行列表结构：左侧字段名，右侧当前值与箭头。
- 可编辑行点击后进入旧版风格的单字段编辑弹层；保存仅写入页面内 Fake 状态。

## 本期字段

- 头像、昵称、个性签名、所在城市、职业、身高。
- 兴趣偏好：常去时段、音乐偏好、饮酒偏好、组局偏好。
- 不展示实名、手机号、性别、生日、资产、等级、支付密码和主页封面编辑。

## 离线边界

- 原批准 Mock 基线不读取相册；用户于 2026-08-29 单独批准封面调用系统相册，但仍不上传媒体、不调用超级接口。
- 昵称为空或超过 16 字时阻止保存并显示错误。
- 离开存在未保存修改的编辑弹层时给出确认提示。
- 页面级“保存”返回 Fake 结果给“我的”主页。

## 验收视口

- Android Medium Phone 竖屏。
- 页面可完整滚动，键盘弹出时当前编辑项不被遮挡。

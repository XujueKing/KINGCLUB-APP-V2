# 设置页交互

| 触发 | 行为 |
|---|---|
| 点支付安全/注销/关于 | 固定 RouteIntent |
| 点通知权限 | Fake 系统设置；未来只打开 OS 设置 |
| 点清缓存 | 确认后只清媒体，不清会话/业务草稿 |
| 点退出登录 | 二次确认，远端撤销后本地原子清理 |
| 退出超时 | 本地仍安全退出并记录稳定提示 |

## 2026-09-12 小程序菜单映射

| 触发 | 行为 |
|---|---|
| 点个人信息 | 打开现有个人信息编辑页 |
| 点账号安全 | 打开现有支付安全页 |
| 点隐私政策 | 直接打开隐私政策阅读态 |
| 点用户协议 | 直接打开会员服务协议阅读态 |
| 点关于KINGBAR | 打开关于与法律目录 |

以上五项为客户端固定顺序和固定 RouteIntent。原通知权限、清理缓存与账号注销不再作为设置首页可见行。

不得执行服务端返回的字符串路由、URL 或 interfaceId。

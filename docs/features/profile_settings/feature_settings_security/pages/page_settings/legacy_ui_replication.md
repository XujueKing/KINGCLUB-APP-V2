# KC-P-043 旧版 UI 复刻规格

状态：Approved for Development（仅 UI / Fake）

## 复刻基线

- 旧版页面：`pages/setting/setting`
- 黑色背景，暖金文字；顶部居中标题“设置”，左侧返回。
- 菜单采用旧版单行列表：图标、名称、辅助信息、右箭头；行间用低对比度分隔。
- 底部保留独立“注销登录”按钮。

## 固定菜单

1. 支付安全
2. 通知权限
3. 清理缓存
4. 关于与法律
5. 账号注销

## 离线交互

- 通知权限在设置页内展示系统授权状态和 Fake 跳转提示，不创建额外消费者页面。
- 清理缓存弹出二次确认，确认后只把本地展示值改为 `0 B`。
- 注销登录必须二次确认；确认后只展示 UI Mock 结果，不清除真实登录信息。
- 菜单完全由客户端固定，不从超级接口下发页面路径。

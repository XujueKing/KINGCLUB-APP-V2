# KC-P-044 旧版 UI 复刻规格

状态：Approved for Development（仅 UI / Fake）

## 复刻基线

- 旧版页面：`pages/modiffypwd/modiffypwd`。
- 黑色背景、暖金标题、左侧返回；表单纵向排列并保留旧版字段说明和主按钮结构。
- V2 已批准契约覆盖旧版 8 位密码与 MD5 逻辑：界面统一为 6 位数字支付 PIN。

## UI/Fake 流程

1. 默认展示“已设置”状态，可选择修改 PIN 或忘记 PIN。
2. 修改路径：验证旧 PIN → 输入新 PIN → 再次输入 → Fake 成功。
3. 忘记路径：本地模拟短信重新认证 → 输入新 PIN → 再次输入 → Fake 成功。
4. 两次输入不一致、非 6 位和简单组合均在本地阻止。

## 安全边界

- 输入始终遮挡，不提供复制、粘贴或自动填充能力。
- PIN 只存在页面内存，退出、进入后台和提交后立即清除。
- 不显示真实手机号，不调用短信、支付或超级接口。

# 关于与法律文档页交互

| 触发 | 行为 |
|---|---|
| 页面进入 | 读取构建版本和权威目录 |
| 点文档 | 以 DocumentRef 在本页进入阅读态 |
| 深入可选 DocumentRef | 校验目录、版本与可见性 |
| 返回 | 文档态回目录，目录态回设置 |
| 点批准外链 | 显示目标域名确认；Fake 阶段不真实打开 |
| 离线 | 只展示标记版本的可信缓存 |

不执行正文 HTML 中的脚本、任意 scheme 或动态路由。

## 2026-09-12 小程序首屏

- 首屏只显示品牌、产品说明、隐私政策/用户协议内联入口及版本/版权/备案信息，不显示四行文档目录。
- 点击《隐私政策》或《用户协议》进入现有法律文档阅读态；返回先回关于首屏，再返回设置。
- 长按标题继续作为离线 UI Mock 场景入口，不改变正常首屏。

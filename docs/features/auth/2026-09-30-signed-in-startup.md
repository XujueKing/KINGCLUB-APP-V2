# 已登录启动直达首页

用户要求：已登录会员从桌面打开 App，不先显示欢迎封面再跳首页。

此前真实 bootstrap 无条件渲染 LegacyWelcomePage，再异步联网恢复会话。
现在 main 首帧前仅读取安全存储中的本地会员快照，不等待网络。只有凭据完整、
会员已通过且有效刷新期限尚未结束，才恢复会员 UI 状态并将初始路由设为 /home。
显式测试入口保持不变；本地快照不续签凭据、不绕过服务端接口鉴权。

首页首帧后沿既有恢复链在线复核，被撤销会话转登录，会员状态变化回注册/审核分流。
暂时网络失败保留既有界面。无可用本地快照时使用无封面、无动画的中性启动底色，
明确未登录后才显示欢迎页；失败可重试。iOS 原生 LaunchScreen 采用同色背景，
去除静态启动图，系统必要的冷启动过程仍然存在，未承诺零启动耗时。

验证：本地有效/缺失/过期/未批准/停用/残缺会话、无网络启动、撤销与延迟响应、
欢迎封面不闪现以及原注册进度恢复共 37 项测试通过。iPhone 新包待构建和覆盖安装。

# 群邀请状态变化保护

群邀请确认对话框期间，列表可能因实时事件或重连刷新。旧确认现在绑定打开时的列表代次；发生刷新后不再提交旧邀请操作。后台不请求列表或响应操作，返回前台重新读取，迟到的旧请求不会打开群聊或覆盖当前结果。后台清空当前邀请展示，账号变化仍沿用原有失效逻辑。

保持现有邀请、加入/拒绝确认、查看群聊 UI。已发出的操作无法由前台取消，返回前台以服务端列表为准，不将客户端中断视作服务器撤销。

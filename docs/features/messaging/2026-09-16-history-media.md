# 消息上下文媒体入口

原上下文页面只显示消息 text 摘要，图片、语音、文件等不能操作。本次从单聊搜索、群搜索以及聊天引用三个入口传入真实 MessagingRepository 和群标识，复用已有图片、视频、文件、位置及语音组件。

- 图片进入完整预览，视频进入原播放器，文件进入原下载/导出详情页；仍由各组件通过消息编号取得权限和短期凭证，不拿历史 URL 绕过鉴权。
- 位置显示原位置卡片及详情。语音按点击创建播放器，整页共享一个播放实例，刷新/账号变化/后台/离页停止播放，打开其他媒体先停止语音。
- 引用入口补齐发送人称呼映射，并在离开原聊天前停止原语音播放。撤回/隐藏结果仍由历史查询边界控制。

18 项上下文媒体、历史搜索和现有语音播放测试通过；5 文件静态分析通过。新增组件测试确认群文件入口保留 group 标识和原仓库，语音/位置为实际可操作组件。测试替身不证明手机声音和视频解码效果；真机验证在后续记录。

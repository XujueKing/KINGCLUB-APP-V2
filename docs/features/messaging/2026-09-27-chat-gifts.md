# 聊天礼物接入

沿用已核对的旧版赠送规则：发送方支付金币，接收方获得对应金币，礼物消息保存成交快照。服务端目录及原子事务已实现，客户端接入进行中，尚未开放真实赠送或验收真实收付。

金额在接口、队列和加密历史中保留十进制字符串，用 BigInt 计算，不能经过 double。客户端确认报价只代表用户同意的价格；实际扣款以服务端目录为准，价格变化必须重新确认。重试沿用原 clientMessageId。

回执必须匹配已确认的 giftId、数量和单价，并校验总额与成交消息编号。历史只保存规定的成交字段，隐藏或撤回后删除快照。图标只按受控 assetKey 映射内置素材，不采用任意路径。

客户端已实现成交快照模型、回执一致性与历史过滤，并接入服务端目录、数量/总额确认、持久发送队列和礼物卡片。真实会话不再使用演示余额或演示报价。队列先落盘再发送，网络失败沿用同一请求编号；价格变化停止自动重试，仍保留原报价，不自动接受更高或更低价格。群会话暂不提供私聊礼物交易入口。

目录接口 K260927000802，发送接口 K260927000803。当前服务端 166/167 仅在隔离事务测试库验证，运行服务部署、启用接口及设备界面验收尚未完成；未进行真实会员资产转移。

# 2026-09-27 前台实时连接与普通推送分流

用户确认前台使用实时连接和未读红点，后台/离线使用普通厂商通知。现有 App 仅前台启动 CCSOP 实时连接，退后台关闭，恢复前台重连并同步列表/未读；不新增常驻通知、静默音频或无限保活承诺。

新增已加密 client.foreground 心跳：connection.ready 后立即发送，每 15 秒续期；服务端以认证会话及账号匹配设备，45 秒失效、连接关闭立即失效。推送 worker 对该设备暂缓 5 秒再检查，保留 durable intent，不增加设备发送 attempts。读完、撤回、静音等沿用已有资格检查跳过；其他设备不因一个设备前台而被抑制。旧客户端没有心跳时继续正常推送。

当前抑制租约在 WebSocket 服务进程内存，不是跨实例共享 presence；其他实例看不到租约时保守正常推送，可能重复提醒，不会错误丢弃消息。多实例部署需补共享租约。推送已被供应商受理后无法撤回。

# 消息承载路径与确认阶段

本次补齐实际接收路径的诊断，未改变路由选择、消息协议、加密或界面。

- `NovoRudpCarrierObservations` 将载体绑定到已鉴权的接收帧：原生 UDP 直连、已确认的 ICE 直连、尚未分类的 ICE、SuperVM 中继。使用弱关联，不长期保留帧或消息内容。
- 文字分片各自记录接收载体；完整内容校验并持久化后，输出 `CHAT_DELIVERY phase=received_persisted carriers=...`。跨路径分片会列出多个载体。
- `durable_receipt` 仅表示有效持久化回执到达及其返回载体，不能用它推断正向消息走了同一条路径。
- `service_response carrier=ccsop` 仅表示传统发送接口返回，不能据此宣称对端收到或已读。
- 日志仅用于非 release 构建，不含正文、会员号、消息 ID、IP、密钥、SDP。没有提供路径信息的旧链路明确显示 unknown。

验证：14 项测试通过（原生 UDP 重建、文字持久化及丢回执重试、发送生命周期、自适应超时与恢复），涉及文件静态分析通过。原生路由测试关闭 UDP 后确认接收载体为中继，再重建 UDP 确认为直连；历史帧的归属不会被新路由覆盖。

测试中的中继是内存载体，UDP 和原生加密为真实实现。这不是 A/B 公网直连通过的证据；本节点尚未安装新包进行双机验收。当前 A/B 公网 ICE 失败记录仍以 `2026-09-25-ice-data-carrier.md` 为准。

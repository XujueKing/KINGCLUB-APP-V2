# 覆盖安装后启动核验

A 的 ApplicationExitInfo 显示 07:11:05 为 installPackageLI 停止进程；06:55:31、06:26:09 为 OTHER KILLS BY SYSTEM / INVALID START（No entry in mProcessNames）。读取 crash buffer 未见对应应用异常堆栈。证据支持覆盖安装后立即启动与系统安装收尾竞争，不足以断言所有首次启动异常均已解释。

新增 scripts/start-chat-preview.ps1，必须指定设备序列号。启动后读取系统前台三次连续匹配才报告就绪；最多两次启动，不发送坐标、不清数据、不修改网络。未稳定则报错停止。即使核验成功，后续仍必须读取当前 UI，不能推断停在首页。

用于已授权测试手机的安装后启动；不修改产品 UI 或增加用户启动等待动画。脚本只能防止调试流程把启动命令成功误当页面就绪，不宣称修复系统安装器或证明聊天功能通过。

实测：A 已运行任务恢复及 force-stop 后冷启动各执行一次，均首次启动即通过三次前台采样；冷启动随后独立读取 UI 确认首页和底栏出现。没有再次覆盖安装，故不宣称安装收尾竞态已在同一次实验复现并消除。B 未操作。

# 文件发送页登录变化保护

文件发送页原来没有图片/视频页已有的登录变化监听。现在登录变化时隐藏文件名、禁用发送和丢弃、取消现有上传器；等待上传器初始化或上传返回的异步操作检查页面是否仍可用，失效后不继续入队或跳转。保留原草稿和已有发送队列，避免将账号变化误当作用户删除请求。

验证：新增页面未发送/等待上传器初始化两种登录变化用例；既有文件已入队与已确认恢复用例，合计 4 项通过。两个修改文件静态分析通过。

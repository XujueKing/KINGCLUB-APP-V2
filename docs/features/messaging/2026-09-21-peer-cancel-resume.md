# Peer 下载主动中断后续传

主动取消或关闭页面曾同时关闭接收许可，导致关闭时无法保存已收齐的分块。现在把接收许可与本地分块保留条件分开：网络立即停止，完整块保存进原账号、原消息的加密续传缓存；每块写入前后检查登录态和删除状态。退出账号或删除消息不保留这些分块。完整文件仍必须通过原 SHA-256 和权限检查，未增加任何绕过授权的路径。

回归用真实磁盘 receiver 预装两个块对应的片段，并在尚缺尾部时取消、销毁页面、退出账号或删除消息。取消/销毁后重建 downloader 仅通过 HTTP 请求块 1、2，不重复块 0；账号/消息撤销场景不复用旧块。片段跨 1 MiB 边界的未完整块不会保存。

验证：下载、媒体入口、准备顺序与新增中断回归 59 项通过；原本需要 native 库的 5 项另设 NOVORUDP_NATIVE_LIBRARY 执行，全部通过（真实加密、乱序丢包修复、错误对象/哈希、ACK预算、退出清理）。静态分析通过。尚未把本修改安装到双机，不作为公网断线实测结果。

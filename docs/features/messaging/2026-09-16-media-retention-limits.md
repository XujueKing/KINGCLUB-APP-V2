# 语音缓存上限与视频封面持久化

发送、转发、转文字均允许不超过 2MiB 的语音，但 MediaCache 下载上限仅为 512KiB，导致合法大语音无法进入本地缓存。下载上限对齐 2MiB，保留流式大小检查，并在临时文件发布前复核真实文件大小；失败删除临时文件。

视频封面生成原先无条件执行图片预算清理，绕过 retainMedia 默认持久保留策略。现在仅在明确启用预算淘汰时清理，避免生成封面删除此前下载的聊天图片或头像。

14 项缓存测试及两文件静态分析通过，包含 2MiB 下载落盘后重新打开读取、超限无残留文件、生成封面不淘汰已保存图片。网络传输测试使用可控适配器，读取使用实际临时磁盘；不是手机端长语音播放验收。本节点尚未安装至手机，合入下一次预览包验证。

# 会话加号面板：对齐旧小程序 CSS

来源：只读旧项目 `D:/WEB3_AI/KingClub-git/pages/chat/chat.wxss` 的 `.box_main_style`、`.box_style`、`.more_button`、`.more_img`，以及 `app.wxss` 的 `.s24`。

旧版参数：面板 420rpx、内容宽 700rpx、按钮 135rpx、按钮外边距 20rpx、圆角 12rpx、图标 50rpx / 60% 不透明度、文字 24rpx / #AAA；分页点选中 #c9b69e，未选中 #FFFFFF60。

实现：按手机宽度换算 rpx（750rpx = 屏幕宽），统一所有功能图标的尺寸、透明度、按钮与文字间距。宽屏内容上限按 480dp 换算，避免横屏按钮过大。保留现有功能与每页八项；旧版只有一行功能，新版两行的高度按真实文字高度扩展，在系统大字号下允许标签换行，避免裁切。会话占位和面板使用相同高度计算，保持键盘切换连续。

验证结果：目标文件静态分析通过；现有面板分页、关闭、键盘连续性及系统返回共 9 项测试通过；新增 320dp 窄屏、1.8 倍字号下两行标签与分页完整显示的检查通过。键盘等高切换测试改为读取实际面板高度，不再依赖旧的固定 242dp。手机实际观感尚待安装后确认。

## 边界

这是现有双通道文字发送的自适应增强，不代表无服务器聊天全部完成。当前文字仍向 CCSOP 对账；新设备目录授权依赖现有服务。附件既有 peer 下载与 HTTP 回退本轮未修改。公网 SuperVM 引导/中继部署、跨运营商打洞和真实移动网络切换需后续完成；本轮没有安装手机或宣称完成双机验收。

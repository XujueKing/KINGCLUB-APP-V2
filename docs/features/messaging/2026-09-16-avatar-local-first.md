# 头像本地优先

ChatMemberAvatar 在资料请求等待期间读取已有、按当前账号隔离的头像文件 ID，以 cacheOnly 读取持久文件，不使用过期下载凭据。网络资料完成后切换到最新头像；资料被删除或拒绝时不继续展示旧头像。无本地文件仍显示既有默认头像，不新增加载动画。

本地 ID 读取前后检查账号与会话一致，等待同 ID 正在进行的存储修改，异常返回无缓存。切换联系人重建本地 FutureBuilder，避免复用前一联系人快照。

验证覆盖本地描述不依赖网络、账号隔离、慢网络期间选择本地缓存、拒绝后清除显示及既有授权竞态。组件测试验证缓存选择，不等于真机头像首帧耗时验收。本节点尚未安装手机。

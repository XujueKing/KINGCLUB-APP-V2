# 聊天扩展面板与礼物 Mock

- Scope ID：`KC-F-033`
- 文档状态：`Approved for Development`
- 所属业务域：`messaging`
- M0 范围：`In Release Scope（2026-08-29 用户追加）`
- 页面承载：复用 `KC-P-024` 单聊页底部面板，不增加路由或页面数量
- 设计版本：`Legacy Chat Extensions Replica v1`

## 目标

在不连接真实相册、相机、资产、支付或消息服务的前提下，复刻旧版单聊底部扩展体验：照片、拍照、金币、红包以及礼物商城。所有操作使用离线 Fake 数据完整演示，并保持黑金主题。

## 已确认范围

- 单聊输入栏左侧提供礼物入口，右侧提供表情和“＋”入口。
- 礼物入口关闭时保持深棕暗色；点击打开礼物面板后切换为与表情、“＋”一致的香槟金亮色，关闭面板后恢复暗色。
- “＋”面板首屏固定为 `照片 / 拍照 / 金币 / 红包`，图标、四列布局和分页圆点以旧版截图为准。
- 礼物面板包含 `推荐 / 场景特效 / 爱意表达 / 装饰互动` 分类、金币余额、礼物网格、价格、选中态和“赠送”动作。
- 照片、拍照、金币、红包和礼物均只产生本地 Fake 消息；不读取真实相册、不启动真实相机、不扣真实金币、不创建真实红包、不发送真实 WebSocket。
- 原已实现的短视频和业务卡片保留在第二页扩展能力，不占用旧版首屏四项。

## 不做事项

- 不连接真实资产、充值、支付、红包领取或礼物清单接口。
- 不创建独立金币转赠页、红包页或礼物页。
- 不修改服务端契约，不把 Fake 余额或消息视为业务事实。

## 状态与互斥

`键盘 / 更多面板 / 礼物面板` 三者互斥。输入框聚焦关闭扩展面板；打开任一面板先收起键盘；发送成功后关闭当前面板并滚动到最新消息。

礼物发送成功后的消息卡片使用左侧完整礼物图、右侧两级文案。图片与文案组整体垂直居中；“赠送礼物”与礼物名称左边线一致，名称不得贴住标签或卡片边缘。

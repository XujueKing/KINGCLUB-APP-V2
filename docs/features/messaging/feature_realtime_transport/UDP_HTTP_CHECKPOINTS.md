# UDP 到 HTTP 的部分文件交接

认证 UDP 碎片按原位落盘。接收任务关闭前，仅提取覆盖碎片全部到齐的 1 MiB
范围（尾块允许更短），写入同账号、消息、文件标识及整文件摘要绑定的加密缓存。
读取与写入串行，避免与接收写入/临时文件清理竞态；每块复核会话和删除状态。
HTTP 回退重新授权后读取这些范围，只下载缺块，最终校验原消息整文件摘要。

这些只是认证传输得到的完整分块，不标记为整文件验证成功、不允许离线导出，
也不伪造完成回执。摘要不符仍清除缓存并报错。缓存与 HTTP 自身的完整分块一样，
只有整文件验证完成才能转为持久化完成态。取消/退出账号不续存。

本批接入 UDP→HTTP 方向；HTTP→UDP 的已有分块导入和实际端到端验证仍待完成。

验证：不对齐边界/缺口导出、接收回执、HTTP 下载和续传共 43 项自动测试通过；
修改文件静态检查通过。

新增 udp_http_handoff_test 使用真实接收临时文件、加密缓存、ChatFileDownloader
和模拟认证帧/HTTP 适配器，验证三块文件接收首块后通道中断，HTTP 仅请求索引
1、2，最终逐字节一致且清理临时文件。注入损坏首块时最终摘要拒绝并清空缓存。
两个集成案例通过；这证明应用内交接，不代表真实 UDP 网络或双机验收。

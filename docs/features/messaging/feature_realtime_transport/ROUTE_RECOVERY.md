# 文字通道恢复

实际文字发送入口以当前认证连接对象作为通道代次。新连接建立后，下一条消息
可立即重试设备通道，无需等待旧连接的冷却期；旧连接迟到的结果不能确认新连接
的发送，也不能修改其冷却状态。每个通道代次仍只允许一个探测发送。

同一连接上持续失败的联系人采用 30、60、120 秒冷却，上限 120 秒；冷却期间
继续走现有服务端回退。真实成功回执恢复初始冷却。所有计时使用单调时钟。

这接入现有 MemberRelayText 路径，不代表公网 UDP 直连和跨通道附件续传已完成。

验证：路由恢复及文字发送有效期共 11 项自动测试通过；本批修改文件静态检查通过。

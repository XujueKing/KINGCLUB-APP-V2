# 预览包公网路由配置

2026-09-20

`build-chat-preview.ps1` 新增 `-StunHost` 和 `-StunPort`（默认 3478），传入实际帧通道使用的 Dart 环境常量。仅接受 IPv4 地址或 DNS 主机名，不接受 URL、凭据或端口后缀。必须同时启用原生 NovoRUDP 并配置已认证中继；未配置 STUN 时保持原行为。配置 STUN 后无需单独开启 LAN 开关即可尝试公网候选。

不硬编码第三方服务。运营方需要提供可达 STUN 地址；中继仍用于认证交换和直连失败回退。发现地址不等于连接成功。

验证：PowerShell 语法解析通过；实际脚本拒绝 URL 主机、禁用原生却配置 STUN、仅指定端口三个无效组合，均在构建前终止。此脚本变更尚未生成或安装新 APK。

环境核对：两台 USB 测试机在线并已授权。随后已部署聊天 peer-media-129 增量服务，真实 SQL、Redis、加密 HTTP 群文件及语音元数据授权验证通过，运行时健康检查通过。商城容器和群通话端口保留。待更新手机 APK 并验证媒体真实收发、公网直连与回退恢复，不能将服务部署等同于双机验收。

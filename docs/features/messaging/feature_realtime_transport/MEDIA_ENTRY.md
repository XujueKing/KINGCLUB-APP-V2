# 媒体实际入口

MessagingRepository.open 安装共享 MediaCache 的聊天传输回调。图片预览、语音播放、
视频播放及预取原本均调用该共享缓存，命中本地文件时不进入回调。
回调仅处理相同 API origin/base path、当前会员 scope 下严格限定的聊天媒体 URL。
旧服务缺少新清单字段时沿用原下载；新清单对象不匹配则拒绝，不降级绕过验证。

服务端原媒体授权增加 sender/assetId（已受原消息权限保护），与 fileId/摘要/长度
构成下载引用。媒体片段使用账户安全存储密钥加密，放在缓存自身 private/resume 下，
每个媒体缓存 key 单独目录；成功发布后删除片段。删除取消活动下载，永久删除标记
阻止迟到发布，重启后仍有效；privateOnly 清缓存同样覆盖分块。

验证：共享缓存实际入口六项（单聊/群聊×图/音/视频）与删除中迟到写入测试通过，
合并既有媒体缓存及重启后清除续传分块共 23 项通过。HTTP 和授权替身，磁盘真实；不是手机公网验收。
剩余：发送端所有本地发送键的可用来源、群媒体目录/握手、服务部署及公网联调。

# 发送方原有缓存接入

媒体对端授权可携带服务端读取的 clientMessageId。客户端只接受 UUID，
复核 sameFile 时同时比较它。媒体来源先查消息键，再查确认过的本机发送键；
语音沿用 asset 键。仅限 authority.sender 为当前会员，且会话/授权仍有效。

逐个候选检查大小及 SHA256，避免消息键内的另一编码遮住原发送文件。
不新增媒体副本、不扫描目录、不从网络补下载。缓存被删除或不匹配即返回无来源，
原有接收侧回退继续有效。发送器仍在实际传输前独立验证文件。

验证：28 项媒体来源/授权/请求准备测试通过，相关四文件静态检查通过。
真实临时磁盘验证图、音、视频来源、相同大小坏内容、跨账号拒绝、取消、删除及
文件数量不增加；没有手机公网验收。

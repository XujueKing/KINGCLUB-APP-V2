# 附件接收与回执等待

文件已落盘、摘要校验通过且权限仍有效时，接收端即可把文件交给消费方。
回执发送阻塞不应阻塞本地文件可用状态。发送方仍必须收到真实回执才能确认完成。

每个下载最多保留一个正在发送的回执。传输层阻塞期间不叠加回执任务；完成或
本地 SocketException 后，下一个 DONE 请求可以再次取得当前回执。
部分文件继续受原有进度超时与总期限约束；关闭下载不关闭共享聊天连接。

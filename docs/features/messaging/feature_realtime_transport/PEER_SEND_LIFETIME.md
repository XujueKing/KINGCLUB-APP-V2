# 点对点发送有效期

服务端回退已经开始时，旧设备通道不能继续重发文字。上层已有的
`stillActive` 有效期必须传入 `NearbyTextChannel`，在本地持久化、计算摘要之后，
以及每次发送分片、重传之前检查。失效只结束这一条发送，不关闭共享通道。

保持原消息 ID 和持久化记录；已经上网的包无法撤回，接收端仍按原 ID 去重。
本变更不新增协议字段、不改变加密与好友授权，也不把发送取消标记为已送达。
测试覆盖发送前失效、分片中失效、等待回执时失效，以及共享通道后续发送。

验证：`nearby_text_send_lifetime_test.dart` 与 `adaptive_peer_text_route_test.dart`
共 8 项测试通过；修改的两个 Dart 源文件及新增测试静态检查通过。
这些检查使用本地数据库和模拟帧通道，不代表公网或双机验收已经完成。

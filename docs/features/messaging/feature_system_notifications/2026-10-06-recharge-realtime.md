# 充值到账前台提醒修复

- 现象：APP 停留在前台，充值成功后要进入聊天页才出现账单和角标。
- 原因：线上 `KINGCLUB_MEMBER_BALANCE_REALTIME_ENABLED` 未开启；APP 只有储物袋和聊天前台横幅，没有充值横幅。
- 实现：开启既有余额事件 outbox；复用系统账单列表驱动角标及充值到账横幅，不新建消息表。前台定时补查覆盖所有标签页。首次历史加载不弹横幅，重复事件不重复提示，切换账号清空状态；只有已确认到账的充值通知可触发横幅。
- 点击横幅打开该笔充值详情；仅展示横幅不标记已读。兼容现金、银行码、微信、支付宝充值。
- 本次范围是 APP 前台；不把 WebSocket 当作锁屏系统推送。
- 验证：补充控制器的首次加载、重复事件、未读、账号切换测试，以及银行码账单兼容测试。线上只读检查开关和事件链路，不制造充值或扣款。

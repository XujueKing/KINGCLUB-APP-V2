# 实时通知接入

用户批准立即接通新服务器现有物业 WebSocket 协议。复用业务独立会话及 HKDF/HMAC/AES-GCM 帧协议，域名前缀 /kingclub-v2/ws 代理至服务 /ws；不与物业账号或频道混用。

全 App 单连接，安全会话变更立即重建，后台断开、前台恢复，心跳和指数退避，验签/序号/去重。核销提交后推送失效事件，页面通过真实接口重新查询，不把消息视为库存凭证。断线恢复重新同步储物，定时换码保留。

前台提示点击按白名单目标进入储物详情，重新检查会话及权限；已核销详情可读，不签新码。系统离线推送平台凭据仍待核对，当前不将 WebSocket 宣称为锁屏推送，也不将模拟聊天宣称为真实IM。

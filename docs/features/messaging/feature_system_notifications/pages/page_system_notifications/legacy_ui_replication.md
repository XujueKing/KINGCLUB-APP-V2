# 旧版系统消息 UI 复刻规范

- 文档状态：`Approved for Development（仅 UI / Fake）`
- 旧版来源：`KingClub-app/pages/sysmessage/sysmessage.wxml|wxss`
- 确认日期：2026-08-27

## 视觉结构

- 页面背景沿用旧版近黑红色 `#0e090c`，顶部居中标题“系统消息”，左侧使用旧版返回图标。
- 通知采用宽卡片纵向排列，卡片为低透明白色、8px 圆角；卡头显示圆形品牌/类别图标和来源名称。
- 卡片正文保持“标题—突出结果—明细键值”的旧版结构，时间独立置于卡片下方居中显示。
- 资产、订单和平台通知均使用纯 Fake 数据；不得显示手机号、实名、真实订单号或可执行支付入口。

## Fake 交互

- 点击卡片展开/收起明细并在本地标记已读。
- “全部已读”仅改变当前内存状态，不删除通知、不请求服务器。
- 页面同时提供空态和离线只读演示入口，便于整 App UI 验收。

## 验收基线

- 黑红背景、顶部栏、卡片宽度、圆角、留白和文字层级与旧版一致。
- 卡片展开、单条已读、全部已读、空态和离线态均可重复演示。
- 不接真实通知、推送、WebSocket、订单或资产接口。

# 搜索结果跟随本地历史清空

搜索页此前监听单条 ChatMediaDeletion 和实时网络通知，但未监听同账号历史库的 clearedConversations。远端搜索结果未下载为本地消息时，清空历史不一定产生这些消息的逐条删除事件，导致当前结果或正在查询的旧响应可能继续显示。

现绑定同账号历史库，按 localConversation 匹配删除事件。整段清空立即清除结果、输入及类型筛选，并递增查询代次拒绝迟到响应；用户可以重新发起查询。部分删除保留序号屏蔽集合和 hiddenThrough 边界，后续查询也不再展示对应结果。无关会话不受影响，页面退出取消订阅；等待历史监听建立后才开始查询。

16 项搜索页、本地 SQLite 搜索、取消扫描和历史删除事件测试通过，两个文件静态检查通过。新增单聊/群聊组件测试覆盖未落盘结果、无实时通知的整段清空、迟到响应、再次查询、部分删除和退出后的事件；不是手机实测。未改变待发队列策略。本节点尚未构建或安装 A/B。

# 文件回退时停止远端发送

接收端关闭、超时或放弃 peer 下载时，过去只关闭本地 receiver，发送端仍可能继续发送和等待 ACK。现在通过已有认证通道发出 cancel，精确匹配传输对象、消息、媒体种类及通道已有群范围后取消远端 sender。取消发生在权限查询或本地源恢复期间，迟到结果也不能启动传输。

保留最多 64 个当前通道内取消标识，忽略旧 REQUEST 重试；新传输对象仍可使用同一连接。成功接收不发送 cancel，共享聊天连接不关闭，原有分块保存、摘要校验和权限校验保持不变。通知是有界尽力发送；通道断开或旧客户端不支持时，仍由发送端已有超时退出，不能保证远端即时收到取消。

验证包括准备顺序、作用域错误取消、延迟授权/源恢复、旧请求不能重启、真实加密 UDP 传输取消后复用连接重新下载，以及既有丢包恢复回归。实际公网大图速度和中途断线接续仍是后续工作；本项不等于公网 UDP 已打通。

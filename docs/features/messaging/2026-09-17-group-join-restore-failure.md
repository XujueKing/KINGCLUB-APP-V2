# 入群申请恢复失败不再视作未申请

发现 GroupJoinRequestPage 吞掉 savedJoinApplication 读取异常后，会解除恢复状态并开放提交；GroupJoinReceiptStore 也会将非空的无效申请编号视为不存在。已有申请时，这会诱导用户提交新的申请，而不是核查原申请。

现在非空无效编号抛出格式错误；恢复读取失败展示“无法读取上次入群申请，请重试”和重试读取按钮，暂停提交。恢复成功后按现有申请编号查询状态，不自动重新提交，也不将本地回执当作入群权限。保持原有正常流程和确认样式。

17 项申请恢复、提交和撤回测试通过，三个文件静态分析通过。新增安全存储受控用例覆盖损坏 JSON、无效申请编号，确认失败时提交不可用；恢复有效回执后只读取原 pending 申请，提交次数始终为零。没有修改真实会员关系或手机存储，不代表设备 KeyStore 故障或实际入群审核已实测。尚未打包安装，A 仍为 26aa51c，B 未操作。

# A 关系分组真机验收

使用当前 A Profile 包（包含 bfea129），只操作已授权 A/B 测试会员之间的关系分组。初始“我的关系”为空。

1. 新建 `AB-TEST`，选择第三个“好友”图标，仅勾选 B，保存后返回列表显示 1 人。
2. 返回通讯录，实际截图确认 B 姓名、性别之后出现所选关系图标，其他联系人未出现该图标。
3. 退出分组页面后重新打开，分组仍为 1 人。进入编辑页，名称保留、第三个图标选中、B 勾选，另一联系人未勾选。
4. 点击删除并在“仅删除这个关系分组，好友和聊天记录会保留”弹窗确认。列表恢复为空，返回通讯录 B 仍存在。

这是实际手机界面和真实接口保存/重新读取证据，不是 Mock；本次未修改源代码、未操作 B 手机，也未改变其他会员关系。私有截图与 UI 层级保留在本机 build/phone-a-relations-*，不提交仓库。

覆盖创建、图标、成员选择、列表联动、退出重进和删除。重命名、跨分组移动、多设备同时编辑及网络中断保存尚不计作真机验收完成。

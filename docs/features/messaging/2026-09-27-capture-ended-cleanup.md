# 通话采集结束收尾

双人通话订阅本地轨道的 `onEnded`，收到终止事件后关闭媒体并向通话状态机报告 Closed，避免误走网络失败的 ICE 恢复等待。释放轨道前移除回调，重复事件只收尾一次。

群通话通过 mediasoup producer 的 `trackended` 事件进入既有错误收尾，保留 SDK 对轨道事件的所有权；由群通话会话释放服务端席位。普通静音、进入后台和锁屏不属于此终止事件。

验证：两项新增回归覆盖采集终止、重复回调、单次释放；连同双人媒体会话、通话状态机、群通话会话共 72 项测试通过，四个变更 Dart 文件静态分析通过。

限制：这是对 SDK 已上报轨道结束事件的处理，不代表所有 Android 撤销权限路径都会上报。系统直接回收进程及实机权限撤销仍待验收。本增量尚未安装到 A/B，不能归入先前锁屏通话通过的版本。

用户本次回复“锁屏后双方仍能听到”，确认的是已建立群语音的锁屏持续通话，与既有 `2026-09-27-group-call-ab-acceptance.md` 记录一致；不据此扩展为锁屏新来电或断网声音恢复验收。

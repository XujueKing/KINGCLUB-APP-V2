# 文件通道取消与截止时间

已确认：聊天附件仍走 CCSOP 上传引用流程；底层 NovoRUDP 文件发送器支持真实加密 UDP 和 SUPERVM 中继，但尚未连接聊天附件消息的协商、持久化与回退流程。

本节点修复发送器的退出边界：以前取消只唤醒 ACK 等待，等待 `link.send` 或退避暂停时仍可能滞留。现在取消、账号事件、连接错误及整体截止时间都能中断网络等待和暂停，释放发送端文件句柄、修复计划和订阅，不关闭共享聊天通道。已经交给底层的单个帧无法撤回，迟到完成/错误不继续发送后续帧。

验证：

- `novorudp_file_sender_test.dart` 使用真实原生库和加密 UDP，9 项通过。18MiB 文件在主动丢包条件下传输 85.989 秒，25,484 个包中丢弃 3,595 个，最终字节一致。这是受损回环测试，不是手机或公网速度指标。
- 新增 3 项等待中的传输测试，分别验证取消、账号切换、截止时间；确认源文件可重命名、共享连接未关闭、迟到错误不再发帧。等待中的发送使用可控替身，密码会话使用真实原生库。
- `supervm_relay_file_test.dart` 对当前真实 WSS 节点传输 262,161 字节，故意丢弃最终回执仍恢复并通过摘要/字节核验，1 项通过。
- 修改的实现和测试文件静态分析通过。未为这一底层变更重新安装手机；聊天媒体直传仍未交付。

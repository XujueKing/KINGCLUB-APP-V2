# 文件草稿后台校验

ChatFileDraftStore 原先在 UI isolate 逐块计算 SHA-256，恢复时每块还读取登录安全存储。大文件会反复占用界面线程。现把文件路径、预期大小传给独立 isolate 做流式校验，不把会话存储、页面对象或整文件字节传过去。主 isolate 在校验前后验证会话，校验失败或会话变化不发布/返回有效草稿。

保存阶段仍逐块复制并验证会话，写入关闭后由后台校验实际草稿文件，再发布安全存储中的元数据。这样多一次顺序磁盘读取，换取散列计算不占用界面线程，并校验最终落盘内容；没有宣称总保存耗时缩短。后台校验开始后会完成当前文件读取，结果仍必须通过会话复核才能使用。

草稿、发送恢复和发送会话失效相关 11 项测试通过；补充同长度尾字节篡改拒绝后，3 项草稿测试再次通过；两个文件静态检查通过。已有缩短文件损坏、重建读取、账号/目标隔离、过期孤儿清理和复制时会话失效回归保留。未以测试代替 Android 大文件帧率或耗时测量。尚未构建安装；A 为 26aa51c，B 未操作。

# 重连成功后立即唤醒发送队列

之前 SuperVM WSS 重连成功没有向发送队列发出就绪通知。未打开的会话依赖 15 秒轮询，当前私聊页面则依赖其他同步事件；网络已恢复时仍可能延迟补发。

现在已鉴权的连接就绪事件按会员和登录代次过滤，立即唤醒前台后台队列以及当前私聊的 queued 消息。后台队列继续遵守可见会话的所有权，不与页面争用；发送仍使用原消息 ID 和已有发送互斥机制。关闭页面、停止队列或切换登录时取消对应监听。原有定时重试作为兜底保留。

不把连接恢复视为消息送达，不跳过服务端权限校验，也不自动重发永久失败的消息。此次不新增系统后台保活或推送，不代表锁屏后台仍能维持传输。

验证：新增两项回归分别覆盖当前私聊、未打开会话在离线排队后收到恢复事件立即发送，连续恢复事件不会重复发送，销毁后不再消费事件。结合队列恢复、中继重连退避、账号切换和自适应发送测试，共 26 项通过。尚未进行此版本双机网络切换验收。

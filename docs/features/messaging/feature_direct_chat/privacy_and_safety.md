# 单聊隐私与安全

- 消息正文、媒体 URL、草稿、备注、ConversationRef、MessageRef 和 ShareIntentRef 不进入日志、埋点、路由、崩溃 breadcrumbs 或系统通知正文。
- 锁屏推送固定为“你收到一条新消息”，除非未来单独批准隐私设置。
- 缓存按账号/会话世代加密隔离；登出、顶号、账号切换时清除密钥与内存草稿。
- 媒体使用受控选择器和 intent/upload/commit；上传地址不得含账号、Authorization 或可长期复用签名。
- 图片/视频预览不自动下载原件；后台时聊天页面使用隐私快照策略。
- 复制只允许纯文本消息且需用户明确操作；复制内容属于系统剪贴板，UI 给出短提示。
- 消息权限由服务端逐命令校验，好友状态/allowedActions 只作 UI 约束。

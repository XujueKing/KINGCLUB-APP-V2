# 旧版联系人选择 UI 复刻规范

- 文档状态：`Approved for Development（仅 UI / Fake）`
- 旧版来源：`KingClub-app/pages/chat_more_select/chat_more_select.wxml|wxss`
- 确认日期：2026-08-27

## 视觉结构

- 顶部左返回、中间“选择联系人”，右侧显示排序方式。
- 顶部搜索区为低透明金色圆角条；联系人行使用低透明金色背景、圆形单选框、方形圆角头像和白色昵称。
- 本期遵循已批准契约改为单选；底部按钮显示“转发(1)”，未选择时禁用。
- 头像缺省使用旧版 `touxiang.png`，不使用真实用户头像、账号或手机号。

## Fake 交互

- 支持按备注/昵称本地搜索、最近聊天/首字母排序和单选。
- 点击底部按钮先打开发送确认层，展示目标昵称与清洗后的消息摘要；确认后返回单聊并显示成功结果。
- 取消、搜索空态、目标失效和分享过期均为可重复 Fake 状态。

## 验收基线

- 顶栏、搜索条、联系人行、头像、单选框和底部按钮符合旧版视觉。
- 搜索、排序、选择、确认、取消和返回路径完整，不支持多选或群发。

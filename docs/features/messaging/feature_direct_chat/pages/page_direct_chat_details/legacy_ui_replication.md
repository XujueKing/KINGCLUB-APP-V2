# 旧版聊天详情 UI 复刻规范

- 文档状态：`Approved for Development（仅 UI / Fake）`
- 旧版来源：`KingClub-app/pages/chat_more/chat_more.wxml|wxss`
- 确认日期：2026-08-27

## 视觉结构

- 顶部使用旧版浅金黑色栏，左返回、中间“聊天详情”。
- 第一组为好友头像与昵称；之后按旧版低透明金色分组依次展示“查找聊天内容”“消息免打扰”“置顶聊天”“关系权限”。
- “清空聊天记录”单独成组并居中显示；删除群管理、群二维码、群公告、聊天背景和退出群聊。
- 开关沿用旧版绿色开启态和深色关闭态，行高、分隔线和左右留白按旧版比例。

## Fake 交互

- 免打扰与置顶只修改当前页面内存状态。
- 搜索在本页展开，按 Fake 消息正文过滤；退出后恢复设置页。
- 关系权限进入已完成的关系权限页；清空记录必须二次确认，只影响 Fake 历史。

## 验收基线

- 分组背景、列表行、头像、开关和破坏性操作符合旧版页面结构。
- 搜索、两个开关、关系权限、清空确认和返回路径全部可用。

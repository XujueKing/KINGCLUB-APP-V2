## 用户任务与线框

查看单聊历史，可靠发送文本、图片、短视频、引用或批准的分享内容，并理解每条消息的发送状态。

```text
[返回]         好友备注 / 公开昵称            [详情]
          [你已添加了对方，现在可以开始聊天了]

[对方] 文本消息
              [我] 图片缩略图          已读
[撤回了一条消息]
[我] 发送失败                              [重试]

[引用：好友 · 原消息摘要]
[＋] [输入消息____________________] [发送]
```

- 头像/标题进入用户主页，详情按钮进入 KC-P-025。
- 首次好友单聊先显示本地系统提醒，消息按微信式时间顺序从顶部向下排列；仅在内容超过视口时滚动到底部。
- “＋”首屏按旧版提供照片、拍照、金币和红包；短视频与已批准业务卡片保留在第二页。输入栏礼物入口打开旧版礼物商城 Mock；无文件或位置。
- 图片和短视频必须显示真实本地 Mock 缩略图，不得以“[Fake 图片]”文字占位；点击缩略图可查看大图/视频静态预览。
- 长按文字消息提供复制、引用、转发、为我删除；本人消息额外提供撤回。删除和撤回必须二次确认。
- 引用进入独立引用草稿条，可单独关闭；发出后在消息气泡内显示被引用内容摘要。
- 关系结束时保留历史只读并禁用输入；不把错误伪装成“对方拒收”。
- 200% 字体下消息气泡限制最大宽度但可纵向扩展；状态和失败动作可由读屏理解。

## 微信式流畅度基线（2026-08-28）

- 点击输入框时立即收起附件面板；点击“＋”打开附件面板时先收起键盘，两者不叠加抢占消息区。
- 键盘完全弹出后再滚动到最新消息，避免跟随键盘动画反复跳动。
- 自己发送文本或附件后立即追加本地气泡，并用短时平滑滚动到最新消息；网络/Fake 完成只更新原气泡状态，不重复插入。
- 消息列表拖动时允许自然收起键盘；长列表继续使用惰性构建和重绘隔离，不因输入内容变化重绘全部气泡。
- 键盘回车键使用“发送”语义；空白内容不发送，发送后输入框立即清空并保持输入焦点。
- 输入框聚焦时保持无描边深色胶囊，不出现系统主题的高亮粗边框；有内容时发送按钮切换为微信式绿色实心按钮。
- 时间与好友建立提醒继续弱化，但在黑底上必须保持可辨认，不能因灰度过低近似消失。
- 长文本和无空格文本必须在气泡最大宽度内自然换行；输入框最多增长到四行，不能挤压或遮挡发送按钮。
- 连续发送至少十条本地 Fake 消息时，每条先插入一次且保持顺序，最终自动停在最新消息，输入焦点不丢失。

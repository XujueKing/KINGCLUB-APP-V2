## 用户任务与线框

查看单聊历史，可靠发送文本、图片、短视频、引用或批准的分享内容，并理解每条消息的发送状态。

```text
[返回]         好友备注 / 公开昵称            [详情]
          [你已添加了对方，现在可以开始聊天了]

[对方] 文本消息
              [我] 图片缩略图          已读
[撤回了一条消息]
[我] 发送失败                              [重试]

[引用：好友 · 原消息摘要]
[＋] [输入消息____________________] [发送]
```

- 头像/标题进入用户主页，详情按钮进入 KC-P-025。
- 首次好友单聊先显示本地系统提醒，消息按微信式时间顺序从顶部向下排列；仅在内容超过视口时滚动到底部。
- “＋”只提供图片、短视频和已批准业务卡片；无红包、金币、礼物、文件或位置。
- 图片和短视频必须显示真实本地 Mock 缩略图，不得以“[Fake 图片]”文字占位；点击缩略图可查看大图/视频静态预览。
- 长按文字消息提供复制、引用、转发、为我删除；本人消息额外提供撤回。删除和撤回必须二次确认。
- 引用进入独立引用草稿条，可单独关闭；发出后在消息气泡内显示被引用内容摘要。
- 关系结束时保留历史只读并禁用输入；不把错误伪装成“对方拒收”。
- 200% 字体下消息气泡限制最大宽度但可纵向扩展；状态和失败动作可由读屏理解。

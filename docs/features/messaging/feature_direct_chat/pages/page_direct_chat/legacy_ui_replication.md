# 旧版单聊 UI 复刻规范

- 文档状态：`Approved for Development（仅 UI / Fake）`
- 旧版来源：`KingClub-app/pages/chat/chat.wxml|wxss`
- 确认日期：2026-08-27

## 视觉结构

- 纯黑背景，顶部固定栏左侧旧版返回图标、中间好友备注、右侧三点详情按钮，下方细金色分隔线。
- 消息区保留旧版头像与气泡布局：对方左侧金色半透明气泡，本人右侧绿色气泡；时间与系统提示居中灰显。
- **已确认事实（2026-08-27）**：消息流采用微信式从上到下排列，不使用反向列表把少量消息挤到页面底部。
- 新建立好友关系并首次进入单聊时，时间下方先显示“你已添加了对方，现在可以开始聊天了。”系统提醒，随后才显示双方消息。
- 底部输入区使用深棕黑圆角面板，包含“＋”、文本输入和发送按钮；展开附件区只保留图片、短视频和业务卡片三项。
- 不复刻旧版红包、金币、礼物、群聊申请及其他已移出本期的入口。

## Fake 交互

- 可发送本地文本并显示发送中、已发送和失败重试演示。
- 新消息追加到现有消息末尾，内容超出可视区域后自动滚动到最新消息；消息较少时保持在顶部自然排列。
- 可展开附件面板，点击附件生成对应 Fake 消息；长按消息显示引用、转发、为我删除和撤回允许项。
- 图片、短视频和业务卡片按旧版消息类型显示独立视觉内容，不使用方括号文字占位；媒体点击后显示本地 Fake 预览。
- 文字消息长按可复制；引用以输入区上方摘要条呈现；删除和撤回需要明确确认。
- 点击右上角进入单聊详情；转发进入联系人选择；不连接真实媒体、WebSocket 或推送。

## 验收基线

- 顶栏、左右气泡、头像、时间提示和底部输入面板符合旧版视觉比例。
- 好友建立提醒和后续消息按微信式时间顺序从顶部向下展示，首屏不得出现大面积空白后才显示消息。
- 文本发送、失败重试、附件、引用、转发和返回路径可演示。
- 图片/短视频缩略图、全屏预览、引用草稿、复制反馈、删除确认和撤回确认均可离线演示。
- 关系结束 Fake 状态保留历史并禁用输入。

# 返回键统一验收（2026-08-30）

## 问题

聊天与通讯录沿用了 `25 × 50` 的旧版返回图片，部分页面只限制宽度，导致箭头实际显示高度达到约 `44–48 px`；另有页面把该图片强制拉伸为正方形。全 App 的 Material 返回图标也存在 `20–25 px` 的尺寸差异。

## 统一规范

- 点击区域：`48 × 48 px`
- 可见箭头高度：`22 px`
- 旧版窄箭头按原比例显示：`11 × 22 px`
- 返回键、页面标题与右侧操作位于同一条垂直中心线

## 覆盖范围

- 聊天共享顶部栏：私聊、聊天详情、联系人选择、系统通知
- 通讯录及好友关系页面
- 登录、会员申请、点单、组局、储物柜、个人设置等使用返回箭头的页面

## 验收结果

聊天页截图见 [01-direct-chat-header.png](./01-direct-chat-header.png)。返回箭头比例正常，与标题中线对齐；组件测试与相关流程测试通过。

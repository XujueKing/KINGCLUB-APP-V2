# 单聊任务流验收（2026-08-28）

## 范围

聊天列表 → 卡座搭子单聊 → 输入聚焦 → 输入内容 → 收起键盘 → 附件面板。

## 截图步骤与健康度

1. `01-chat-list.png`：聊天列表，基本健康。
2. `02-chat-idle.png`：单聊空闲态，基本健康；时间与好友建立提醒对比度偏低。
3. `03-keyboard.png`：输入聚焦态，需要修正；输入框出现不属于目标样式的粗金色边框。
4. `04-composer-filled.png`：输入内容态，模拟器输入法表层进入异常浮动显示；该截图只用于记录平台输入法现象，不作为 App 排版证据。
5. `05-keyboard-dismissed.png`：收起键盘后内容保留，基本健康；启用发送按钮缺少微信式明确状态。
6. `06-attachments.png`：附件面板，基本健康；图片、短视频和业务卡片入口清楚，输入内容得以保留。
7. `07-polished-composer.png`：修正后的输入态，健康；聚焦粗边框已移除，输入内容后显示固定尺寸微信绿发送按钮。
8. `08-chat-stress-start.png`：压力验收起点，健康；固定顶栏、消息区和输入区均完整。
9. `11-long-unbroken-draft.png`：四行以内长连续字符草稿，健康；输入区纵向增长，附件和发送按钮没有被挤出。
10. `12-long-sent-recovered.png`：长连续字符发送结果，健康；本人气泡在最大宽度内换行，头像、底栏和顶栏稳定。

## 本轮最高优先级修正

- P1：固定输入框聚焦视觉，禁止系统主题自动添加粗描边。
- P1：输入有效文字后显示固定尺寸微信绿实心“发送”，增强操作反馈且避免布局横跳。
- P2：提高时间和好友建立提醒的最低对比度，仍保持次级层级。

以上三项已在同轮完成并通过 Android 预览复核。

## 压力验证

- 180 个连续中文字符：输入框保持 `maxLines=4`，发送后气泡宽度未超过设计上限且无布局异常。
- 连续发送 10 条消息：每次新增消息仅出现一次，最后一条保持可见，输入焦点继续留在当前会话。
- Android 预览中的长连续字符已通过 `11-long-unbroken-draft.png` 与 `12-long-sent-recovered.png` 复核。
- `09-long-draft.png` 与 `10-long-sent.png` 记录的是 ADB 输入法表层异常，不作为 App 视觉验收证据。

## 证据限制

- Android 模拟器当前输入法存在浮动工具栏/窗口表层异常，无法凭截图确认真实手机软键盘外观。
- 本轮 ADB 仅发现 `emulator-5554`，未发现实体安卓手机，因此真机输入法切换仍为待补证据。
- 截图能检查视觉和可见状态，但不能证明完整无障碍合规；读屏顺序、动态字体与真机键盘仍需专项测试。

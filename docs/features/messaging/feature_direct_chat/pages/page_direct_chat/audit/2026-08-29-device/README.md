# 单聊实体机验收（2026-08-29）

## 环境

- 设备：Xiaomi 14 Pro（1080×2400）
- 连接：USB ADB，设备状态 `device`
- 包名：`com.lingmei.kingclub.v2preview`
- 构建：Flutter Preview Debug，离线 UI Mock，初始路由 `/home`
- 未接入真实超级接口、WebSocket、支付、推送或其他生产 SDK

## 验收路径与结果

1. `03-app-shell.png`：从 Mock 首页进入消息模块，健康。
2. `04-chat-list.png`：通讯录切换至聊天列表，健康；置顶会话与好友会话可见。
3. `05-direct-chat-idle.png`：进入“卡座搭子”单聊，健康；顶栏、消息流和输入区完整。
4. `06-direct-chat-keyboard.png`：点击输入框后真机软键盘弹出，健康；顶栏保持固定，消息区未被键盘遮挡。
5. `07-chat-draft.png`：普通草稿输入，健康；输入框保持焦点，发送按钮显示启用态。
6. `08-chat-sent.png`：普通消息发送，健康；消息仅插入一次、输入框清空且软键盘保留。
7. `09-chat-long-draft.png`：120 个连续字符草稿，健康；输入框纵向增长但不挤出附件与发送按钮。
8. `10-chat-long-sent.png`：超长连续字符发送，健康；本人气泡在最大宽度内自动换行，无横向溢出。
9. `11-chat-attachments.png`：键盘打开时切换附件面板，健康；软键盘关闭，图片、短视频和业务卡片入口完整。
10. `12-chat-burst.png`：连续发送 10 条本地消息，健康；顺序正确，最后一条保持可见，输入焦点保留。

## 结论

- 单聊核心输入与发送流程已通过实体安卓手机验收。
- 真机键盘、附件面板、长消息和连续发送均未出现遮挡、横向溢出或消息挤在底部的问题。
- 当前阶段仍只批准 UI Mock；本结果不代表真实 WebSocket、离线补偿、推送或服务端消息一致性通过。

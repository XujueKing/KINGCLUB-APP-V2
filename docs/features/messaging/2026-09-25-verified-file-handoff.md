# 已校验附件的完成交接

接收端已收到全部内容、通过摘要校验后，最终 ACK 的发送失败或连接关闭仍会触发下载对象清理。消费者拿到的 File 可能已经被删除；同步 ACK 异常甚至会把已校验完成的下载变成失败。

修复将完成通知放在最终 ACK 之前。完成后的纯传输故障不再主动删除文件，文件由消费者复制到缓存后显式关闭；账号退出、权限失效和显式取消仍使用原清理路径。未完成下载的故障处理和分块保留规则不变。

三个新增回归分别复现同步 ACK 异常、异步 ACK 异常、完成后连接关闭。旧实现三个均失败，修复后均通过，并验证 owner.close 后临时文件确实删除。该修复作用于共享附件接收器，涵盖使用此接收器的文件、图片、语音和视频。

此处为代码和本机测试结论，不代表已经完成 A/B 公网附件验收或解决跨网络打洞。

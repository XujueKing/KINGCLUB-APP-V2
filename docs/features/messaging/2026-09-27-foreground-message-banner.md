# 前台 K聊 消息横幅（2026-09-27）

用户要求参照旧小程序：前台其他页面有消息提醒，正在看的会话不提示。只读对照旧仓 components/message-modal（K聊、您收到一条新消息、点击进对应会话、圆角顶部卡片）和 app.js openMessage（5 秒自动收起）。新版此前仅有储物核销横幅，并无普通聊天横幅；前台推送抑制不能替代该 UI。

新增全局站内横幅，覆盖首页/其他栏目/聊天列表；收到 chat.changed 或 chat.group.message 后读取已授权且应用本地已读水位的会话列表，分页寻找目标，过滤已读、免打扰、自己发送和重复序号。正在显示对应会话时不展示；手动打开该会话也收起已有横幅。点击前再次检查账号/会话，复用当前路由，不破坏草稿。切后台、切换账号取消横幅及迟到请求；通话展示期间不抢占。文本沿用旧版通用提示，不展示聊天正文。

横幅 260ms 顶部滑入、5 秒收起，可手动关闭。不是 Android 系统通知、不调用 OPPO、不消耗厂商额度。断线重连仅同步未读，不把 connection.ready 当成新消息弹横幅。

验证：27 项提醒解析、账号/后台隔离、路由去重和原推送恢复测试通过；5 个相关文件 analyze 无问题。实机安装/提醒证据见下方后续记录。消息正文和私有设备转储不提交。

边界：此版横幅由 CCSOP 实时消息事件触发；纯 SuperVM 离线于 CCSOP 的接收尚未另接横幅，不能把此节点宣称为所有传输路径完整验收。

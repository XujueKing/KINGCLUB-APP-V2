# 视频源一致性

视频硬件压缩后，在后台 isolate 创建私有容器清理副本，保持音视频包和位置不变；不修改相册原件和草稿。小视频同样清理。上传及发送方持久化使用该副本，转发先校验原授权文件再清理、校验实际上传副本；入队后或页面关闭清理临时文件。恢复已入队草稿不得覆盖已有媒体缓存。

支持普通 MP4 的 H.264/HEVC、可选单 AAC 音轨；未知结构保持既有服务端处理。服务端对尺寸、码率、帧率、方向等合规且容器已清理的 H.264 完整解码验证后保留原字节。HEVC 保留原版本并生成 H.264 兼容文件，不混淆两个文件哈希。封面独立生成。

验证：容器/优化/转发21项（后增HEVC黄金1项）、发送生命周期5项、静态分析通过。两端使用合成 H.264/HEVC 黄金文件比对。后台真实 FFmpeg 覆盖完整字节相同、损坏拒绝、旋转、静音/有声、封面、HEVC兼容码率预算。实机及公网验收尚待记录，不能据此宣称全部视频跨公网直连。

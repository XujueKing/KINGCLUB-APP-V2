# 添加朋友搜索与全屏扫一扫

- 添加朋友搜索直接复用聊天列表 LegacyConversationSearch 的尺寸、底色、圆角、搜索图标和清除按钮；键盘搜索键提交账号/手机号查询。
- 查询期间、结果及错误状态隐藏固定功能菜单；清空搜索恢复菜单，清除旧结果并使旧请求失效。
- 真实 MemberScannerPage 删除 AppBar，预览 BoxFit.cover 铺满屏幕，返回按钮悬浮在安全区内；底部为透明渐变操作区。
- 闪光灯跟随实际 TorchState，有无硬件及相机运行状态决定是否可点。
- 相册使用系统图片选择器、本地 analyzeImage 识码，再复用既有桌卡/个人/群二维码校验和跳转。取消选图恢复扫描；无二维码及权限错误提供重试。相册生命周期不会误判为账号变化，真正的账号变化仍取消结果。

验证：搜索菜单切换、全屏预览布局、闪光灯调用、选图识别及重新扫描、已有二维码路由和顶部角标共 9 项测试通过；真机灯光和照片识别效果需安装后检查。

# 文件本地读取提示

此前离线读取自己的持久化文件也显示“下载完成”，失败一律提示网络问题。读取器现在仅在完整下载缓存或发送源库恢复并校验通过时标记本地来源；新的读取操作重置标记，网络/直连分支不标为本地。

文件详情入口采用“读取文件/重试读取”，处理中可“取消读取”。成功时本地分支显示“已从本地读取，文件校验通过”，网络分支保留下载完成提示。失败用“文件读取未完成，请重试”，不将磁盘或会话错误错误归因于网络。布局、发送和授权逻辑不变。

验证：读取器真实缓存用例检查本地来源标记，页面测试覆盖本地/下载提示及删除后提示移除；两个测试文件 35 项通过，4 个文件静态分析通过。本修复尚未安装手机。

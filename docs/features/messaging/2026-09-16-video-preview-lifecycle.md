# 发送视频页预览生命周期

修复发送视频页缺少后台暂停的问题。离开前台时暂停预览，回前台不自动播放；登录状态变化同样安全暂停。点击播放期间收到后台或发送状态变化，原生迟到的播放完成后再次暂停，避免恢复出声。

压缩和上传期间禁止点击预览重新开始播放，减少与转码并行使用解码器。播放/暂停异步错误由页面处理，不产生未处理 Future；不改变已有布局或上传、草稿重试规则。

验证：发送页4项生命周期测试通过，包含延迟play完成、后台/前台、上传期间点击、会话变化和离页；优化器10项测试通过。定向静态检查通过。本次代码尚未安装手机，后台无声仍需真机验证；不把模拟播放器测试当作设备听感验收。

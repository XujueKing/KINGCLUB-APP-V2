# 新朋友申请本地持久化

用户要求聊天相关列表本地持久化、进入页面不等待联网。当前真实新朋友页面只保存内存列表，本轮补齐账号隔离的加密 SQLite 快照。

设计：数据库新增申请快照表，只在完整分页成功后替换；旧请求不得覆盖较新快照。持久化申请标识、双方账号、昵称、备注、日期、处理状态，不保存头像访问令牌。页面先恢复只读缓存，同时联网刷新；迟到缓存不能覆盖联网结果，退出登录立即清除页面并拒绝迟到响应。缓存不赋予接受/拒绝权限，操作必须收到服务端结果。网络失败保留已有列表，首次无缓存继续显示错误；主动刷新提供失败反馈。

验证门槛：加密磁盘重开、空快照、旧响应拒绝、缓存与联网竞争、退出登录竞争和现有真实申请流程回归。代码通过不等于已安装双机验收。

已实现 SQLite v24 增量升级，保留既有聊天表。快照恢复与网络并行，磁盘写入不阻塞申请事件刷新。仅缓存期间禁止操作申请；联网成功后恢复既有接受/拒绝流程。自动断网保留列表，主动下拉刷新报告失败。头像访问凭据不入库。

验证结果：friend_request_cache、real_friend_requests、contact_snapshot、chat_history_store、group_chat_history 共 99 项通过；最后增加只读缓存点击断言后，两个申请页面测试文件 6 项再次通过。5 个修改代码/测试文件 analyze 无问题，git diff --check 通过。安装包与双机重启验证待后续集中执行；不将已有手机版视为包含本次修改。

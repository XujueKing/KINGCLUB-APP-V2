# 私聊设置保存确认与登录变化

核查发现私聊详情页未校验 settings 返回的 saved，保存未确认也可能更新免打扰/置顶/仅聊天 UI；确认清空弹窗和异步保存期间没有监听登录变化。群详情已有相应保护，本次补齐私聊入口。

真实设置与清空只有收到 saved=true 才更新状态、通知上层或退出页面；失败保留当前页并允许重试。清空确认期间与写入期间共用保存锁，防止重复弹窗或与开关保存并发。收到 SecureSessionStore.changes 后隐藏旧资料与搜索结果，禁止继续操作；迟到结果不更新 UI、不通知父页、不关闭新状态页面。已发到服务端的请求仍由既有鉴权控制，本次不声称撤销已提交事务。

自动化使用真实组件和延迟响应，覆盖未确认保存不改变开关、重试成功、弹窗期间登录变化不发送清空、保存期间登录变化拒绝迟到回调、清空失败保留页面并可重试。连同头像及免打扰既有测试共 7 项通过。没有删除任何真实聊天数据或更改真实会员设置；尚未合入手机安装包，等待下一次集中安装。

# 群通话恢复期间的自动心跳提示

代码核查发现自动心跳的 NETWORK_ERROR 和 CHAT_GROUP_CALL_VERSION_CONFLICT 会调用页面 onError；页面把错误字符串持续保留，恢复后没有对应清除。因此一次可恢复的心跳失败可能留下永久失败横幅。

仅自动心跳过滤上述两类可恢复错误：网络终止由媒体既有的有限恢复期限处理；版本冲突由控制器刷新快照，后续心跳继续。没有过滤用户发起的操作失败、其他错误或媒体最终失败，也没有放宽会话权限。新增测试覆盖两类可恢复错误、未知错误仍上报，以及下一次成功心跳清除控制器错误。

会话、控制器、原生群媒体及页面测试共 47 项通过；两处修改文件 analyze 通过。此增量尚未安装手机，A/B 仍为 AA6C0241443FBF4FD7B5EE80E84C834445D4F8D59BDCE98BC121AE5A9E86634F 的 profile 包。不扩大已有声音/视频及离线推送验收结论。

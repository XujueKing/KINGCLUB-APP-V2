# 会话列表

- Scope ID：`KC-F-019`
- 文档状态：`Approved for Development`
- 所属业务域：`messaging`
- M0 范围：`In Release Scope`
- 设计版本：`Conversations v1`
- 最后更新：2026-08-25

## 目标与用户价值

让会员查看稳定单聊、未读状态和系统通知入口，并在消息与通讯录之间快速切换。

## 已确认事实

- 旧版在 `index` 同一 swiper 中混合会话、通讯录、动态 tab、系统消息和群聊。
- 旧会话摘要会同时拼接服务端结果与本地 `messagesDataBase`，可能出现预览和未读不一致。
- 旧列表支持置顶、免打扰、隐藏和删除，但数字菜单语义及本地删除边界不清晰。
- 本期保留稳定单聊，完整群聊、红包和金币转赠已移出。

## 当前建议

- 消息分支根固定为“消息/通讯录”切换；会话列表只显示系统通知入口和一对一会话。
- 置顶与免打扰在单聊详情设置；列表滑动只提供“标记已读/未读”和“从列表隐藏”。
- 隐藏不删除历史；新消息到达后会话重新出现。
- 搜索只匹配会话显示名，不搜索聊天正文、手机号或永久账号。
- 排序固定为置顶组优先，再按服务端 `lastActivityAt` 倒序；客户端不混用本地消息时间重排。

## 本期不包含

- 群会话、会话文件夹、聊天正文搜索、在线状态和输入中状态。
- 在列表直接删除服务器历史或执行关系权限操作。
- 真实会话、未读、WebSocket 或推送接入。

## 已确认决策

1. 会话列表只显示系统通知与单聊，群聊继续暂缓。
2. 滑动操作只保留已读/未读和隐藏；置顶、免打扰、清空记录放单聊详情。
3. 搜索只查显示名，不查消息正文、手机号或永久账号。

## 开发门禁

本功能已达到文档准入；全部 48 页批准前不创建 Flutter UI，全局 UI Flow Approved 前不接真实消息服务。

# 会话列表页交互

- 点击单聊发出 `openDirectChat(ConversationRef)`；点击系统通知发出 `openSystemNotifications`。
- 切换通讯录发出 `openContacts`，不创建新的 Shell 分支。
- 搜索 300ms 防抖，只匹配显示名；清空恢复完整列表。
- 标记已读/未读和隐藏均使用 expectedVersion、幂等键与 SingleFlight。
- 下拉/分页失败保留已有摘要；WebSocket 事件先去重再触发 Repository 合并/补拉。
- 重复点击当前消息入口回顶；会话引用失效时留在列表并刷新。

## UI Mock 交互（2026-08-27）

- 点击带未读数的好友会话：先将当前 Fake 未读清零，再进入对应单聊。
- 好友会话向左拖动超过阈值：固定露出三个操作按钮；反向拖动或点击会话正文收起。
- “标为已读/未读”：在 `0` 与 `1` 条 Fake 未读之间切换，并立即更新红点。
- “置顶/取消置顶”：移动到置顶折叠区域或普通区域；置顶区域折叠时，置顶会话随区域隐藏。
- “删除会话”：先显示“确认删除并清空记录？”；取消不改变列表，确认后仅从当前 Mock 内存移除。
- 长按好友会话打开同能力底部菜单，作为无障碍和不便滑动时的等价入口。
- `KING CLUB` 系统会话不响应左滑删除，点击仍进入系统通知。
- KING CLUB 行未读数由系统消息页回调更新；打开入口不视为已读，返回后立即显示剩余数量。
- 好友会话未读变化必须同步回 App Shell 聚合徽标；进入单聊、标记已读/未读与确认删除分别回传最新值，不能由 Tab 切换推断已读。
- 下拉刷新首次进入 Fake 局部失败：保留当前摘要、未读和滚动位置，显示“网络不可用，已保留最近会话”与“重试”。
- 点击重试只在本地恢复 `ready` 并提示“会话已是最新（UI Mock）”；重复点击由页面级 SingleFlight 阻止。
- 旧版隐藏搜索不在本复刻批次中激活；不得用搜索图标、输入框或空搜索页改变已确认首屏。
- 长按好友会话选择“模拟关系已结束”：清除该会话未读、更新 Shell 聚合，把行摘要改为“好友关系已结束 · 仅可查看历史摘要”。
- 点击只读摘要：显示说明弹窗，可“知道了”留在列表或“返回通讯录”；不得打开仍可输入的聊天页。
- 长按选择“模拟会话失效”：清除未读并把摘要改为“会话已失效 · 请本地刷新”；点击时阻止导航并显示恢复弹窗。
- 失效弹窗“本地刷新”捕获当前 Fake generation，450ms 后仅在 generation 未变化时恢复正常摘要；迟到结果不得覆盖后续状态。
- 非正常状态的长按菜单提供“恢复正常 Mock 状态”；恢复后好友未读设为 `1`，用于验证列表与 Shell 徽标回流。

## 用户任务与线框

查看系统通知和单聊摘要，识别未读消息并进入正确会话。

```text
消息
[消息] [通讯录]                     [添加好友]
[搜索会话名称____________________________]

[KINGCLUB] 系统通知              3   10:20
           订单状态已更新

置顶
[头像] 好友备注                    2   09:10
       [图片]

最近
[头像] 好友昵称                    ·   昨天
       你收到一条新消息
```

- 列表只含系统通知和单聊；免打扰未读用非数字弱提示，普通未读显示 1～99+。
- 右滑/更多提供无障碍等价菜单：“标记已读/未读”“从列表隐藏”。
- 不显示在线状态、手机号、账号或完整消息正文。

状态见 [states.md](states.md)，交互见 [interactions.md](interactions.md)，验收见 [acceptance.md](acceptance.md)。

## 当前复刻决策

- 用户于 2026-08-26 提供旧版聊天截图，确认保留现有通讯录主体，并在顶部相邻增加 `聊天` 选项。
- 当前 UI 以 [旧版聊天列表 UI 复刻规范](legacy_ui_replication.md) 为准；原线框作为后续扩展场景保留。

- Android API 37 模拟器已验证通讯录/聊天双向切换、置顶折叠、Fake 会话预览和消息底栏选中态；验收截图见 [android_chat_mock_latest.png](android_chat_mock_latest.png)。

## 会话管理 Mock 增量（2026-08-27）

- 好友会话默认显示数字未读标记；进入会话或选择“标为已读”后，本地清零。
- 好友会话左滑露出“标为已读/未读、置顶/取消置顶、删除”三项；长按提供同能力菜单。
- 置顶只改变当前 Fake 列表分组和折叠归属，不写本地数据库。
- 删除必须二次确认；确认后只从当前内存列表移除，不删除真实聊天记录。
- `KING CLUB` 系统会话继续作为受保护入口，不提供删除动作。

## 系统消息未读联动（2026-08-27）

- KING CLUB 会话行初始显示 `3` 条系统未读。
- 系统消息页单条已读或全部已读后，会话行显示剩余数量或移除红点。
- 点击 KING CLUB 行本身不清零；阅读动作必须发生在系统消息页内。
- 联动只存在于当前 App Shell Fake 生命周期，不持久化、不接推送。

## Shell 消息徽标联动（2026-08-27）

- 会话页把好友会话当前 Fake 未读数回传给 App Shell；Shell 与系统通知未读求和后显示在底部消息 Tab。
- 默认聚合为 `3 + 2 = 5`；只打开消息页、切换通讯录/聊天或折叠置顶不会清零。
- 进入好友单聊、标为已读或确认删除 Fake 会话后，好友来源变为 `0`；标为未读时变为 `1`。

## 列表刷新与空状态 UI Mock（2026-08-27）

- 旧版 `pages/index/index.wxml` 的聊天搜索输入框被明确设为 `wx:if="{{0==1}}"`，因此 `Legacy Conversations Replica v1` 正常首屏不新增可见搜索栏；搜索契约保留，待后续单独批准升级版视觉后再开放。
- 会话列表保留旧版下拉刷新手势；本轮 Fake 首次刷新进入局部离线状态，现有 KING CLUB 与好友摘要保持不动，并显示可重试提示。
- 点击重试后只恢复 ready 状态并提示“会话已是最新（UI Mock）”，不访问网络、不生成新消息。
- 删除唯一好友 Fake 会话后，列表只保留受保护的 KING CLUB 系统入口和旧版纯黑留白；不增加偏离旧版的插画或大段空态文案。

## 关系结束与会话失效 UI Mock（2026-08-27）

- 为保持旧版正常首屏不变，异常演示入口只放入好友会话现有的长按等价菜单，不在顶部或会话行新增常驻测试按钮。
- “模拟关系已结束”清除好友未读并把摘要改为只读；点击该行只说明历史摘要仍可查看、不能继续发送，不进入可输入的单聊页。
- “模拟会话失效”清除好友未读并显示失效摘要；点击该行阻止导航，提供“本地刷新”和“返回通讯录”。
- 本地刷新使用当前 Fake 会话世代恢复正常摘要；世代不匹配的迟到结果被忽略，不覆盖更新后的页面状态。
- 长按菜单提供“恢复正常 Mock 状态”，用于连续验收；恢复后补 `1` 条 Fake 未读以验证 Shell 聚合重新出现。
- 离线提示补充固定 Fake 缓存时间 `今天 21:08`，不读取系统数据库或服务器时间。

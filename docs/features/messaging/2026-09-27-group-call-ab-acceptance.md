# A/B 正式包群通话验收

两端使用正式包名 com.lingmei.kingclub 的 profile APK，SHA256 `0CA6848DC52BB55E3E005BECD89DC59AC3703735217BCF558BF4FEFC7223B9BC`。B 用户完成登录后，实际 UI 为正式包首页。

在既有 A/B 测试群发起群语音，B 收到邀请并接听，首次麦克风权限选择使用时允许。A/B 均显示双方“已加入”并持续计时，服务端两个成员 phase=joined、占用数=2、通话未结束。两端 CallForegroundService 均为前台服务。用户明确确认双方都能听到声音。

随后 A 退桌面并锁屏，dumpsys power 为 Dozing，前台通话服务仍有效。锁屏后的实际声音和恢复、双机群视频、结束清理尚待本轮后续确认，不能由前台语音通过推定。

后续用户确认 A 锁屏后双方仍能听到。唤醒 A 返回通话，计时为 02:25，双方仍已加入。两端近同时返回退出后短暂观察到一个群席位占用，随后归零；最终 participant 为一个 left、一个 expired，说明没有证明双方都及时主动退出。

代码核查发现 hangUp 遇到版本冲突时直接关闭控制器，无法执行 controller 已刷新状态后的下一次 leave。现仅针对明确 CHAT_GROUP_CALL_VERSION_CONFLICT 最多尝试三次退出，其他网络或权限错误不重试，不重试加入或采集。新增覆盖一次冲突后使用新 requestId 成功退出、持续冲突有限终止；会话及控制器共 15 项测试通过，变更文件 analyze 通过。此修正尚未打包安装，不将上述实机残留直接归因为已证实的版本冲突。

同版双机群视频邀请和接听成功，B 首次摄像头授权选择使用时允许；两端已持续计时超过两分钟、双方均已加入。实际双向画面与声音待用户确认，当前没有替用户认定。

本记录不代表系统离线推送、锁屏新来电唤醒或跨网纯直连已通过；本次是已建立群媒体通话的验收。

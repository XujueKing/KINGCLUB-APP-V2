# 静态图片上传与本地源一致性修复

Android 的 JPEG/静态 PNG 在上传前由原生插件压缩为最长边 2560、质量 85 的 WebP，不保留 EXIF。哈希、加密上传及发送方持久化使用同一份结果，转发和失败重试也保留实际上传源；恢复已入队草稿不得覆盖已有图片缓存。

配套服务端对无用户元数据、尺寸合规的静态 WebP 完整解码验证后保留字节；Android 固定 Google 2016 sRGB 配置按精确哈希允许，其他输入继续原有规范化。保持原有长度/SHA256 校验，不用跳过完整性验证掩盖源不匹配。

验证：客户端上传/重试/持久化/转发 11 项测试通过，静态分析通过。后台完整 verify 最终 104 文件、492 项测试通过。

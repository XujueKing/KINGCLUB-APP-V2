# 静态图片上传与本地源一致性修复

Android 的 JPEG/静态 PNG 在上传前由原生插件压缩为最长边 2560、质量 85 的 WebP，不保留 EXIF。哈希、加密上传及发送方持久化使用同一份结果，转发和失败重试也保留实际上传源；恢复已入队草稿不得覆盖已有图片缓存。

配套服务端对无元数据、尺寸合规的静态 WebP 完整解码验证后保留字节；其他输入继续原有规范化。保持原有长度/SHA256 校验，不用跳过完整性验证掩盖源不匹配。

验证：客户端上传/重试/持久化/转发 11 项测试通过。后台完整 verify 104 文件、491 项测试通过。实机安装和新增图片点对点验收待记录。

范围：缩略图仍由服务端生成，动画、非 Android 输入和语音/视频规范化不在本次保证范围内。不能据此宣称所有媒体已经脱离服务器。

# 媒体预取授权变化后的缓存处理

检查图片、语音、视频预取时发现：下载后再次签发的授权如果指向不同文件，原实现直接返回，没有设置失败状态，也没有移除按消息 ID 保存的下载临时副本。下一次尝试可能复用该旧副本；图片和语音尤其不能仅凭新授权把旧副本发布成本地消息媒体。

现将这种情况统一处理为可重试失败：先丢弃对应 transfer 缓存，再进入既有 30 秒退避；恢复网络等显式 retryFailures 可以提前重试。视频同时检查 fileId、sha256 和 size。删除或会话结束仍优先停止，不通过重试恢复已删除内容。

新增测试覆盖私聊和群聊的三种媒体：下载前后授权变化、不发布旧内容、旧 transfer 被清除、普通刷新保持退避、显式重试下载新字节、重新打开磁盘缓存后读取新字节。连同既有预取、重连、撤销、删除、视频损坏用例共 43 项通过，四个变更 Dart 文件 analyze 无问题。

未声称生产中已发生媒体文件替换，也不把此修复当作会话动画性能验收。普通缓存命中只检查本地文件存在及长度，不读取完整媒体内容；没有为未经证实的性能原因添加成功缓存状态。

# 公网文件与视频中断恢复

安装版本 a6cd895d，A 蜂窝网络、B Wi-Fi，使用公网 WSS；只使用 A/B 测试账号和合成素材。以下 peer 帧均为加密中继，不能记作 UDP 直连。

## 8 MiB 文件：进程重启后复用完整块

B 通过实际文件入口发送 `KC-PUBLIC-RESUME-0921.bin`，消息 `708e2125-859e-4f3f-9472-8bf605c236eb`，8,388,608 字节，源 SHA-256 `2a7ed4446dbaca6d9162182728a96018d3bfdfae50b60a8c2d7906a7932dca3e`。

A 首次读取时慢中继于 15:05:43 回退 HTTP；脚本观察到续传目录已原子写入 0.block、1.block 后，于 15:05:46 force-stop A。停止后目录确实只有这两个块，没有 retained 标记。服务端曾返回块 0、1、2，但第 2 块未提交到缓存，不记为已接收。

重启 A、进入原会话并再次点读取文件后，客户端导入缓存再次尝试 peer；仍为慢中继，15:07:28 回退。服务端 15:07:30–34 **只出现块 2–7**，没有再次请求块 0、1。最终界面显示“保存到文件”，8 MiB 明文工作副本哈希与源一致；缓存有八个 1,048,604 字节加密块及 retained 标记。

该结果证明跨网络完整分块在进程被停止后持久保存、重新读取时复用。恢复包含人工重新进入页面点击读取，不声称系统杀进程后自动后台恢复；也不是 UDP 中断实验。

## 视频：发送端中断后自动回退并解码

B 通过实际照片→选择视频发送此前合成的 20 秒 H.264，消息 `996473cd-6667-4157-979d-b1f6ab42ca7a`。A 点击视频后，在新接收临时文件高水位 135,664 字节时，15:11:39 停止 B。随后没有再操作 A。

A 15:11:42.698 报接收超时，自动进入 HTTP（距离停止 B 约 3 秒）。接收统计中继 256 帧/249,856 字节，包含传输在途数据，不能把触发时高水位当作全部有效字节。完整块不足 1 MiB，本轮不能证明视频复用了完整块。

服务端 15:11:43–45 返回三块 1,048,576 字节及末块 338,038 字节。A 两份持久化视频均为 3,483,766 字节，SHA-256 `1633d6463f046e564ebf42f6eea7d633f0dafad4adce7f087006fc384d56d6ba` 与原规范化合成源一致。实际画面显示 19.958 秒 / 479 帧末帧（本机截图 build/public-video-recovered.png）。确认自动回退、完整性与解码；无声源不计听音验收。

B 已重新启动并返回测试会话。公网 UDP、跨网语音、长时间后台及操作系统回收后的后台自动恢复仍不由本记录证明。

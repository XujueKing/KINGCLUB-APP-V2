# 本地聊天记录检索

搜索页网络失败时回退到当前账号、当前单聊或群聊的加密本地记录；权限和登录错误不回退。界面明确提示仅搜索本机已保存记录，不能表示服务端完整历史。回退后继续向前分页使用同一本地来源。

正文及文件名支持不区分大小写的子串检索；附件类型筛选复用本地检索。每批解密最多 50 行，按序号游标扫描，以匹配结果分页，不建立明文索引。事务保证删除期间读取一致性，忽略 stale、hidden、recalled 内容。文件结果显示文件名。

验证：单聊、群聊分别在真实 SQLite 文件中写入 125 条记录，验证跨扫描批次分页、大小写、文件名、类型过滤、其他会话隔离，以及删除后关闭重开数据库和 stale 排除。搜索页既有交互回归另行运行。

限制：尚未安装到手机做断网搜索验收。联网搜索仍以服务端契约为准，本次不改变服务端文件名搜索。未缓存到本机的历史不会被本地搜索找到。

## 离线上下文

单聊、群聊搜索结果及会话中的引用消息入口均接入本地上下文：服务端读取发生 NETWORK_ERROR 时，整段回退本地事务读取，不拼接两个来源。读取目标前后各最多 20 条，加目标最多 41 条；校验序号和消息 ID 同时匹配，已删除、stale、已撤回目标不可打开。界面显示本机记录提示。权限或会话错误不允许回退。

15 项上下文相关测试通过：真实 SQLite 有界窗口和删除后重启不可打开，组件网络错误回退、权限错误不回退、退出登录屏蔽迟到本地结果，以及既有媒体和删除刷新回归。尚未完成手机断网端到端验收，不能将组件测试等同于实机交付。

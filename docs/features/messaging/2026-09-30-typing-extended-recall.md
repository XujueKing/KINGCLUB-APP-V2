# 标题对齐、正在输入与不限时撤回

## 用户确认

标题左右按钮应对称。单聊显示“对方正在输入”。普通撤回保留；不限时撤回只针对本人消息，任何会员可付费，默认每条 5 金币，费用及高级权限/等级豁免由全局规则决定。

## 实现

- 标题右按钮偏移从 -2dp 改为 0dp，保留返回图标位置。
- 单聊真实编辑发送 `client.chatTyping`，3 秒节流、停止编辑 4 秒结束；失焦、发送清空、后台、离开及账号重绑定时停止。只传布尔状态和对方账号，不传文字，不产生通知或未读数。接收仅匹配当前对方和会话，6 秒过期还原标题。
- 长按已发送的本人普通消息可查看普通撤回和“为所有人撤回”。超出两分钟普通撤回保持可见但不可点，并提示不限时入口。
- 不限时撤回先查询服务器报价，用户确认后携带确切费用提交；无报价、价格变化、余额不足、权限失败均不在客户端假装完成。
- 单聊/群聊调用既有 661/662 接口的新模式。成功才清理本地消息及相关媒体，并重新同步。对方离线时须恢复连接后才能同步删除；外部另存/截图无法收回。

## 验证与发布边界

Flutter 静态检查通过；相关 61 项测试通过（包括标题、控制器、缓存删除及报价边界）。共享测试服务已发布 migration 211/212 及输入状态、撤回模块，运行健康检查通过。iOS build 29（提交 fc7112db）已构建、校验签名并覆盖安装，保留数据；远程启动被系统拒绝，已请用户解锁后打开。实时输入和付费撤回尚未完成真机交互验收。仅服务确认消息支持此入口，纯 P2P 尚未登记服务端的消息不显示收费入口。

前置迁移阻塞已解决：新增 212 允许合成测试库登记目录，保留历史迁移不变。全新合成库完成迁移并通过真实 MySQL 验证：单聊/群聊并发扣费幂等、通知失败回滚、权限免费、余额及报价校验、所有参与者历史隐藏、列表预览和未读排除，以及输入状态好友/拉黑校验。测试仅使用合成会员，不修改真实会员余额。

发布前完成私有数据库备份，保留旧容器可回退。仅更新相关模块；服务器现有 WebSocket 入口保持原实现，仅合入输入状态分支。默认报价 5 金币、661/662 契约及三张表目录登记已在运行服务核对。后台目前通过数据库规则配置费用、经验门槛及独立授权，尚无专用管理页面。

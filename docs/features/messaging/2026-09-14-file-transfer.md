## 慢网凭证续签
分块 GET 返回 401/403 时关闭该响应流，重新通过 652/654 校验当前权限与完整文件元数据，并只重试当前块一次；之前已经写入的块不重传。重新授权拒绝、元数据改变或新凭证再次被拒立即停止并清理，不无限重试。该机制不代表进程重启后的磁盘断点续传。

下载续签已完成客户端验证：15 项下载测试通过，包含第二块首次 403 后重新签发、请求块序列恰为 [0,1,1]，完整拼装摘要仍一致；重新授权撤销或元数据不符不再请求该块，第二次 403 不再循环。analyze 无问题。手机测试包安装仍在原进程等待用户解锁确认，本次未重复安装。

## 上传短凭证续签
上传分块返回 401/403 时使用原 clientUploadId 重新准备，严格核对相同资产与文件元数据，并核验新 AAD/密钥后重新加密当前块，最多重试一次。不会将旧密文发给新 grant，也不为续签创建新消息或上传编号。已上传块保持，权限拒绝/资产过期/元数据改变停止；进度不回退。

上传续签验证通过：原丢回执恢复测试保留；新增第二块 403，重新准备时改变密钥与 AAD，合成服务独立解密新密文并核对原始字节，最终仅 3 次分块请求且上传编号不变。ready 再次调用不上传，会话变化仍拒绝。两项协议流程测试与 analyze 通过，不作为真实服务器/手机慢网联调证据。另将文件句柄关闭放入嵌套 finally，关闭异常也能释放上传忙状态。

上传拒绝路径补充验证：重新准备拒绝、重新准备返回其他资产、续签后分块仍 403 均停止，不调用 650、不新建 clientUploadId，服务端合成回执中仅保留首块。续签最多尝试一次，分块请求数分别 2/2/3。连同丢回执和成功续签共 5 项测试通过，analyze 通过。手机 package 查询仍仅原 preview，独立文件测试安装进程仍活跃等待确认；未重新安装或误报原生保存已通过。

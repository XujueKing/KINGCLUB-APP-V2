# 视频播放与群已读

现有视频组件收到群已读就销毁播放器并重取文件，导致播放回到开头。改为在已展示视频/封面时后台重新取得媒体授权，文件身份不变则保留播放器和进度；拒绝或文件变化则清空。通知在复核期间再次到达时需再复核一次，不能信任早先请求的结果。加载期间继续原有重载取消机制；前后台、账号及明确权限变化仍清空。

本次只改变已读处理，不改变界面与编码选择。以组件测试验证保留实例、失败停止和迟到授权边界，不把受控测试等同真实视频声音验收。

7 项视频组件/缓存授权测试通过，2 文件静态分析无问题。新增三种情况覆盖：普通已读保留同一播放器、7 秒位置及一次文件读取；授权拒绝或同一文件编号内容尺寸变化后销毁播放器；复核中再次到达通知时，不以先到的旧授权跳过后续拒绝。首次测试的模拟播放器未设已初始化状态，导致进度条持续等待，修正替身后通过。

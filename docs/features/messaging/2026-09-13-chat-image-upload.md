# 聊天静态图片上传接入

用户持续开发授权下接通真实图片链路，保持现有照片／拍摄入口与会话布局。

## 当前模块

- ChatImageUploader 调用 631 获取本人图片上传记录及短期凭证，以 AES-256-GCM 发送独立二进制请求，AAD 绑定账号、图片摘要、大小和上传记录。禁止跟随重定向携带凭证。
- 本地安全存储仅保存账号隔离的上传幂等 ID，不存凭证或图片字节。上传成功但响应丢失后，重选相同图片可复用 ready 记录；只有图片消息写入持久发送队列后才确认删除上传 ID。
- 会话变化取消当前请求；每个异步阶段检查身份，迟到结果不能进入新账号会话。源文件上限 20 MiB，服务端处理静态图并生成预览。
- 这是客户端到服务端的上传加密，不等同聊天双方端到端加密。

## 验收及未完成项

客户端测试覆盖实际二进制加解密、上传提交后丢失回执、重建上传器后的 ID 复用、消息入队后释放 ID、超限输入、会话切换和错误账号凭证。

尚未接入照片／拍摄按钮与接收图片气泡；重启后未完成上传需要重新选择原文件，并非完整离线附件队列。群图片、断点续传、孤立文件清理及双机真机验收未完成。服务端 053–056 仅隔离数据库验证，尚未部署到共享测试服务。

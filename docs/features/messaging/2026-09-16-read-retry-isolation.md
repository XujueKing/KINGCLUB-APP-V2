# 已读补交异常确认隔离

现有补交按单聊、群聊顺序处理。服务端确认字段不合法时抛出 FormatException，被通用异常分支捕获后直接结束整轮，可能使后面的正常会话长期无法清除未读。

对格式错误的确认保留原已读意图，对该会话及当前序号采用现有五分钟冷却，继续处理后续会话。新序号或用户再次明确阅读仍绕过冷却。网络及登录状态错误仍停止本轮，不把异常确认当成成功，不发成功刷新事件。

验证覆盖单聊和群聊的异常首条、正常后续条目、冷却期间不重复请求及服务恢复后的补交。此为受控接口测试，不等于双机真实未读验收。

结果：已读确认、群已读队列、单聊已读队列及并发阅读共 29 项测试通过，两文件静态分析通过。本修复尚未打包安装到手机。

# 地图位置选择页

用户指定以微信位置选择截图为参照，替换黑色表单页。结构：上部约 64% 真实地图，地图上浮动“取消 / 发送”；下部白色地点面板、浅灰搜索框、地点名称和淡灰地址/距离、选中项右侧绿色勾选。没有页面标题栏、左侧单选圆圈、底部大号确认按钮。键盘出现时压缩地图，并避免定位按钮遮住顶部操作。

iOS 新增独立 MapKit 平台视图，使用系统浅色地图、蓝色实际定位点、固定中心选点标记。拖动地图结束后防抖 350ms，查询地图中心地址和周边真实 POI；查询由 MKLocalPointsOfInterestRequest / MKLocalSearch 完成。GPS 原始坐标与附近建筑是分开的候选，不能将附近建筑改名为“当前位置”。点列表候选会重新定位地图；搜索真实地点后仍需选择并明确发送。旧会话详情的深色地图不改。

精确定位仍采用上个节点的新鲜度和精度检查，收到的坐标按 WGS84 原样传给 MapKit API，不对苹果地图重复偏移。用户现场的 1–2 公里误差尚未在本版本复测，不以估计精度代替现场验收。地图中心选点可由用户校正实际落点。

安全与生命周期：取消不发送，选择与拖动不发送；发送保存失败可重试；账号变化立即隐藏地图、清空候选和选择，迟到查询不能恢复；原生地理编码/搜索的新请求取消旧请求，销毁视图取消任务。附近 POI 失败时只保留真实选点，不编造建筑列表。第三方系统地图查询仅包含地点/坐标，不发送聊天消息。

Android 尚无内嵌地图 SDK Key，本次统一上下区布局、搜索框、选项和发送控制，地图区域明确提示未接入，支持已配置的外部系统地图查看；不能宣称完成 Android 微信式地图拖动/POI 联调。用户此前已说明没有 Key。

验证：21 项位置、地图详情、定位新鲜度、明确发送、会话变化和键盘布局测试通过；新增 iOS 平台视图通道测试验证地图移动不自动发送、过期请求被拒绝。两个修改的 Dart 文件静态分析通过。浅色地图页单独设置深色系统状态栏文字，避免与浅色背景混在一起。

# A 视频压缩与断网重试实测

设备 A（PCLM50），当前 c8271f6 独立构建 Profile 包。通过 A→B 已授权单聊的“照片→选择视频”，选择已有专用合成样本 `kingclub-ab-compression-20260915.mp4`，不使用未知私人视频。

发送前暂时关闭 A 的 Wi-Fi 和移动数据。原生输出检查 accepted=true：20,071,696 字节、8,021ms 的原视频变为 1,962,230 字节，约减少90.22%。3479ms进入上传阶段，3636ms报网络连接失败。页面实际保留“已压缩：19.14 MB → 1.87 MB”和发送按钮。

恢复原有 Wi-Fi/移动数据开启状态（均读取为1）。网络刚恢复时的一次重试仍失败；连接稳定后重试14ms即进入上传，1467ms进入服务端处理，5711ms进入队列，5843ms完成入队。未再次执行原生转码。页面返回单聊并出现一个新的8秒视频卡片。

打开新卡片实际显示合成色视频，进度到100%，截帧时间约7.93秒，证明本机解码到结尾。未操作 B，未核对接收端播放或听感；没有以音轨存在代替听感验收。没有验证上传过程中断线的分块续传，仅验证上传前断网后的重试与压缩结果复用。

用户此前18MB视频身份尚未确定，相册中存在多段相近大小视频；本结果不作为该私人样本的压缩质量证明。UI/XML/截图只保留本机build目录。

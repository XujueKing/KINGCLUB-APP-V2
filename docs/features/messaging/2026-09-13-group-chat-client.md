# 群聊客户端真实数据接入

GroupChatRepository通过现有认证账号客户端调用617–622；不将groupId冒充好友账号调用单聊接口。建群在编辑器存活期间对同名和同成员集合复用requestId，成员顺序归一；确认返回群ID后清理请求标识。建群表单跨进程恢复尚未完成。

GroupChatController从共享账号安全Outbox读取groupId匹配的消息，不读取单聊recipient项；文本先写安全队列再发送，失败保留原clientMessageId，历史确认后才删待发项。初次最近页和after补收、before旧历史、按messageId去重、已读提交、同步期间通知补读已实现。群权限拒绝清除已确认历史并禁新发，自己未发出的草稿保留。清空/销毁后的迟到历史不能重现。

验证：5项测试覆盖建群重试ID、丢失发送确认后从历史恢复且不重复发送/不读取单聊草稿、群权限撤销、同步中通知、清理后迟到响应；两文件静态分析通过。

状态：此批数据层代码尚未接群页面入口；群主/管理员/成员管理、客户端建群页、群列表和聊天布局继续开发。未部署042/043、未作双机验收；不将此数据层标记为可用完整群聊。服务端已有真实加密接口与MySQL并发测试证据见后端群聊文档。

# 认证后的新地址学习

同 socket 跨目标 STUN 诊断发现 A 的公网 IP 和端口均变化。此前 route 只允许相同已通报 IP 的新端口，未知 IP 在解密前直接丢弃。现在对可路由单播地址以及既有私网地址允许有界认证尝试：未知地址与未知端口共用每秒最多八次额度；身份仍完全由现有原生加密会话验证，IP 不成为身份依据。

未知端点只能通过认证 ping 进入最多两个 observed 候选，再通过该端点绑定的一次性随机 challenge/pong 确认回程。普通应用数据不参与建路、未确认前不交付；已健康路径不因未知源包被替换。过滤范围保持不接受回环、链路本地或组播等非候选地址。此机制不进行端口扫描。

原生 AEAD + 真实 UDP 测试分别覆盖已通报 IP 的新端口，以及完全未通报 IP 的来源：垃圾包、篡改密文、认证但未确认的应用数据均不能建路；错误 nonce 不能确认；正确挑战回执后数据可交付。另保留父级真实 socket 重建恢复与 nonce 过期/一次性校验。

这修复已知实现限制，不是当前公网丢包原因已确认。此前手机 unknownAddresses=0，若运营商/网关仍不允许报文抵达，该改动不能突破过滤。部署后的公网直连须另看真实收发与路由计数。

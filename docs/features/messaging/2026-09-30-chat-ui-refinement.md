# 聊天列表与输入区调整

按用户本轮要求：群头像统一圆形、两人左右各半、三人上下一加二、所有人数铺满，无额外灰色间隙。图片按目标格子比例居中裁剪，不拉伸；仍生成 144×144 PNG 并按账号持久化，缓存版本升级以避免显示旧拼图。

聊天／通讯录顶部标签分别使用消息未读数和待处理好友申请数；在两个标签页面都显示，计数归零时隐藏。复用已有消息及好友申请同步路径。

表情分类显示“表情”和“自定义表情”，移除动物、食物入口，保留用户已添加的表情包及添加表情包入口。自定义表情加号沿用系统照片多选器及已有压缩、持久化、容量限制。输入文字时固定保留笑脸和加号，使用键盘发送键或表情面板发送按钮。

## 旧版 CSS 对照

来源：只读旧项目 `pages/index/index.wxss` 中 `.chat_view`、`.chat_text_style`、`.chat_text_name`、`.chat_text_content`、`.chat_date`、`.touxiang_style`。

| 项目 | 旧版 | 当前 Flutter |
|---|---|---|
| 行高 | 140rpx | 140 × 屏宽 / 750 |
| 圆形头像 | 96rpx | 96 × 屏宽 / 750 |
| 头像与文字间距 | 25rpx | 25 × 屏宽 / 750 |
| 姓名字号 | 30rpx | 30 × 屏宽 / 750，正常字重 |
| 摘要字号 | 26rpx | 26 × 屏宽 / 750 |
| 时间字号 | 24rpx | 24 × 屏宽 / 750 |
| 两行间隔 | 5rpx | 5 × 屏宽 / 750 |

上述尺寸已有对应。旧 CSS 没有给这些文字单独指定字体或行高；本轮去掉列表文字继承的全局 1.6 倍行高，改用字体自然行高（`kTextHeightNone`），草稿摘要保持一致。Flutter 使用平台字体度量，不能宣称跨平台字形和行盒逐像素相同。保留用户后来指定的右侧时间与分割线对齐布局。

## 输入法问题

未自行增加输入法。输入法本身可以接触输入文本，恶意输入法存在风险；自制键盘无法抵御已被控制的操作系统，也会丢失成熟中文输入体验。采用可信输入法和系统安全更新，不作“无法监控”的承诺。

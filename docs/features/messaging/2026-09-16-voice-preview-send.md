# 语音草稿发送状态修复

预览发送前停止播放，但原逻辑没有同步播放按钮，也没有在停止播放的异步等待结束后重新检查页面和会话。发送失败后可能仍显示停止图标；关闭预览、退出账号或切后台时，尚未开始的发送不应继续。

本次保留现有布局：停止成功后同步播放状态；发送前记录操作代次，关闭、会话变化、切后台使等待中的发送失效；回到前台不自动补发，由用户再次点击。已经交给发送器的消息沿用原有发送与幂等逻辑。

验证通过：新增四个异常场景测试在修改前均失败，修改后通过；正常发送防重点击且成功关闭预览也通过。预览页面共 9 项、录音控制 15 项测试通过，定向 analyze 无问题。该验证使用受控音频输出，不代表手机端验收；本次尚未安装。

# 表情连续发送与系统卡片样式

- 分类恢复为原来的笑脸和爱心图标，保留“表情／自定义表情”提示语用于辅助识别，不显示文字标签；已添加表情包不变。
- 普通文本／Unicode 表情入队后只清空已提交文本与引用，保留当前面板、类别、分页位置。键盘发送继续保持焦点。
- 系统消息从固定首行移入未置顶会话区域，按最后消息时间插入；无消息时间的空入口排在普通记录之后。保留用户置顶及草稿顺序。新增时间入参已验证，但当前系统通知真实数据源仍未接入，不编造日期。
- 系统页背景与用户会话一致为 `#101010`，顶部横线 `#C9B69E` 11% 不透明度、0.5dp。
- 卡片参考只读旧项目 `pages/sysmessage/sysmessage.wxss/wxml`：总宽 660rpx、内边距 30rpx、圆角 16rpx、上下边距 20rpx；标题区底边距 30rpx，分隔线之后留白 90rpx；标题 28rpx、主值 56rpx；明细默认显示，左右 20rpx、上 50rpx、下 30rpx，标签宽 152rpx。不再用展开动画改变卡片高度，也不添加旧版没有的未读外框。

验证：15 项相关组件测试通过，静态分析通过。覆盖面板发送后原位保留、系统会话新／旧／空时间混排、键盘连续输入和真实系统页不泄露演示数据。卡片在演示数据下可呈现；真实系统消息为空的现状不变。

# 已读回执确认

当前单聊/群聊均已有持久已读队列，但请求返回后未验证 readSequence 即删除队列并推进页面确认位置。服务端单聊和群聊接口均返回整数 readSequence，且不低于请求位置。

在即时已读和后台补交共用确认校验：回执必须是有效非负整数、达到请求位置；无效回执保留待补交记录，不发布成功通知。较晚返回的旧请求只确认自己发送的位置，不删除更新的本地意图。群服务返回的 groupId 同时必须匹配请求。

仅客户端确认逻辑修改，无数据库变更。补充异常回执及重试验证，并更新既有测试替身为实际回执结构。

31 项已读队列、并发重试、建群和列表未读测试通过。新增测试覆盖缺失、落后、字符串、小数、越界序号及错误群标识：即时请求拒绝异常回执，补交不清队列且不发布成功事件；合法回执重试后清除。既有并发测试继续证明晚到回执不会清掉更新位置。这里使用受控服务和安全存储替身，不代替手机断网重启验收。本节点尚未打包安装。

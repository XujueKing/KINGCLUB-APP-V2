# 视频本地优先读取

ChatVideoView 原先即使文件已下载，也必须先成功取得服务器 grant。新增账号、消息、单聊/群聊与封面/视频分别隔离的本地键。服务器下载仍校验长度与 SHA256，并再次确认授权后导入消息本地键；再次进入优先读取该文件。解码失败移除该本地入口并尝试既有授权下载和 HEVC/H264 回退。

关系、群设置、连接恢复事件走重新授权；权限错误清除当前本地入口，网络失败可回到本地读取；会话变化仍中止显示。后台返回重新读取本地，不继续背景播放。

10项相关测试及静态分析通过：新增真实临时文件封面的离线零接口读取；保留越权拒绝、会话变化、HEVC回退测试。完整视频使用原生播放器，离线重启播放仍待真机验收。本节点未安装；发送方上传前的视频原片保留及全局撤回物理清理仍未在本节点完成。

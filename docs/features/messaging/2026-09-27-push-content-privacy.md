# 聊天推送内容隐私

用户要求：不使用手机厂商推送聊天内容。

- 聊天内容由自己的服务器通过 APP 已认证连接同步，不作为厂商推送载荷。
- 禁止载荷包含正文、预览、发送人、群名、附件内容或附件下载链接。
- 如后续接入厂商离线提醒，只发送通用提醒与必要的不透明事件标识；APP 恢复后验证登录和会话权限，再从自己的服务器读取消息。
- 客户端前台实时连接与手机离线提醒分开验收，不宣称现有实时通信具有离线唤醒能力。

本次静态检查范围：商务 APP 的 pubspec、lib、android，以及 commerce 服务 src；未找到常见华为/小米/OPPO/vivo/荣耀、极光、友盟或 Firebase 厂商推送集成标识。该结果不能代替聊天主分支或线上运行配置的完整审计。本次记录约束，没有删除聊天传输逻辑，也没有安装新的推送 SDK。

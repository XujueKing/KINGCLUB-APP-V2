## 会话页误报好友关系结束（2026-09-14）

用户截图同时出现登录状态变化和好友关系结束。核实数据库仍为双向关注、双方未拉黑。根因是会话页把 `_chat == null` 作为只读状态，并硬编码展示关系结束；session 通知销毁连接后没有恢复。

已将连接状态提示与好友关系分离。同一账号 session 保存/续期后重新打开当前凭据的 repository，并初始化聊天；退出/换账号清空内容且不重连旧好友页面。连接 generation 阻止迟到的旧连接覆盖新状态，录音/通话/播放停止，重建语音播放实例。

新增 direct_chat_session_rebind_test 验证原消息 → 同账号续期自动恢复 → 换账号清空及禁止旧会话恢复；通过。不以此声称真机验收完成。

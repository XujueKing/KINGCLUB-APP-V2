# 会话样式与设备历史规则

用户要求：气泡尾部小三角、对侧至少一头像宽度留白、深灰背景、右侧淡色时间（当天时分、昨天、一周内周几、较早日期）、群成员头像拼图及压缩、明确分页、同账号设备历史单次领取。

用户已明确选择：一条消息被某台设备成功持久化后，其他设备不能再下载该历史消息。不能用“关闭自动预取”冒充此规则；服务端需要可信登录设备身份、并发领取与持久化确认，客户端需保留本地记录。网络中断未保存不能永久消耗领取权。换机历史迁移是独立能力，不把此规则描述成微信已核实行为。

实施与验证按样式/时间、群头像、分页、设备领取分别记录，未完成项不标完成。

## 本批实现

- 普通消息气泡增加与背景同色的小三角，文本和语音复用；图片、视频、红包等独立卡片保留自身造型。
- 两侧各预留 42dp 头像与 10dp 间距，长文本宽度由剩余空间约束，上限 280dp。
- 会话及标题背景为 #191919，接收气泡 #303030；日期 #888888、11sp、右对齐，保留五分钟/跨日时间分隔。
- 会话列表和已加入群列表使用最多九位成员头像合成的 144×144 PNG。先缩图再合成，PNG 无损压缩；账号隔离持久缓存，网络失败保留旧图，重新进入刷新成员。没有引入自研压缩协议。
- 核实单聊、群聊已有 50 条分页与惰性 ListView；增加历史顶部“查看更早的消息”及加载状态，短会话无需强行拖动也能翻页。未宣称此前完全没有分页。

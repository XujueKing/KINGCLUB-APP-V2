# 列表进入时重复加载修复

用户反馈聊天列表、通讯录和聊天记录进入时有加载过程，要求本地持久化并先展示本地内容。

检查结果：聊天记录使用加密 SQLite；会话列表及联系人已有磁盘快照。问题不能简化为没有数据库。聊天和通讯录切换激活时主动清空头像 Future，导致成功头像也重复加载；会话列表磁盘恢复使用与网络请求共用的代次，实时刷新先启动会使本地读取被丢弃。

本次修复：普通标签切换及聊天页回前台保留成功头像，失败请求仍可重试，关系通知及主动刷新继续更新。会话列表按当前账号仓库身份校验磁盘读取，不被同账号后台请求取消；已取得新快照时不再用旧磁盘内容覆盖。

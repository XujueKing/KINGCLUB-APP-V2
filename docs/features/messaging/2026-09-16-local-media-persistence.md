# 本地媒体持久化

用户明确要求语音、图片、视频、头像等保存到本地，已有文件离线可用，发送方不应重新下载自己的文件。

实现方向：共享媒体存储改用应用数据目录，迁移旧媒体目录；默认不按临时缓存容量自动淘汰。文件按账号及内容标识隔离；保留主动清理、单文件损坏删除及会话撤回处理。新增统一本地读取能力；本地文件导入及发送、接收、播放路径接入继续进行。

不能仅凭更换目录宣称完成：仍需逐一接入图片/视频的离线读取、发送文件保留、通知撤权清理，并用 A/B 离线及重启验收。聊天正文已使用本地加密 SQLite，媒体存储与正文独立。当前进行中，尚未安装。

第二步：新增按内容标识原子导入本地文件。语音上传后、发件入队前保存账号隔离的资产副本；清理录音草稿不再删除该副本，残留草稿的幂等恢复分支也先保留。聊天语音携带历史中的 voiceAssetId，已有副本直接播放；缺少副本才请求下载授权，下载后保留副本。撤回后的气泡不再提供语音入口，现有会话变更仍停止播放；物理文件清理同步尚需接入。

第二步验证：36 项媒体存储/录音发送/播放测试通过，6 个相关文件静态分析通过。实际磁盘测试覆盖删除源草稿、重开媒体存储、无网络调用播放以及主动清理后不能再本地播放。此为文件持久化与播放器调用验证，不替代手机音频解码/听感验收。旧版本按 fileId 保存的副本暂需在线授权读取一次，才能生成新的资产索引副本；不得声称旧文件已全部自动迁移到可离线播放状态。

第三步：退出登录不再删除全部私有媒体；账号绑定发生变化时取消旧下载与在途读取，文件继续按账号散列目录隔离。主动清理入口明确说明会清除本机图片、视频、语音，随后需要联网重新下载。11 项共享媒体测试通过，包含取消会话后旧读取拒绝、文件保留、重开恢复和其他账号不可命中；尚未在手机安装验收。

第一步验证：共享媒体及语音播放 28 项测试通过，四个相关文件静态分析通过。真实临时目录写入图片/视频/音频后，重新打开存储仍能只读本地文件；小于文件体积的预算不再默认淘汰文件；不同账号不能命中同一文件，主动清理后读取失败。语音网络错误提示已区分传输失败和权限拒绝，尚未移除播放前联网校验。现有退出登录清理规则也尚待随账号持久化访问控制一起调整。

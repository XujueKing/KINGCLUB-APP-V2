# 聊天头像资料失败缓存修复

聊天列表原先用putIfAbsent保存资料Future，失败后仍永久保留，列表刷新继续显示默认头像。现在失败时仅移除同一Future，下次正常重建/列表刷新重新请求；不主动setState循环重试，成功结果仍复用，旧失败不删除新请求。

聊天列表在connection.ready、chat.friend-request.changed、chat.relationship.changed时清理资料缓存，和通讯录的关系变化刷新保持一致；会话页也新增friend-request事件失效，覆盖扫码申请被接受后的资料更新。未改变头像大小样式、图片磁盘缓存或账号隔离规则。

受控widget测试验证首次资料失败、再次进入重试成功、成功后不反复请求；相关静态检查通过。本批尚未安装手机，不能断言用户默认头像案例根因已完全闭环，仍需真机确认。

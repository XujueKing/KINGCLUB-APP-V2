# 地图、键盘与首页间距修正

用户要求：安卓发送/查看位置应有地图；两端进入地图避免闪屏；聊天/通讯录标题使用小红点；键盘打开时消息连续移动；首页对齐旧小程序截图与 CSS。

已查明：位置详情和地图截图仅支持 iOS；原生地图在页面转场期间创建且未定位即可露出；首页卡片行距重复叠加 24rpx 和 6dp。键盘已有 Flutter 逐帧 inset 布局，需核对真实焦点和安全区变化，不能把模拟 inset 测试当成真机流畅验收。

实施：复用已配置腾讯 Android SDK 与明确地图同意；详情展示、定位与回到目的地统一坐标边界。地图卡片使用静态图片，内存复用并在切换账号时失效；详情在转场结束后创建地图，以预览覆盖加载过程。保留原始定位精度与坐标纠偏。小红点不改变会话行未读数量或桌面数字角标。首页采用同一 rpx 基准和单次间距，不改原图片素材。补齐焦点/安全区/面板切换布局检查。

键盘修正：输入框聚焦期间锁定原有底部安全间距，避免安卓导航栏在 IME 帧之前出现造成第一次位移；输入框不要求额外滚动留白。保留平台逐帧 IME 更新，不追加第二条键盘 tween。已新增真实聚焦后的导航间距变化回归。iPhone 的具体卡顿仍需更新后现场复核，不能由模拟帧验证直接判定。

首页会员区域改为 84rpx（原固定 86dp），内容高 76rpx；横幅 417rpx、动作按钮 140rpx，保留 20rpx 横幅到按钮及 22rpx 按钮到海报间距；移除额外 8dp 影子占位和重复 24rpx 卡片间距，两行海报仅间隔 6dp。图片和缓存仍沿用上一节点的旧版压缩素材。

46 项相关回归和截图基线验证通过；14 个修改/新增 Dart 文件静态分析无问题。地图截图验证包括同坐标复用、切换账号丢弃迟到图片；转场测试发现 Navigator 的 offstage 预布局会暂时把 animation 显示成 completed，现延迟到正常布局并等待真正滑入结束。地图已经显示后不会在拖动/重选时重复覆盖预览。

腾讯官方静态图接口 `https://lbs.qq.com/service/staticV2/staticGuide/staticDoc` 已核对，现有配置返回有效 PNG；图片请求只传坐标、尺寸和地图 Key。原生 iOS MapKit 缩略图也采用同一会话内存缓存。不得把构建或安装成功当成真机体验验收。

# 单聊通话实时状态刷新

通话页面接入已有加密通知流。收到 `chat.call.changed`、`chat.relationship.changed` 或重连成功时立即读取当前通话权威状态，保留两秒轮询作为通知丢失时的补偿。通知本身不直接授予接听或采集权限。

请求进行期间收到通知会合并为一次后续刷新，避免旧响应吞掉关系变化。服务端确认 ended 或拒绝访问后沿用现有关闭流程释放媒体，关闭页面同时取消通知订阅。

验证：控制器 9 项测试通过，包括进行中的旧请求返回后再次读取 revoked 状态、关闭媒体、关闭后不再响应通知；定向静态检查通过。尚未安装本次改动到 A/B，不将自动化结果计为双机实测。本次没有更改服务端通话历史存储。

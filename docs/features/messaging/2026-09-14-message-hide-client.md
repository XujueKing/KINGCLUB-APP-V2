# 单条为我删除：原生客户端

长按现有消息菜单的“为我删除”接通单聊 663、群聊 664；确认只影响本人记录，群请求绑定当前成员代次。通过历史 canHideMessage 能力字段决定是否启用按钮，旧服务/待发送消息禁用。失败保留消息，成功使本地历史失效并重新同步，同时停止当前语音播放。

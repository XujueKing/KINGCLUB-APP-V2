# 输入区统一占位与固定尺寸消息入场

用户反馈淡入残影、新消息突然出现、输入框和卡片仍抖动。本次去掉消息透明度动画，消息子内容一次按完整尺寸布局，外层顶部对齐裁剪逐步让出行空间，使新行从底部移动进入并推动历史。仅本次进入之后创建的新收发消息参与；历史补加载不动画。

输入区取消 Scaffold 自动缩小与附件 AnimatedSize 的叠加。键盘、附件、表情共用一个200ms底部占位，取键盘与面板含安全区高度最大值，输入框和历史在同一Column中跟随；不把两者高度相加。系统IME自己的动画仍由系统控制，本次并未接管原生IME帧。

7项组件测试通过，补充键盘/附件同时存在不双重压缩列表、消息入场中文字尺寸不变；静态分析通过。Android gfxinfo只读样本984帧、24帧deadline missed，但该统计不是Flutter完整UI/raster逐帧指标，不能据此判用户顺滑度通过。

原始UI/性能信息仅保存在忽略的build目录；无私人消息上传。真机视觉验收仍待安装后确认。

# 会话更新重复计算减负

DirectChatController 和 GroupChatController 的 messages getter 会合并、排序已加载历史。页面一次通知原先多次调用该 getter，滚动期间已读检查也反复调用；改为每次通知取得单一快照，派生消息UI及当前可见历史末尾序号。已读检查沿用可见页面、前台、贴底检查，但直接读取该序号；空历史重置为null。

列表稳定Key定位改为每次build构建一次ID到反向索引映射，避免逐行线性扫描全部历史。不改变本地持久化、排序、分页、回执协议或已确认UI。

7项会话/面板交互测试及静态分析通过。此改动消除明确的重复计算，没有取得真机帧耗时对比，不能宣称抖动已验收；尚未打包安装。

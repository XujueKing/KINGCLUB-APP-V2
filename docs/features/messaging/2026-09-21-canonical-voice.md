# 语音原文件一致性

录音已经是 AAC-LC/24kHz/单声道；再次转码会损失质量并改变 peer 清单哈希。上传前清理受支持 M4A 容器的 udta/meta、空闲区、创建/修改时间和 handler 名称，不移动音频包或修改 sample offsets。和服务端采用相同黄金文件/哈希验证规则。上传、发送持久化和转发使用实际上传的字节，残留草稿不覆盖已保存资产。

服务端仅对结构支持、清理幂等、符合 24kHz/单声道/LC/大小和时长限制且通过完整 FFmpeg 解码的文件保留字节；其他输入仍走旧转码，不放宽 SHA256 或媒体授权。不是任意上传格式的直通接口。

客户端相关 20 项测试、静态分析通过；另用真实 M4A 验证加密上传、上传回执丢失重试和 sourceBytes 一致。后台真实解码/元数据/损坏/时长/多轨集成通过。实机录音验收尚待记录；视频仍需独立处理。

# 会话进入动画与历史气泡稳定

用户反馈列表进入会话未呈现全局横向动画，且历史气泡有刷新放大感。

列表入口原为 MaterialPageRoute，主题已配置 KingSlidePageTransitionsBuilder；A 三项系统动画倍率实际均为1，未证实是系统禁用动画。本次入口使用 KingPageRoute，直接调用同一全局横向 builder，明确240ms进入、220ms返回，关闭快照，不引入独立视觉曲线。

历史动画原因已确认：页面已有本地记录后，网络同步带来的新 ID 被加入消息展开集合，旧历史因此被误认为新消息。现在仅对进入页面之后创建、本人发送且正在排队/发送的新 ID 播放展开；历史、同步补收及旧发件不播放。

两项定向测试通过，验证横向中间帧、页面尺寸不缩放、返回方向及从历史位置发送后定位；静态分析通过。手机新包安装状态另记录，不把测试判为用户视觉验收。

安装：预览工作树6f1c53c，Profile构建101.2秒，159.2MB；A覆盖安装成功并稳定启动，实际UI为已登录首页。本包同时包含8024f1d、8faea76、491da6f媒体持久化修复。B未更新；本轮因用户新反馈优先修复进入动画，完整视频离线实测仍待继续。

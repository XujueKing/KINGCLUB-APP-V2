# 离线列表稳定性修正

B 在 Wi-Fi 关闭且 IPv4/IPv6 路由均为空时冷启动，聊天列表和通讯录都显示本地数据，但自动刷新失败插入错误条导致列表位移。测试结束已在 finally 恢复 Wi-Fi，wifi_on=1。

修正目标：已有完整快照时，NETWORK_ERROR 自动刷新保留列表，不插入错误条；首次无快照、登录/权限及其他错误仍显示。用户主动下拉失败仍提供明确反馈。不抹除控制器错误，不将离线数据当成服务器最新数据，不改变发送/授权判断。空的完整通讯录快照同样视为可用快照。

需验证自动刷新、手动刷新、首次失败和会话失效边界，后续合并安装再做手机回归。

新增四组组件场景覆盖聊天列表/通讯录、有快照/无快照；有快照的自动网络失败不显示错误条且联系人顶部坐标保持，手动刷新仍显示通知，SESSION_EXPIRED 仍显示登录错误。分页失败仍保留反馈，不把未加载页当成完整数据。

窄屏测试另复现会话日期行 RenderFlex 水平溢出，为日期添加 Flexible 和单行省略，保留昵称可用空间。列表稳定性、联系人控制器/流程、刷新顺序及分页联合 29 项测试通过。旧版实机断网时的错误条证据保留于隔离构建目录 `build/offline-list-b.xml`、`build/offline-contacts-b.xml`，本轮尚未安装此列表修复。

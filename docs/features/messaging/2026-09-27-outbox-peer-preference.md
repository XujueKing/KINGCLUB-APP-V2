# 离开会话后的点对点优先重试

问题：会话页面创建 DirectChatController 时配置了 preferRelayText，可用时先通过 NovoRUDP 的自适应点对点路径发送；ChatOutboxRecovery 创建的控制器只配置发送函数，没有偏好判断，自动恢复时始终先等待 CCSOP 发送结果。这导致同一条待发文字在会话内外使用不同策略。

# 定位卡片与消息文字

用户要求按两张截图调整，保留此前明确的无箭头、单侧直角气泡。

- 消息正文统一为 16dp、w400；双方使用相同字重，纯表情保持 30dp。
- 定位卡片宽 250dp，深灰标题区、单行地点和地址，地图区固定高 96dp；定位卡不再套普通文字气泡的内边距。
- iOS 新增 MapKit 快照通道，只传坐标，不传聊天内容、会员或地点名称。加载期间及失败后尺寸不变；失败仍可打开原位置详情。
- 当前只支持 iOS/WGS-84 预览。GCJ-02 旧消息及 Android 保留地点文字与位置图标，未接入地图缩略图，不声称跨端全部完成。
- 不将示意道路当成实际地图。未改变地图详情与删除位置消息的逻辑。

验证：Flutter 静态检查及位置消息/表情测试。iOS 原生新增代码尚待云端编译及真机地图预览验收，本节点未安装手机。

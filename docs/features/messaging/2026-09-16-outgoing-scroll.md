# 本人发送后显示最新消息

A实机发送位置成功后仍停留在旧记录，需要手动上滑才能看到新卡片。原因：消息变化时只有列表原本接近底部才滚动，对用户主动发送也使用了接收新消息的保留阅读位置规则。

保持当前列表和面板样式。新增本账号排队/发送中消息时滚到最新；历史加载、已存在消息的回执更新、他人消息仍沿用原有接近底部判断，避免阅读历史被打断。以clientMessageId识别新排队消息，单聊和群聊共用页面均适用。

长列表的惰性布局还会在动画期间修正底部估算；动画确实到达原目标后，再校准实际底部。用户中途滚动离开目标时不强制校准。

页面回归通过：停在30条历史中间，接收新消息不改变阅读位置，本人断网发送后排队消息进入可见区域且到达底部。定向analyze通过。修复未安装手机，群聊共用逻辑未单独实机复验。

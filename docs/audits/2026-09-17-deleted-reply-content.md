# 删除原消息时清理缓存引用正文

复现：缓存原消息和引用回复后，仅收到原消息撤回、清空游标，或显式单条删除，未重新获取的旧回复仍保存原文摘要。新增真实SQLite测试在三种路径下均明确失败。

修复：在同一数据库事务内，按会话分50条扫描缓存引用；匹配删除消息ID或清空游标的引用替换为messageId及available=false，重新加密持久化。保留回复自身正文及其他会话。只对新删除变化执行扫描，重复收到同一已处理标记不重复扫描。原消息删除后的页面继续沿用已有“原消息不可用”展示。

验证：新建3个重启后数据库断言覆盖显式删除、撤回、清空游标及跨会话隔离；连同引用失效/历史存储45项通过，优化触发条件后重新跑5项引用测试通过。3个相关Dart文件静态检查通过。尚未打包安装，不宣称真机引用刷新已验收。此前版本已经残留的引用摘要迁移、无新删除事件时的历史修复仍待补充；此节点处理新发生的删除。

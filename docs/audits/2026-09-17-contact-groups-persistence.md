# 关系分组本地持久化

此前通讯录联系人快照已落盘，但关系分组只存在网络返回和页面内存中，重启或离线时关系图标缺失。

新增 v19 contact_group_snapshot，沿用账号独立聊天数据库和 AES-GCM 密钥，AAD 绑定账号及服务端版本。成功读取/保存后的分组名称、图标、成员以加密快照落盘，低版本迟到写入不能覆盖高版本，删除后的空分组同样落盘。缓存不包含媒体授权 URL。磁盘失败不把已确认的服务端保存变成失败。

通讯录及关系页先显示本地快照，再读取服务端；迟到本地读取不能覆盖网络结果。缓存不授予编辑版本，离线可查看，编辑必须取得真实服务端版本。关系页保留入口已有分组，不再为等待首次请求主动清空。沿用既有页面样式。

验证：3 个真实 SQLite 仓库测试覆盖保存后重新打开、离线展示且禁止凭缓存写入、版本防倒退、空结果持久化及迟到本地读取；连同既有分组、页面、联系人快照、历史和附近记录迁移共 57 项通过。5 个相关 Dart 文件 analyze 通过。旧迁移夹具同步移除较新版本才有的表/列，保持真实旧结构。尚未打包安装此节点，不宣称手机离线分组验收完成。

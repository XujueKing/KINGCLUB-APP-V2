# 删除记录时关闭媒体预览

清理消息媒体前，已打开的图片和视频预览按账号、群聊标记和消息 ID 接收删除通知。匹配的图片立即移除，已播放的视频释放播放器；删除后的重试不会重新请求媒体。其他账号、群聊或消息的删除不影响当前预览。

验证：图片预览、视频预览、视频缓存授权共 20 个测试通过；本次四个 Dart 文件静态检查无问题。覆盖本地图片删除后隐藏、无关删除隔离、视频播放器释放及删除后重试不再播放。

这是客户端测试结果。本次预览关闭补丁尚未安装到手机；此前 A 端单条图片删除与离线重进验收见 `2026-09-17-image-deletion-phone-acceptance.md`。正在初始化的播放器通过既有代次检查在初始化结束后释放，未进行这一路径的真机时序验收。

# 删除消息时取消未完成的文件导出

此前下载器响应删除通知，但文件导出器只监听登录状态变化；文件复制开始后的删除无法主动取消导出。

文件详情传入当前账号，导出器监听账号、会话类型、消息 ID 匹配的媒体删除事件，调用既有原生 cancel，迟到 choose/copy 成功不再更新保存状态。原生取消逻辑会清理未完成的目标文档；已成功导出的公共文件仅释放打开引用，不删除公共文件。

验证：导出及详情测试合计 9 项通过；新增在系统选择器、复制两个等待阶段删除，验证取消已调用、迟到成功被拒绝、跨账号/类型隔离。三个文件静态分析通过。测试使用模拟原生通道，不代表 Android 文档提供器阻塞场景已经实机验证；本补丁尚未安装。

# 清空会话同步移除离线列表快照

ChatHistoryStore 完整删除会话历史和媒体时，现在在同一 SQLite 事务内移除该会话的加密列表快照，防止离线冷启动显示清空前的预览和未读数。按 direct/group 与对应身份精确匹配，同名另一类会话保留。普通失效刷新（deleteMedia=false）和单条消息删除不移除整条列表项。

列表保存的加密与写入移入同一个数据库事务，已经开始的保存与清空按事务顺序执行，避免清空夹在加密和写入之间。未解决清空之后才发起保存的陈旧网络响应，也不声称当前页面内存列表/全局未读立即刷新已完全验证。

单聊/群聊真实 SQLite 回归覆盖：保留刷新、单条删除不影响列表；并发启动保存然后清空，关闭重开数据库后只剩其他会话且其预览和未读值完整。列表与历史测试 29 项通过，三文件静态分析通过。未安装手机；待发送队列语义未改变。

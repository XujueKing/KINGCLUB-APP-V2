# 最近聊天图片后台持久化

- 单聊/群聊控制器更新时，按最近50条消息筛选图片，串行补齐原图。已有消息原图或本人发送源副本则跳过；不解码图片、不阻塞聊天布局。离页/账号变化停止后续任务，失败等后续历史更新再重试，30秒退避。
- 下载前后检查媒体授权，授权仍指向同一文件才发布消息原图副本。删除事件取消对应下载并等待退出；显式清理同时永久删除新增传输缓存身份，防止迟到任务恢复。
- 图片缩略视图在缩略副本缺失时可使用已保存原图，保持离线显示能力；完整大图不以低清缩略图代替。
- 28项图片预取、图片组件和媒体清理测试通过。覆盖单聊/群聊发送及接收、已有发送副本不下载、下载后授权撤销不发布、删除期间迟到响应不发布、磁盘重开可读及永久删除后拒绝写回。网络及下载字节为夹具；图片视图测试使用真实PNG解码。
- 本节点尚未安装手机，不计作原图后台补齐的真实接口验收。自动保存覆盖最近窗口，并不代表所有历史图片已下载。

# 发送文件本地保留上限一致性

文件上传、下载允许 256 MiB，但发送源库此前只保留 64 MiB，导致较大文件发送后离线读取失效。将发送源库上限统一为 256 MiB，保持每块 1 MiB 的加密读写；引用该常量的发送源保留和中继文件检查同时使用统一上限。

验证：生成 65 MiB + 7 字节真实磁盘文件，计算摘要、分块加密保留，删除原文件后重新打开存储，逐块还原文件长度及 SHA-256 均一致。回调结束后临时明文不存在，删除源记录后加密目录为空。发送源测试共 9 项通过，静态检查无问题；测试断言源库上限等于上传和下载上限。

未安装真机；没有将此测试计作 256 MiB 边界实测、手机大文件发送或 NovoRUDP 大文件直传验收。

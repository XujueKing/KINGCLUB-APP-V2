# 共享文件最后引用清理

问题：文件源库以当前账号和附件摘要隔离；引用保留检查包含发送和接收消息，但删除源库此前只处理本人发送的消息。因此本人发送引用先删、接收引用最后删时，源副本可能残留。

修复：在当前账号内，最后一个文件引用消失时清理对应源副本，不以最后一条消息的发送者决定。仍按附件 ID、大小和 SHA-256 精确删除；未删除消息和待发送消息的引用继续保留。系统导出副本不受影响。

验证：真实加密文件源和 SQLite 历史中写入跨单聊/群聊共享引用，先删发送记录并重开存储，再通过本地清空或远端撤回删掉最后接收引用。两条新增用例均验证中途保留、最终分块与 retained 标记清除；相关 30 项测试通过，三个相关文件静态检查无问题。本补丁未安装手机，此项不替代手机验收。

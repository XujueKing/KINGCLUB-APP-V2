# 视频删除与迟到授权回归

补充 ChatVideoView 与真实 ChatMediaCleanup/MediaCache 的组合检查：先从临时磁盘显示视频封面，执行消息清理，验证封面 UI 消失，封面和视频缓存文件均不存在，过程中不请求媒体授权。视频缓存用测试字节占位，本测试不启动原生视频解码器。

单聊/群聊各检查一次：媒体授权请求未返回时删除消息，再返回格式有效的授权；下载函数未调用，点击重试也不能让已删除消息重新发起请求。网络和下载边界为测试替身，不访问真实会员。

该文件 5 项测试通过，静态分析通过。未发现需要修改当前生产实现的新失败；新增回归覆盖既有删除屏障，不宣称群聊真机或原生播放器释放验收完成。没有新 APK。

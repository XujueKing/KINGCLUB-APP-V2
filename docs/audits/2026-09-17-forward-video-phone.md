# A 转发视频离线播放验收

设备 A，预览 e3a30ec。使用既有项目合成样本 kingclub-ab-compression-20260915.mp4，经照片→选择视频发送到已授权 A/B 会话。实际页面显示压缩 19.14 MB → 1.87 MB，随后出现 8 秒视频卡片。长按这条新视频，转发给 B 并确认，返回会话。

关闭 Wi-Fi/移动数据，确认 Active default network: none 后强制停止、冷启动。会话显示原视频和较新转发视频的封面；点击较新卡片，实际渲染合成色视频。播放结束时进度语义为 100，截图末帧约 7.93 秒，与样本长度相符；同时再次确认默认网络为 none。随后恢复 Wi-Fi/移动数据并返回会话。

本地证据为预览 build/kc-video-offline.png、kc-video-end.png，包含聊天内容，不提交图片。未操作 B。结论仅限 A 的该合成视频发送、转发、本地冷启动封面和画面解码到结尾；未人工确认声音听感，不证明 B 接收、群聊、私人 18 MB 样本或多格式压缩质量通过。

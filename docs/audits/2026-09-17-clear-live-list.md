# 清空提交后刷新内存列表与未读

完整本地清空事务成功后，账号历史存储发送会话清理通知。订阅中的会话列表立即移除精确匹配的条目、重算好友未读总数，并使在途本地合并读取失效；随后尝试服务器刷新。事务失败不会发送成功清理通知。页面退出、账号变化和存储更换均取消旧订阅，数据库关闭时关闭通知流。

首次列表快照恢复也核对清理版本，避免清空期间的旧磁盘读取覆盖新状态。单条消息删除与权限版本刷新不发送完整会话清理通知。

真实 SQLite/组件测试在所有服务器请求均返回 NETWORK_ERROR 时显示缓存好友及未读 2，直接清空，不注入 WebSocket 或中继事件，验证好友和预览消失、上报未读 0。列表、分页与历史测试 31 项通过，静态分析无问题。尚未安装手机；不覆盖待发送队列取消。

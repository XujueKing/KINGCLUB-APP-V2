# 文件分块加密移出 UI isolate

加密文件缓存将至少 64 KiB 的分块 AES-256-GCM 加解密放入 Isolate.run，较小分块保留轻量直接路径。每次后台任务只传递当前块、密钥字节和认证附加数据，不捕获文件存储实例或网络客户端。仍保持 1 MiB 分块上限、原 nonce/tag 格式和读写前后删除检查。

验证：缓存、发送源和下载器 43 项回归通过，其中包括 65 MiB 文件保留/恢复。新增 128 KiB 块与原 AES-GCM 实现双向兼容、篡改拒绝测试后缓存套件 5 项通过；静态检查无问题。

这是把分块加解密计算移出主 isolate 的实现，不是加密耗时或手机帧率提升的实测声明。逐块 isolate 启动有开销，整体吞吐和手机交互仍待 Profile 实测。摘要计算及其他消息加密不在本次改动范围，未更改网络协议或安全算法。

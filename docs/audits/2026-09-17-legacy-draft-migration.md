# 旧草稿引用清理

- 账号历史库首次接入此补丁时，检查该账号安全存储中的旧草稿引用，以每页 50 条核对对应会话的有效本地原消息。
- 已隐藏、撤回、失效或未缓存的原消息均不能确认引用有效，因此保留草稿正文、移除引用及预览；有效引用保留。未缓存并不等于服务端已删除，此处仅采取保守的本地预览清理。
- 账号隔离，一次性迁移完成标记保存于安全存储；处理失败不写完成标记，并关闭本次打开的数据库，以便下次重试。没有清空发送队列或用户草稿正文。
- 16 项相关测试通过，包含有效原消息位于第二页、已删除与未缓存原消息、其他账号隔离以及完成标记避免重复迁移；3 文件 analyze 通过。
- 本补丁尚未安装，安全存储使用测试替身，未计作手机迁移验收。后续新草稿涉及从未缓存原消息且仅收到清空序号边界的情形仍待补齐。

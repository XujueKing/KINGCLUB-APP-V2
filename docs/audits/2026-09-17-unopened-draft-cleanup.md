# 未打开会话的草稿引用清理

- 生产 ChatHistoryStore 接入账号安全存储，单条删除按消息 ID 清除对应草稿引用，整段清空移除该会话草稿引用；用户尚未发送的文字与草稿 ID 保留。
- 接收服务端 hidden/recalled 消息及已缓存历史的 hiddenThrough 清理时，同步移除已知被删原消息的草稿引用。direct 历史键映射 peer 草稿键，group 键保持原样。
- 与草稿写入共享串行锁，记录当前进程已清理的草稿 ID，阻止同一旧草稿的迟到写入恢复引用。其他账号和另一会话类型不受影响。
- 61 项历史存储、引用迁移、草稿存储和页面测试通过；4 文件 analyze 通过。新增 4 项真实 SQLite / 加密历史配合安全存储测试替身的删除、清空、撤回及清空边界验证。没有把安全存储测试替身计作手机实测。
- 未安装本补丁；早前删除完成而残留、又不再收到删除事件的旧草稿尚无全量迁移。若原消息从未缓存，单凭序号边界无法判断不带序号的旧草稿引用是否被清空，仍待补齐。待发送队列策略不变。

# 清空附近直连记录时移除持久化正文

用户要求清空和删除记录时同步删除对应的持久化内容。确认普通历史及媒体已有清理链路，但 nearby_message 的显式清空此前只写 hidden，仍保留正文密文。

本节点：显式清空直连记录同时清空 nearby_message.payload，保留身份标记以抑制同设备及另一设备重放。底层设备历史及重试查询排除隐藏记录；收到服务端撤回/隐藏标记时也清理直连副本正文。数据库版本 18 迁移清理历史 hidden=1 的正文。保留标记不包含消息正文；不宣称底层磁盘取证级安全擦除。

验证：附近成员历史、设备历史、服务端对账、历史数据库、媒体清理、列表缓存共 57 项测试通过，5 个改动 Dart 文件 analyze 通过。新增真实 SQLite 检查迁移及显式清空后的 payload 为零长度，重放不能恢复可见记录。补齐旧 v6 测试数据库遗漏的 message 表定义。尚未打包安装本节点。

范围：普通已发送记录的删除、附件引用保护延续既有实现；用户主动保存到公共相册/下载目录的副本不作为应用缓存删除。未发送队列取消策略仍待之前的问题答复，本节点未修改发件箱。未进行真实会员记录删除。

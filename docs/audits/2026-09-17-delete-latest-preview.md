# 单条删除同步清理最后消息预览

明确删除单条记录时，如果被删除的 sequence 等于持久化列表的 lastSequence，同事务清空 preview，保留会话、日期、游标和其他消息的未读数。清理通知携带删除序号，内存列表采用相同规则；版本屏障也覆盖这次删除，拒绝先前请求恢复旧文本。删除非最后一条不改变当前预览。

不凭本地不完整历史推算新的预览或准确未读数，仍等待服务端刷新。群聊和单聊按类型及身份区分。此修改覆盖本地显式删除路径，尚未新增其他设备删除后远端 tombstone 路径的列表同步证明。

单聊/群聊各以真实 SQLite 保存两条消息及两个同名不同类型会话，依次删除旧消息/最新消息；验证只有目标最新预览被清空、其他会话与计数保留、旧版本保存被拒绝、重开数据库结果不变。通知应用到内存行亦符合相同结果。历史/列表/分页测试 33 项通过，静态分析无问题。未安装新 APK。

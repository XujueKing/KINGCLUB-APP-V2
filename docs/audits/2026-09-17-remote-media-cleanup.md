# 服务端历史删除结果的附件清理

提交服务器历史页时，在删除清空边界内记录、或用 hidden/recalled 替换旧消息之前，解密旧记录查找本地附件并清理。处理包含 stale 归属，先校验当前本地代次、历史版本及群成员版本，过期页不能触发文件删除。

共享语音、发送文件及图片/视频源按剩余本地历史、当前新页和待发送队列引用保留。最后一个引用移除后清理共用副本。复用既有消息清理通知、永久删除标记和播放器/下载取消逻辑。

验证：单聊/群聊分别覆盖远端撤回、隐藏、清空边界的真实 SQLite 与磁盘清理；未删图片保留，迟到页不删除媒体。首次相关回归 64 项通过；新增共享语音测试后历史套件 23 项全部通过，静态检查无问题。

尚未安装真机，也未完成 A/B 跨设备撤回验收。清理由服务端删除结果抵达本机触发，不表示离线设备能即时感知远端变化；尚未重新取到的旧页、旧版本已丢失归属的文件仍需进一步处理。

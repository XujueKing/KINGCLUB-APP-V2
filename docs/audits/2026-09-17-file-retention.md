# 完成文件的持久保留

原文件块存储位于系统临时目录，读取时一天过期、清理时最多保留四份；成功下载还会立即删除分块。这不满足聊天附件长期保存需求。

本次将账号隔离的加密下载/发送块存储移到 Application Support。目标目录不存在时迁移旧目录，包括已有删除标记。校验完成的发送源和服务端下载文件标记为 retained；直连文件校验、授权完成后同样保存加密块。已完成文件不参与一天过期和四份临时传输清理，显式删除仍删除对应目录。未完成分块继续保留原有过期策略。

验证：下载缓存、发送文件缓存、下载器共 38 项测试通过，静态检查无问题。新增跨重开、30 天旧时间戳、超过四份已完成文件及显式删除检查；原篡改拒绝、账号改变、传输取消和消息删除测试保持通过。

限制：未安装真机；旧目录迁移未作真机验收。文件打开/导出仍依赖现有联网授权，此提交不是完全离线打开验收。发送源现有 64 MiB 上限仍在。尚未新增存储占用管理入口。已完成文件由用户删除消息时回收，不再自动按数量删除。

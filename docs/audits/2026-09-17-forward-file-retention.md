# 转发文件本地保留

转发文件重新上传为本人附件后，原流程立即释放临时明文，没有为新附件保存本地发送源。修复为准备成功后保留下载器拥有的临时文件，只有持久化发件箱接管消息后，才保留新附件加密副本并确认上传日志；随后释放临时明文。取消、失败和账号变更仍清理临时文件，未入队不创建发送源。

转发器与页面 14 项测试通过，覆盖准备阶段不保留发送源、入队确认先保存再确认日志、取消不创建发送源、保存中取消不提前删除读入文件、摘要不匹配、账号变化及发件箱重试。静态检查通过。转发器测试用注入上传器验证调用次序与临时文件生命周期，不把它计作真实上传或手机离线读取验收；补丁尚未安装手机。

补充磁盘验证：新增用例使用真实 ChatFileUploader.retainQueuedSource、AES-GCM 缓存和 ChatSentFileCache；准备阶段没有创建发送源目录，确认入队后临时原件删除，重新打开加密库仍可校验摘要并还原原始字节，读取结束临时明文清除，最后删除源后目录为空。转发器 6 项通过。上传/下载网络仍为注入边界，不能据此宣称服务端转发或手机断网验收通过。

# 清空前发起的会话列表请求失效

历史存储增加当前实例的列表清理版本。完整清空时递增；会话页面在请求前捕获版本，收到结果后先核对，再决定是否更新 UI、未读数、预取和持久化。版本不符则丢弃结果并重新拉取。列表保存也在事务内核对请求携带的版本。

覆盖同一账号生产共享 ChatHistoryStore 实例内的请求竞态；不声明多个独立数据库实例或多进程已协调。普通历史失效和单条消息删除不触发完整会话版本变化。待发送队列未修改。

组件回归使用真实 SQLite 与可控延迟网络：请求开始→清空→返回旧群预览/未读 9，验证不渲染、不上报 9、不保存，随后自动发起第二次请求并接受空列表。存储测试也验证旧版本保存不能覆盖清空结果。列表与分页测试 6 项通过，静态分析通过。网络为测试替身，尚未安装真机。

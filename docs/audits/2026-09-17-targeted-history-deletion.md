# 单条删除保留其余本地历史

此前针对指定消息 ID 的删除只清理该消息媒体，但会删除该会话全部本地消息行。若未再次同步就继续清空，剩余附件失去归属，无法清理。现改为仅删除匹配消息的序号，保留其他加密历史记录；仍推进本地代次并重置同步游标，拒绝清理前的迟到写入。

同时将剩余历史里的本人 clientMessageId 纳入发送副本保留集合，与待发送队列共同防止误删仍被引用的图片/视频源。

验证：真实 SQLite 存储中先删除两条图片之一，关闭并重开数据库确认另一条仍在；不进行网络同步，直接清空会话，第二张图片也被清理。历史存储、单聊控制器、群聊控制器共 52 项测试通过，静态检查无问题。

尚未安装此补丁真机；不同端的历史版本失效与旧附件回收仍是独立待完成项。

# 引用草稿的清空边界

- 新引用草稿保存原消息序号；解析兼容旧草稿，限制序号为有效 uint32 正整数。页面恢复及清除引用时同步维护序号。
- 历史同步传入 hiddenThrough，即使本机没有缓存原消息，也能移除边界以内的引用；保留用户输入文字及边界之后的引用。清理后通知已打开页面。
- 同一进程的后续草稿写入也检查该会话已知清空边界，避免用户继续输入形成新草稿 ID 时恢复旧引用。
- 20 项相关测试通过，新增未缓存原消息、清空后的迟到新草稿写入、边界外引用保留测试；5 文件 analyze 通过。

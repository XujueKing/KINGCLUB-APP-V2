# 未打开会话的语音持久化与清理

后台语音预下载原先只保存音频，没有保存消息归属，导致未打开会话清空时可能遗漏音频。现在启用真实历史持久化的账号先将返回的消息页保存到加密历史库，再下载语音。分页不推进前台同步游标，不标记已读。

沿用历史版本、清空代次、群成员版本和入群边界；清空前发出的迟到历史响应不得恢复消息或开始下载。不同账号的历史存储拒绝使用。

验证：后台预下载、历史存储共 22 项测试通过；新增四项使用真实 SQLite、加密密钥和磁盘文件验证单聊/群聊在重新打开存储后仍能清理未打开会话的语音，以及请求期间清空时拒绝迟到响应。静态检查无问题。媒体下载使用固定测试字节，不代表音频编码或真机播放验收。

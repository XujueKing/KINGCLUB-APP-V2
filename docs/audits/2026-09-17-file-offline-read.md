# 已下载文件离线读取

文件下载器优先尝试该账号、消息、资源和摘要对应的已完成加密分块。逐块解密后核对完整 SHA-256，成功才交给页面，完全命中时不请求下载授权或连接对端。缺块或摘要错误会清除无效副本并回到原联网流程。会话检查、删除标记及取消检查仍然执行。

本次已从本地完整验证的文件可离线导出；其他文件沿用原授权流程。删除通知仍关闭对应使用状态、删除临时明文并拒绝继续下载或导出。

验证：下载器和下载缓存共 32 项测试通过，静态检查无问题。新增真实加密磁盘分块重新打开、模拟网络不可用下的单聊/群聊读取与导出授权、删除后临时文件消失及禁止再次导出检查。未进行真机文件打开器或系统保存界面验收。

仍待完成：发送方只保存在 sent-file 源库、尚未形成消息下载副本的文件本地直读；多端撤回/隐藏通知到本地文件失效的完整验收；手机离线冷启动与保存实测。服务端权限变化在设备离线时无法即时获知，与其他已保留附件相同。

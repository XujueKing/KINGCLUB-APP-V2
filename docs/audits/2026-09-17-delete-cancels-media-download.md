# 删除时取消对应媒体下载

- MediaCache按缓存身份记录下载取消令牌；永久删除先取消该下载，再等待临时文件收尾及写入持久化删除标记，避免等待网络超时。
- 语音及视频后台补齐收到删除事件时先取消对应传输，再等待任务退出，继续使用既有正式清理写入永久标记。其他消息下载不受影响；删除错误仍统一为已删除状态，不暴露HTTP取消类型给上层。
- 34项媒体缓存/清理/语音视频预取测试通过。新增阻塞HTTP适配器用例：两个下载同时等待，删除第一个在3秒测试上限内完成，第二个仍可完成；磁盘重开后第一项不可读，第二项保留，无.part残留。4文件analyze通过。
- 本次网络由测试适配器控制，文件写入为真实临时目录；尚未安装，不计作手机弱网删除耗时验收。授权接口本身的等待不在此下载取消范围内。

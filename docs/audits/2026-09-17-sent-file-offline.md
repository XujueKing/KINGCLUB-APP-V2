# 发送方文件源离线读取

文件下载器打开账号隔离的发送源库。在消息 sender 与当前账号相同时，优先从发送源库按资源 ID、长度和 SHA-256 还原已保存文件；源库自身逐块解密并核对摘要。临时明文由下载器接管，原源库回调创建的临时文件仍按原规则释放。

本地命中无需服务端请求，可以继续离线保存。下载器在恢复前后检查会话与删除状态；删除通知仍清理明文和拦截导出。其他发送者不能使用此分支。缺失或超出现有源库 64 MiB 上限的文件回到正常下载流程。

验证：下载器与发送源库共 38 项测试通过；静态检查无问题。单聊/群聊均覆盖源库重开、网络不可用、本地读取、导出授权以及删除后拒绝使用。代码检查确认普通聊天、历史搜索上下文均传入发送者字段。未安装真机，系统文件打开/保存与断网冷启动仍待实测。

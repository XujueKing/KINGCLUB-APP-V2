# A 转发文件离线读取真机验收

设备 A（462606d8），预览 d0a8740；仅在已授权 A/B 会话使用项目测试文件 KINGCLUB-offline-file-test.txt（50 字节），B 未操作。

1. 从原生文件选择器选中测试文件，发送后会话出现文件卡片。
2. 长按该卡片，选择转发，选择 B 并确认发送，会话中出现原始和转发两张文件卡片。
3. 禁用 Wi-Fi/移动数据，等待 dumpsys connectivity 明确返回 `Active default network: none`，之后强制停止并冷启动 App。
4. 离线会话仍展示两张文件卡片，打开较新的转发卡片，点“下载文件”，出现“下载完成，文件校验通过”和“保存到文件”。未重新开启网络或进行新的服务器下载。这验证了新附件的本地源在进程重启后仍能使用。
5. 恢复 Wi-Fi/移动数据；ADB device 状态正常，默认网络恢复为 136。

本次限 A 发送方、50 字节文件、同一单聊内转发后的本地读取。没有验证 B 接收、群转发、大文件、系统导出或最后引用清理。未删除原有用户消息，也未删除本次测试卡片。UI 快照只保留在设备本地，不提交聊天内容。

## 后续删除验收

仅长按较新的转发测试卡片，执行“为我删除”并确认；原始测试卡片及用户其他记录保留。删除前发送源库有两份 retained 目录，删除后只剩原始源；转发源目录 `7b0c82533c3b38c4219828290a8123f79b93a9d82ae153c007498cc8a441c212` 的目录存在检查返回 1（不存在），不是仅移除标记。

再次禁用 Wi-Fi/移动数据并确认无默认网络，强制停止/冷启动，A/B 会话只剩一张测试文件卡片。打开原始卡片后，本地读取仍显示“文件校验通过”和“保存到文件”。随后恢复网络，默认网络 137。

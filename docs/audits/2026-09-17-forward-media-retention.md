# 图片与视频转发本地保留

转发生成本人新附件后，按持久化发件箱里的 clientMessageId 保存图片/视频发送源，复用普通发送、离线展示和删除清理的键。未确认入队不创建新发送源；取消时释放图片内存引用。视频源使用消息归属的缓存键，避免转发下载留下不能由消息删除清理的别名。保留既有 UI 和服务端授权检查。

验证要求：图片及视频转发入队后缓存重开可读取，删除清理可命中，取消或账号变化不保存新副本。手机验收另记。

实现及验证：持久化发件箱入队后传入真实 clientMessageId，图片/视频分别写入 chat-image-sent 与 chat-video-sent。视频转发源使用独立 chat-video-forward 消息键，删除清理同时覆盖该键，避免与普通播放的编码缓存混用。保存过程中关闭页面/账号变化会清掉刚生成的副本。

四个相关套件共 25 项通过，七个相关文件静态检查通过。单聊/群聊测试使用真实磁盘缓存，验证准备阶段未保存新发送源、入队后缓存重开字节一致，以及新消息删除后文件消失；另有转发视频源的永久删除及拒绝重写检查。媒体字节为测试夹具、网络为注入边界，没有据此声称图像解码、视频音画或真实上传通过。手机包尚未更新本补丁。

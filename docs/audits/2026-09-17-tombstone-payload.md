# 删除标记不持久化原消息内容

历史写入的 hidden/recalled 标记改为仅保留消息/会话/账号身份、序号、创建时间和消息类型。hidden 正文固定为空，recalled 固定为“消息已撤回”；原正文、文件名/大小/哈希、图片/视频/语音附件字段、位置、引用和通话内容不进入新的持久化标记。

真实 SQLite 回归给删除标记夹带上述字段，关闭后重新打开并读取，断言仅剩同步身份与固定提示；读取函数另补 status=sent，并非保存原内容。38 项历史存储测试通过，静态分析无问题。

本次是新提交记录的过滤，不是旧数据库全量擦除迁移，不声明文件系统安全擦除。尚未安装新 APK，旧已落盘标记的批量迁移仍未执行。

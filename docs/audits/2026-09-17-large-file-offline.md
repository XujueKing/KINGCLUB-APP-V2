# A 12 MiB 文件离线读取

A 覆盖安装 a2c1ca1 Profile（159.4MB，Gradle 65.4 秒），包含文件发送页登录变化保护。仅操作 A；在已授权 A/B 测试会话发送项目随机字节文件 KINGCLUB-large-file-12MiB.bin，12,582,912 字节，SHA-256 `1eb0f97217050d3f260231f1fee9b4a69e310042b1b6bdb3bb928967d4c724e1`。素材及 UI 证据仅在本机 build。

原生文件选择器先停在上次 Pictures 目录。切到下载目录后，系统搜索仍报“暂时无法加载内容”；直接浏览目录、滚动到文件可正常选择。进入发送页并点击发送，真实会话出现 12.0 MB 文件卡片。

第一次断网读取采样只看到“取消下载”，其后恢复网络，因此不能计为离线读取成功。第二次重新进入飞行模式并关闭 Wi-Fi，dumpsys connectivity 明确 `Active default network: none`；强制停止并冷启动 App，重新进入 A/B 会话，打开同一文件并点下载。连续 UI 检查第二个样本显示“下载完成，文件校验通过”；随后再次核对仍无默认网络。这证明已落盘的大文件跨进程离线读取和校验通过，不据此区分最终读取的是发送源库还是第一次读取形成的下载库。

finally 恢复网络；后验 airplane_mode_on=0、wifi_on=1。已返回会话，测试文件卡片保留。未操作 B、未修改真实用户文件。未验证 B 接收、大文件系统导出、弱网中断续传、最大 256 MiB 边界或主观流畅度。

## 后续系统导出

在同一 A/a2c1ca1 再次打开该文件，读取校验通过后点击“保存到文件”，通过系统保存器写入下载目录，App 显示“已保存到所选位置”。系统自动创建 `KINGCLUB-large-file-12MiB (1).bin`，原测试文件未覆盖。

ADB sha256sum 检查手机下载目录的原始文件与新导出副本，均与电脑原件的上述 SHA-256 完全一致。导出后已返回会话，未操作 B。此项补齐 12 MiB 系统保存完整性，覆盖上一段“系统导出未验证”的旧状态；本次导出时网络已恢复，不扩大为离线系统导出验收。外部查看器、弱网续传、接收端仍待完成。

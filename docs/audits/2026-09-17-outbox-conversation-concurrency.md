# 多会话补发避免串行阻塞

此前恢复器按会话逐个等待 initialize（读取历史及发送队列），一个慢请求会阻塞后续所有收件人。隔离复现放入5个不同收件人的待发消息，暂停历史返回，原实现只启动1个会话。

现改为最多3个会话并行恢复，同一轮按会话去重，同一会话内仍使用原控制器及原消息ID。每个槽位启动前再次检查页面是否已接管；关闭后不再启动新会话，已有控制器继续按原取消规则处理。单会话错误不阻断其余收件人。没有调整UI、收费、清空队列策略或服务端协议。

验证：新增测试证明阻塞期间启动3个独立会话、并发峰值3，释放后5个会话全部补发且队列为空；修复前明确失败（实际1）。恢复器8项测试通过，2个相关文件静态检查通过。尚未安装进行真实多会话弱网验收。

# v17 旧删除标记内容清理

本地历史数据库升级到 v17。在 SQLite 升级事务内，每批 50 行读取并验证解密，仅重写 hidden/recalled 记录，沿用新写入的身份字段白名单与固定提示。普通消息的密文不重写，消息数量、序号、游标及 stale 标记保留。新建数据库不扫描，成功升级后不重复执行。

回归构造 60 条真实加密历史，在第 1、55 条注入 v16 旧标记及私密字段；升级后验证两个批次均清理、58 条普通消息原始数据库行完全不变、记录数 60、游标 60、版本 17，重新打开结果一致。包括早期 v1 升级在内的 39 项历史测试通过，静态分析通过。

升级异常不吞掉，交由 SQLite 升级事务回滚；本节点未注入中途磁盘故障验证。升级首次需要遍历已保存历史，大容量设备耗时未测。只迁移加密记录字段，不保证文件系统不可恢复擦除，不新增历史遗留附件的全盘回收。尚未构建安装 A/B。

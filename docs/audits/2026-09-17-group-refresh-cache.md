# 已确认分组不被旧磁盘快照回退

复现：真实 SQLite 保留 version=1，仓库成功读取服务端 version=2，但注入一次磁盘打开失败。下次网络刷新未完成时，原实现通过 onCached 发布 version=1，导致已显示的新分组短暂回退。新增回归在修复前明确失败，观察到一次旧缓存发布。

修复：本地缓存仅用于该仓库首次成功网络读取之前的恢复。一旦已有服务端确认版本，刷新保留当前内容，不再发布旧磁盘快照；首次离线恢复仍可用。不会因本地写入失败把服务端已确认保存标为失败。

验证：持久化、仓库并发与幂等、分组页面共10项测试通过，2个相关Dart文件静态检查通过。尚未合入安装预览，本节点不新增手机验收声明。

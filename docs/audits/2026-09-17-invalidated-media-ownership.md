# 历史失效保留附件清理归属

本地数据库升级到 16，为加密消息增加 stale 标记。普通刷新与历史版本变更将旧消息标记为不可展示，而不是直接删除其加密归属信息；历史读取排除 stale 行，新确认页替换行后恢复有效状态。显式清空仍遍历这些记录清理附件并删除记录。

验证：版本变更/普通刷新后关闭并重开 SQLite，旧记录不展示、文件仍在；随后显式清空能删除旧文件。与单聊、群聊和后台语音持久化回归共 58 项测试通过，静态检查无问题。升级测试覆盖旧版数据库。

这是防止刷新过程中丢失附件归属的修复，尚未安装真机。服务器返回撤回/隐藏记录、远端清空边界时的即时媒体回收仍需继续补齐；当前提交不能宣称跨设备媒体删除已完成。

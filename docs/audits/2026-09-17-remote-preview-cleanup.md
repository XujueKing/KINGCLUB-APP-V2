# 历史同步的删除标记清理列表预览

历史 commit 通过 epoch/版本校验后，清理被 hidden/recalled 或 hiddenThrough 覆盖的旧内容时，同时更新加密会话快照并发出清理通知。单条删除只清除相应最后消息预览；清空边界覆盖列表 lastSequence 时移除旧会话项，边界之后的新会话内容保留。

只在实际替换旧内容或清空边界推进时递增列表版本、通知页面，重复同步同一删除标记不再次通知，避免历史预取与列表刷新循环。事务未提交不发成功通知。

真实 SQLite 单聊回归分别覆盖 hidden、recalled、floor：拒绝过期 epoch 时列表不变；首次有效提交清理预览；重放无重复事件及版本变化；旧版本列表写入无效；关闭重开后结果保留。存储/列表测试共 35 项通过，静态分析无问题。未安装新 APK，未执行双机远端删除或群聊真机验收。只有列表缓存但缺少对应消息行的旧安装仍需服务器刷新完成预览纠正。

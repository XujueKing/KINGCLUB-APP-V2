# Flutter V2 本期范围评审包

- 状态：`M0 Scope Frozen`
- 审计基线：旧版 `KingClub-app / master / 505d222 / 1.1.37`
- 审计日期：2026-08-24
- 用途：确认本期 Flutter App 的完整功能、页面和明确不做项

## 已确认事实

- 旧版 `app.json` 注册 68 个主包页面和 1 个分包页面，共 69 个物理路由。
- `pages/index/index` 单个物理路由内嵌首页、通讯录/会话、短视频、私人储物柜和我的等多个逻辑页面，不能按“一个旧文件等于一个 V2 页面”迁移。
- 设置、管理员面板等入口由超级接口返回动态菜单，因此静态引用次数不能单独证明页面是否仍在生产使用。
- 旧版同时混有普通会员、群主/局长、员工、代理、财务和超级管理员能力。
- 通用成功页、APK 下载页、日志页和部分实验页不应原样迁移为 V2 产品页面。
- 本次只审计和写 V2 规划文档，没有修改旧版仓库，也没有创建 Flutter 工程。

## 已确认事实

- 用户确认：旧小程序学习流程和 UI；V2 为主开发项目；新 API 和数据库落在 `ccsop-service`；UI 目标保持 99% 类似。
- 用户追加确认：以前手工代码和存储过程不必照搬，允许现代化重构；以有效业务、数据一致性、可维护性和可验证的性能为验收依据。
- 用户进一步确认：SQL 是多网站混包，KING CLUB 业务表按 `k_` / `K_` 前缀识别；通过 `s_interface` 分类及真实依赖交叉核对。
- 当前快照的分类链为 `s_interface.interfaceType -> s_interface_type.typeId -> parentId`，根分类为“酒吧”，下分 App 和服务器端使用，共 103 个接口；后续群聊脚本另有 3 个接口。
- 本机 V2 已有 48 页 UI/Mock 和首批跨页交易修复；这不等于 72 个旧路由对应的全部产品能力已经完成，更不等于生产可用。
- CCSOP 当前 KingClub 分支有登录/统一身份和通用基础设施，不是完整的聊天、短视频、交易、会员业务服务器。
- 本轮不执行旧 SQL、不导入用户数据、不发送短信/支付、不修改旧服务、不部署、不提交或推送 Git。

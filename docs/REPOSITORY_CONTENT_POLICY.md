## 提交检查

使用 Node.js 运行 `node scripts/check_repository_content.mjs` 检查暂存区（服务端开发环境已有 Node.js）：

1. 不允许提交匹配 `.gitignore` 的文件，防止强制添加绕过过滤。
2. 默认单文件上限为 10 MiB，当前快照全部文件之和上限为 100 MiB。这是本项目的体积预算，不是 GitHub 的平台限制。
3. 检查的是 Git 暂存区中的内容，不计算本地缓存，也不等于仓库克隆或 `.git` 目录大小。

后续确需超过预算的运行素材，应先确认压缩、按需下载或其他存储方案，不因临时验收附件提高预算。

## 历史边界

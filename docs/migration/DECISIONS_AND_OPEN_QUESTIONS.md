# 已定事项与待确认问题

## 已确认事实

- 当前可用基线是 `master / 505d222 / 1.1.37`。
- 未提交 AI 重构已保存到独立分支和提交。
- 当前小程序包含社交、聊天、内容、门店、订单、支付、会员和代理等复杂业务。
- 原项目尝试用小程序 multiPlatform 同时支持微信、Android 和 iOS。
- 微信小程序无法承载计划中的全部原生 App 扩展能力。
- 服务端已经升级，旧数据库被多套 App 共用。
- 共享数据库中存在同城个人用户信息。

## 方向性决策

- 微信小程序保留并渐进完善。
- Flutter 作为 iOS/Android V2 首选方案。
- 数据按领域拆分，而不是按客户端机械复制。
- 身份可以共享，App 业务资料和交易数据隔离。
- 先 API v2 和数据边界，后大规模 Flutter UI。
- 迁移过程保持旧版可回滚。

以上是当前推荐方案，正式立项时仍需由产品、后端和运营共同确认。
